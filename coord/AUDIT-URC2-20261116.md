## 3. C2 两条关系的逐项核验

### 3.1 q 侧 `q_P5 = -M`，`M=Q/(2l)`，log-mass `(1/(2l))log|q|`

- 真数学在 `Mzk1URRootMassActual`：
  - `normalizedLogMass_smul_units`（261 行）：`(1/[L:Qp])(log μ(w·Int)−log μ(Int)) = log‖w‖`，用 `distribHaarChar`、`distribHaarChar_urPrimeUnit = p^{-D}`、单位球不变性、`measure_prime_smul_finiteDimensional` 真证；
  - `normalizedLogMass_kummer_root`（290 行）：`r^d=q` 时该量 `= (1/d)log‖q‖`。
  两定理与 paper 语义一致（d=2l 即 1/(2l)·log|q|）。
- 缺的三步：
  1. 在实际 `b` 上实例化：`L = rootNormedExtension T b`、`r = urRootAlpha T b`、`d = 2l`、`q = algebraMap (sourceRootQUnit)`（`urRootAlpha_pow` 已给幂关系）。全树没有这个定理（`urRootMass_kummer` 只是注释）。
  2. 按 P4 权重 `nativeBadLocalWeight` 求和得到 `M`。**没有**。
  3. 与 P5 的 q 读数同一。P5 读数是 `qPilotRealifiedLogVolume = -MqBad`，`MqBad = Σ_b order(q_b)·f·log p`，字面上也不含 `/(2l)`；route §5.4 要求 paper 的 `|log q|` 是 `M=Q/(2l)`。现有 `paperQAbsLog = qPacketSignedLogQ/(2l)`（`Mzk1P3DictQAbsLogIdentityActual`）说明项目内部确实区分未取根量与被 2l 除的量，但 U-R 六项既没有把 P5 读数改接到 M，也没有证明 `q_P5=-M`。清单把 `actualQPilotMagnitudeClassical` 叫 `M`（`ur_negM_le_Htheta`），按其定义它是未取根的 q 量级，属**归一化误标**；若 route 的 `M=Q/(2l)` 为准，则记作 `-Q` 的下界**推不出** `-M` 的下界（`-Q < -M`），P5→C4 的夹逼系数会差 2l（这里 Q 只表示未取根量级，具体归一只需一个恒等式即可固定，但没有）。

### 3.2 θ 侧 `θ_P5 ≤ H_pkt = Σ_a w_a V_a`

- `p6PacketHull` 是 `arithmeticTupleHolomorphicHull(possibleImages)`（`FinitePlaceStepVAssembly.lean:752`），`p6_possibleImages_subset_packetHull` = `subset_arithmeticTupleHolomorphicHull`（759 行，`x∈A ⇒ x∈hull(A)`）。这是定义包含，且 `A` 是 possible images，不是 P5 的 `actualRootThetaHull`（`PaperLevelXiFTargetActual:94`，系数 `j²·c_norm/(2l)`）。两者之间**没有包含定理**。
- `H_pkt` 的现有定义在 `Mzk1ULHpktActual`：`Hpkt w V = Σ w_a V_a`，`w,V` 任意（审计 §4.7/#132 已判）；U-R 清单没有把它接到 `ulThetaPacketV` / `ulDivisorWeight`。
- 唯一接到 `V_a` 的真定理是 `urRootTheta_mass` / `ulThetaPacketV_eq_neg_order`（per-b 等式），没有 `hull volume ≤ Σ V_a`。
- 消费侧也承认这一点：`Mzk1UCC1UpperActual.uc_c4_of_p6_data`（59–70 行）把 `htheta : actualThetaHullLogRoot ≤ Hpkt` 作为**显式假设**；route §5.3 原本要求 U-R 提供它。U-R 六项没有。
- 零坍缩路线（`Node09P5ThetaReadingZeroActual` + `Mzk1P6P5ControlJ1Actual`）把 `qVFamThetaReading` 与 `H_pkt` 都证成 0：`theta hull = 单位区域 ⇒ log-volume 0`。这不是"区域包含"，也与 paper 的 `θ_P5>0` 语义相反（该文件自己还证了 `qVFamThetaReading ≠ 正 logQ`）。不得记为 C2 的 producer。
