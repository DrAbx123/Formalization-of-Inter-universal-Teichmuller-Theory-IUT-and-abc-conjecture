## 1. Exact signature and quantifier of h312

MainTheorem.lean:36:

  theorem classicalABC_of_variant (h312 : Cor312VariantHolds) : ClassicalABC

where (ThetaRegion.lean:375):

  def Cor312VariantHolds : Prop :=
    forall D : InitialThetaData.{0}, Corollary312Variant (concreteVariantData D)

and (Statement.lean:89):

  Corollary312Variant X : Prop := X.qPilot.lhs <= X.rhsData.rhs

Therefore h312 is literally:
  forall D : InitialThetaData.{0}, -D.qPilot.absLogQ <= (concreteVariantData D).rhsData.rhs.

Quantifier facts:
- the universe is fixed: InitialThetaData.{0};
- the only restriction on D is the structure InitialThetaData (IUT I, Definition 3.1);
- there is no "there exists D", no finite set, no height/conductor/qOrder/level
  restriction in Cor312VariantHolds itself;
- concreteVariantData D is a function of D (data := D, qPilot := D.qPilot,
  rhsData := D.rhsData); no additional choice.

## 3. If variant holds only for a restricted class of D

Suppose one has a partial statement

  hPartial : forall D : InitialThetaData, Bound D -> Corollary312Variant
    (concreteVariantData D)

for some Bound D (e.g. qOrder <= B, height <= H, or a finite set).

Then hPartial cannot be passed to classicalABC_of_variant directly, because
that theorem requires the exact type Cor312VariantHolds:
  forall D, Corollary312Variant (concreteVariantData D),
with no Bound argument.

One could try to build a modified bridge for hPartial. The needed extra step is
  forall K d x ..., Bound (D_{K,d,x}),
where D_{K,d,x} is the D produced by concreteThetaDataExistence' for the
point x and prime ell. The audited construction supplies no such bound:
- D is built from the curve of x, its Tate inputs, and an ell chosen in the
  Corollary 2.2 input;
- qOrder of D is the qOrder of the actual curve/Tate parameter
  (Existence.lean:316 thetaData_qOrder), not a fixed bounded quantity;
- the quantifiers in Corollary22Inputs/ThetaDataExistence (Corollary23.lean:360-374)
  do not contain a qOrder/height bound; they assert existence of D for every x
  and every prime ell with the stated arithmetic properties;
- classicalABC quantifies over all coprime a,b,c, so a bound on the curves
  would need to be proved for all these D, not assumed.

Consequently:
- a variant restricted to qOrder <= B does not imply classicalABC through the
  existing bridge;
- it could only imply a restricted ABC statement on the subfamily whose
  constructed D satisfy the bound;
- the full ABC conclusion needs the bound to hold for every D generated by
  concreteThetaDataExistence' (equivalently, for every relevant curve), or a
  proof that the construction only generates bounded-qOrder D (not available;
  qOrder is unbounded in the formal domain).

## 4. Verdict

1. h312 quantifies over all InitialThetaData.{0}; it is not a finite or
   bounded-domain statement and has no hidden qOrder/height restriction.
2. classicalABC_of_variant uses only h312 plus the Tripod/Corollary22
   construction and the Chebyshev/prime-counting bounds; it is a pure
   implication from the full variant to ClassicalABC.
3. The proof applies h312 to every D produced by concreteThetaDataExistence',
   not to a chosen finite set.
4. If the variant is only known on a subclass (e.g. qOrder <= B), the existing
   bridge cannot be used unless one proves the constructed D always lies in
   that subclass. No such bound is present in the audited definitions or
   construction. Such a partial variant at most gives a restricted ABC
   statement, not ClassicalABC.
5. This reinforces the status in LANA-VARIANT-STATUS: the full quantifier is
   essential; weakening it is not a hidden route to ABC.
