# BUIUM p-导数数值实验（A794，stage4）

日期：2026-11-12。目标：用便宜数值实验检验 "Buium 算术 Kodaira–Spencer 的 p-导数不变量" 的
v_p 代理量是否与 Szpiro 余量 `(1/6)log|Δ| − log N` 相关，从而快速否定/指出方向。

**结论（先给）**：对 Frey 曲线族，`v_p(c4)` 型代理量**没有独立信号**——
所有奇数坏素数的 `v_p(c4)=0`（结构性，见 §3），因此 `Σ_p v_p(c4)·log p = log 16` 为常数；
`v_p(Δ)` 组合是 `log|Δ|` 的精确线性函数。本实验**否定**"曲线不变量的 v_p 代理量可以
探测 p-导数不变量"这一廉价路线；要检验 Buium 不变量必须真正计算 p 进 Frobenius 提升
（p-曲率/算术 KS 类），而不是不变量的赋值。样本 59 条曲线、3 族；无 Lean 文件改动。

## 执行摘要（A796 归档；路线 γ 结论）

- **A794（廉价代理）**：Frey 族上 v_p(c4) 对所有奇坏素数结构性为 0（只剩 log16），零方差；
  与 Szpiro 余量的"相关"完全由 M=(1/6)log|Δ|−log N 的定义代数决定（OLS R²=1）。⇒ 廉价代理路线**淘汰**。
- **A795（真 p-曲率）**：用 Legendre 族 Hasse 不变量（Gauss–Manin 连接 p-曲率标量）在 p=5..199 计算
  p 进深度 T；129/129 与 a_p mod p 验证一致；T 有实质变化（std=5.00），但与 Szpiro 余量**无相关**：
  Pearson −0.035、偏相关（控制 logΔ,logN）−0.036（n=37）。
- **判定**：按预登记判据（|偏相关|≥0.5 且独立家族复现、n≥100、规范 Teichmüller 提升）**三条全不满足**
  ⇒ 路线 γ 的"p-曲率深度 ↔ Szpiro 余量相关性"分支**暂停**（不删除证据）。
- **若要重启**：先实现规范提升（Teichmüller/Serre–Tate）并选第二独立家族；否则性价比低。
- 全程无 Lean 文件改动；脚本与数据见文末 §6/§7.8。


## 1. 方法

对 abc 三元组 `A+B=C`，取 Frey 曲线 `E_{A,B}: y^2 = x(x−A)(x+B)`。用标准 Weierstrass
不变量公式（sympy 计算，与闭式一致）：

- `c4 = 16(A^2+AB+B^2)`
- `Δ = 16 A^2 B^2 C^2`（`log|Δ| = log16 + 2logA+2logB+2logC`）
- 导体代理 `N ≈ rad(A·B·C)`
- Szpiro 余量 `M = (1/6)log|Δ| − log N`

代理量（对 `p | Δ` 的坏素数求和，`v_p` 为整数赋值）：

| 记号 | 定义 |
|---|---|
| PKS_a | `Σ_{p|Δ} v_p(c4)·log p`（"算术 KS 尺度"） |
| PKS_b | `Σ_{p|Δ} (v_p(c4) − v_p(Δ)/3)·log p`（量纲平衡） |
| PKS_c | `Σ_{p|Δ} max(0, v_p(c4) − v_p(Δ)/3)·log p` |
| logC4 | `log|c4|`（对照） |

样本：F1 = `(1, 3^n−1, 3^n)`, n=1..15；F2 = `(1, k, k+1)`, k=2..30；
F3 = 15 条杂三元组（含 `(1,8,9)`、`(2,3,5)`、`(4,5,9)`、`(1,20,21)` 等）。共 59 行（未去重）。

## 3. 结构性发现（关键，可证明）

对 `E_{A,B}`，`c4 = 16(A^2+AB+B^2)`，`A,B,C` 两两互素（abc 三元组）。设奇素数 `p | Δ`：

- `p | A` ⇒ `B,C ≢ 0 (mod p)`，`A^2+AB+B^2 ≡ B^2 ≢ 0`;
- `p | B` ⇒ `≡ A^2 ≢ 0`;
- `p | C` ⇒ `A ≡ −B`，`A^2+AB+B^2 ≡ B^2 ≢ 0`。

故 `v_p(c4)=0` 对**所有奇坏素数**成立；只剩 `p=2`：`v_2(c4)=4`（样本中 `16(A^2+AB+B^2)`
的奇数部分不含 2）。因此

`PKS_a = 4·log 2 = log 16 ≈ 2.7726`（**零方差常数**，实测 59 行全部一致，
`odd_prime_c4_nonzero_count = 0`）。

由此 `PKS_b = log16 − (1/3)log|Δ|` 是 `log|Δ|` 的精确线性函数（r = −1.0），
不是独立信号。`PKS_c` 亦仅为 `−v_p(Δ)/3` 截断的简单函数。

## 4. 相关性

| 量 | Pearson r vs M | Spearman ρ vs M |
|---|---|---|
| log\|Δ\| | −0.460 | −0.530 |
| log N | −0.754 | −0.825 |
| log C4 | −0.434 | −0.475 |
| PKS_a | n/a（零方差） | −0.253 |
| PKS_b | 0.460 | 0.531 |
| PKS_c | −0.346 | −0.372 |

对照：`M = (1/6)log|Δ| − log N` 由定义就是 `(log|Δ|, logN)` 的线性组合，
OLS 回归 `M ~ log|Δ| + logN` 得 **R² = 1.0**（系数 1/6、−1，截距 0）。
**这意味着任何**基于 `log|Δ|`/`log N` 的"相关性"都是代数恒等式，不能当作证据。
去掉这两项的残差与 `PKS_b` 的相关（−0.911）同理是 `log|Δ|` 的残余，不是新信息。

## 5. 结论与方向

1. **否定廉价代理路线**：`v_p(c4)`（及 `v_p(Δ)` 组合）在 Frey 族上被结构性地钉死
   （奇数坏素数 `v_p(c4)=0`，只剩 `log 16`），不含关于 p 进提升的信息；
   与 Szpiro 余量的"相关"完全由 `M` 的定义代数决定（R²=1）。
2. **样本量/覆盖面**：59 条曲线、3 族、无超奇异/普通分类、无大素数 p；
   即便有信号也无法统计区分。
3. **要检验 Buium 算术 KS 不变量**，下一步必须计算真正的 p 进对象，例如固定小素数
   `p`（如 p=2,3,5）上曲线的 Frobenius 提升/形式群坐标，取 p-曲率或算术 KS 类
   `f^1_p(E)` 的 p 进赋值，而不是 `c4,Δ` 的整数赋值；本实验的结论是：
   **"曲线不变量赋值"不足以代理 Buium 不变量**（negative result，方向明确）。
4. 若后续做真 p 进实验，建议比较对象：固定 p、一族高 Szpiro 比曲线，比较
   `v_p(KS 类)` 与 `M`（并控制 `log|Δ|`、`log N` 的线性混杂，如用残差/偏回归）。

# A795：真 p-曲率计算（Legendre 族 Hasse 不变量 + p 进深度） vs 廉价代理

日期：2026-11-12。目的：按 A794 建议，用**真正的 p-曲率**（Gauss–Manin 连接的 Hasse
不变量）在固定小素数上计算，看其 p 进深度是否与 Szpiro 余量 M 相关；并控制 log|Δ|、log N
混杂（残差偏回归）。**无 Lean 文件改动。**

## 7.1 模型与算法（可执行、可手算验证）

Frey 曲线 `E_{A,B}: y^2=x(x−A)(x+B)`（`A+B=C`，两两互素）同构于 Legendre 族
`E_λ: y^2=x(x−1)(x−λ)`，其中 `λ = A/(A+B) = A/C`。

Gauss–Manin 连接的 **p-曲率标量** = Hasse 不变量：

`H_p(λ) := [x^{p−1}] (x(x−1)(x−λ))^{(p−1)/2}  ∈ F_p`

（`p≥5` 奇素数，good reduction）。事实：p-曲率 ≡ 0（即 `H_p(λ)=0`）⇔ 曲线 mod p
超奇异；`H_p(λ)≠0` ⇔ 普通（ordinary）。这就是 Buium 算术 Kodaira–Spencer 不变量
`f^1_p` 的标量影子：ordinary 时 `f^1_p` 是单位，supersingular 时被 p 整除。

**p 进深度代理**（本实验定义，lift 依赖，见局限）：

`κ_p(E) := v_p(H_p(λ_E) mod p²)`，其中 `λ_E = A·C^{−1} mod p²`。

即：把 Legendre 参数提升到 `Z/p²`，计算 Hasse 多项式在该提升点的值，取 p 进赋值
（0/1/2；0 表示普通，≥1 表示 p-曲率在模 p 层面消失的深度）。

**算法伪码**：

```
for (A,B,C=A+B) in curves:
  λ = A*C^{-1} mod p^2      # p ∤ C required
  H = coeff of x^{p-1} in (x(x-1)(x-λ))^{(p-1)/2} mod p^2
  κ = v_p(H)
T(E) = Σ_{5≤p<200, p∤Δ} κ_p(E)·log p
M(E) = (1/6)log|Δ| − log N,  N ≈ rad(A·B·C)
```

## 7.2 验证（Hasse 不变量 = a_p mod p）

对每个 (曲线, p) 用点计数 `a_p = p+1−#E(F_p)` 交叉验证 `H_p(λ) ≡ a_p (mod p)`：
**129/129 全部一致（100%）**。这同时给出 p=5 的手算例子：`E_{1,2}: y²=x(x−1)(x+2)`，
`λ=1/3`；p=5 时 `(x(x−1)(x−2))²` 的 x⁴ 系数 = 2，而点计数得 `a_5 ≡ 2 (mod 5)` ✓。

## 7.3 数据（37 条曲线：F2 k=2..30 与 F1 3^n−1, n=1..8）

- 深度记录 129 条（仅统计 `κ_p>0` 的超奇异 good 素数）：κ=1 有 **127** 条，κ=2 有 **2** 条；
- T 分布：mean = **13.34**，std = **5.00**（范围 4.26–23.20）——**有实质变化**（区别于 A794 的常数 log16）；
- 示例：`E_{1,2}`（k=2）：p=23 超奇异（H=0，a₂₃≡0）、T=8.388；
  `E_{1,5}`：p=7,11,167 超奇异，T=9.462；
  `F1_3^3=E_{1,26}`：p=7,47,71 超奇异，T=10.059。

## 7.4 与 Szpiro 余量的相关性（含混杂控制）

| 统计量 | 值 |
|---|---|
| Pearson r(T, M) | **−0.035** |
| Spearman ρ(T, M) | −0.029 |
| **偏相关 r(T, M \| logΔ, log N)**（残差回归） | **−0.036** |
| 偏 Spearman（残差秩） | +0.022 |
| r(T, logΔ) / r(T, log N) | 0.175 / 0.139 |

结论：真正的 p-曲率深度代理 T 与 Szpiro 余量 **无相关**（|r|≈0.04，n=37）。

## 7.5 与 A794 廉价代理的差异

| | A794 廉价代理 v_p(c4) | A795 真 p-曲率 Hasse 深度 |
|---|---|---|
| 对象 | 曲线不变量的整数赋值 | Gauss–Manin 连接的 p-曲率标量（固定 p，模 p²） |
| 变化 | **零方差常数 log16** | std=5.00，范围 4.26–23.20 |
| 验证 | 无独立内容（奇坏素数 v_p(c4)=0 结构性） | 129/129 与 a_p mod p 一致 |
| 与 M 相关 | 代数恒等式（R²=1 for logΔ/logN） | Pearson −0.035 / 偏 −0.036（近零） |

要点：真 p-曲率确实**产生了独立的、可验证的变化量**（A794 代理没有），但在当前家族/样本上
它与 Szpiro 余量仍不相关 ⇒ 不是"Cheap proxy 错、真对象对"的差别，而是**该家族上 Szpiro
余量与 p-曲率深度之间没有可检测关联**（或样本/家族过窄）。

## 7.6 量化判据与建议（是否继续这条线）

**继续阈值**（预先登记，避免事后挑数据）：需同时满足
1. 偏相关 |r(T,M \| logΔ, logN)| ≥ 0.5（用独立第二家族复现同号）；
2. n ≥ 100 条曲线且有足够 κ 变化（κ≥1 的 (curve,p) 配对 ≥ 300 或存在 κ≥2 的曲线 ≥ 20 条）；
3. 使用**规范（Teichmüller/Serre–Tate）提升**而非本节 lift-dependent 的 `A·C^{−1} mod p²` 提升，
   否则 κ 的 p 进深度不可比较。

**当前实测**：偏相关 −0.036，n=37，κ≥2 仅 2 条 ⇒ **不满足任何一条**。
**建议**：路线 γ 的"p-曲率深度 ↔ Szpiro 余量相关性"分支**降级/暂停**（量化上已否定当前
形式）；若日后继续，应先做规范提升实现（成本较高），再用第二独立家族检验，否则性价比低。

## 7.7 局限

1. κ 依赖所选 p 进提升（λ 的 lift 非 Teichmüller），p 进深度不可跨曲线直接比较；
2. 仅 Legendre 型（全 2-挠有理性）曲线，仅 good 素数 5≤p<200，仅 p≥5（p=3 在该家族全部超奇异，
   无区分度；p=2 亦退化）；
3. 未计算完整 Frobenius 提升矩阵/p-曲率算子，只算其标量不变量（Hasse）；
4. n=37 小样本，M 与 logΔ/log N 高度共线（r=0.708），统计力有限。

## 7.8 复现
