## 2. 数据表：候选、`R_p` 公式、Thm 2.0.1 核对、m、cost、Q2

### 2.1 机制 (a)：模形式/同余输入

**构造**：取 `f(τ)=Σ a_n q^n ∈ Z[[q]]` 为 `Γ(N)` 上权 `k`、整系数、归一化 Hecke 特征形式
（如 `Δ`：`N=1,k=12,a_1=1`）。取 `f_i` 为其（或若干独立形式的）`q`-展开在 `x=λ/16`
坐标下的分量；`x(t)=λ(t)/16`，`φ(z)=β(rz)`，`f_i(x(t))` 的 `q`-展开整系数。

**`R_p` 公式/界**：对 `p∤N`，Hecke 递推

    `a_{p^{m+1}} = a_p a_{p^m} − p^{k−1} a_{p^{m−1}}`。

令 `α,β` 为 `X²−a_p X+p^{k−1}` 的根，`αβ=p^{k−1}`。则

    `a_{p^m} = (α^{m+1}−β^{m+1})/(α−β)`，
    `v_p(a_{p^m}) = O(m)`（由 `v_p(α)+v_p(β)=k−1` 与最大项估计），

而 `n=p^m` 时 `v_p(a_{p^m})/p^m → 0`。对一般 `n=p^m r`（`p∤r`），`a_n=a_{p^m}a_r`，
`v_p(a_n)=v_p(a_{p^m})+v_p(a_r)=O(m)=O(log n)`；且 `r=1` 给出 `v_p(a_{p^m})/n→0`，
故 `liminf_n v_p(a_n)/n=0`，即 `R_p=1`（不是 >1）。`p|N` 时 `U_p` 递推同型，仍 `O(log n)`。

更强地，Deligne/Hecke 系数界 `|a_n|≤d(n)n^{(k−1)/2}` 给 `v_p(a_n)≤O(log n)` 对所有 `n`，直接排除 `c·n` 型 H；Hecke 递推只是给出局部显式公式。

**Theorem 2.0.1 假设核对**：

| 假设 | 核对 |
|---|---|
| `p(x)=x^N`（或 `x`）无极点 | ✓ |
| `x(t)=λ/16∈t+t²Z[[t]]` | ✓ |
| `p(x(t))∈Z[[t]]` | ✓（`λ/16` 整系数） |
| `φ=β(rz)`，`|φ′(0)|=3>1`，`φ*p∈O(D)` | ✓ |
| `x*f_i∈Z[[t]]` | ✓（模形式 q-展开整系数） |
| `φ*f_i∈O(D)` | ✓（模形式在 `λ/16` 坐标下 holonomic，Thm 7.2.1 型） |
| 分母类型 `R=Z` | ✓（整系数 q-展开） |
| **H: `R_p>1`** | **✗**：`R_p=1`，只有 `R_p≥1` |

`m` 选择：`Γ(N)` 的维数 `dim S_k(Γ(N)) ≈ kN³/12`；可作为候选 `m`（同余供给）。
`cost(m)`：`cost = B−m`，`B=e I_N/log3`；由于 `R_p=1`，`I_N` 不含 `log c−log rad`，
`cost` 仍线性；且 H 已否决，不需要继续。

### 2.2 机制 (b)：theta/CM 形式

**构造**：`θ(τ)=Σ_{n∈Z} q^{n²}`（权 1/2，CM by `Q(i)`）；或 `K=Q(√−d)` 上的 CM 权 1 形式
`f(τ)=Σ_{a⊂O_K}(D_K/a)q^{N(a)} ∈ Z[[q]]`。

**`R_p` 公式/界**：

* `θ`：`a_n∈{0,1,2}`（`n` 为平方数时 1，否则 0），故 `v_p(a_n)≤1`，`R_p=1`；
* CM 权 1 形式：`|a_n|≪n^{1/2+ε}`（Hecke 界），故 `0≤v_p(a_n)≤O(log n)`，
  `v_p(a_n)/n→0`，`R_p=1`；
* 在 CM 素数的 split/inert 处，系数是 0 或由 Hecke 特征值给出的有界值，
  没有 `c·n` 型 p 进衰减。

**Theorem 2.0.1 假设核对**：

| 假设 | 核对 |
|---|---|
| `p(x)=x^N`/`x` | ✓ |
| `x(t)=λ/16` 或 `t` | ✓ |
| `φ=β(rz)` | ✓ |
| `x*f_i∈Z[[t]]` | ✓（theta/CM 的 q-展开整系数） |
| `φ*f_i∈O(D)` | ✓（theta 在 `λ/16` 坐标下 holomorphic；权 1/2 需按 Thm7.2.1 型核对分支） |
| `R=Z` | ✓ |
| **H: `R_p>1`** | **✗**：`R_p=1` |

`m` 选择：`θ` 的独立分量只有 1 个；CM 形式维数有限；`m` 不随 k 增长。
`cost(m)`：无 H 时无意义；若强行计入 `B−m`，仍无 `log c−log rad` 差分。

### 2.3 存在性说明（为什么 H 非空不是问题，但 Q2 仍失败）

抽象函数 `g_p(x)=1/(1−p x)=Σ p^n x^n` 满足 `v_p(a_n)=n`，故 `R_p=p>1`，
`g_p∈Q[[x]]` 且 holonomic、`x*g_p∈Z[[t]]`；它表明 H 本身可满足，**不是**硬性要求为空。
但 `g_p` 的系数只依赖人为 p，不依赖 `(1,3^k−1,3^k)` 的因子结构；在 Q2 中
`3^k−1` 的信息没有进入 `I_N`，所以不能作为路线 A 候选（且不是模形式/theta 机制）。

## 3. 判定与试金石

### 3.1 H 判定

* (a) 模形式：`R_p=1`（Hecke 递推 `O(log n)` vs `n`）⇒ **拒绝**；
* (b) theta/CM：`R_p=1`（系数有界/`O(n^{1/2+ε})`）⇒ **拒绝**；
* 两者都只给 `R_p≥1`，不满足显式 `c·n` 衰减或 `R_p>1` 闭式下界。

### 3.2 cost(m) 抵消判据

* PASS 要求 `cost(m)` 不随 k 线性；对 (a)/(b) 由于 `R_p=1`，`I_N` 不含 rad 差结构，
  `cost(m)` 的线性项（A3 已测 F4 的 `≈4.44m`）无法被抵消；
* 即使人为取 `m≈kN³`，`B` 仍 ∝ m；H 已否决，cost 判定不需要继续。

### 3.3 试金石 Q2（必须回答）

**问题**：`3^k−1` 非近似完全幂的信息从哪一步进入 `I_N`/上界？

**回答：答不出**。

* 机制 (a) 的 `R_p` 只由 Hecke 递推/局部特征值决定，与 `3^k−1` 的因子分解无关；
  模形式的 level/weight/character 也不编码 `rad(3^k−1)`；
* 机制 (b) 的系数由 CM 域/特征给出，`R_p` 只取决于 CM 素数分裂类型，
  与 `3^k−1` 是否近完全幂无关；
* 两者都无法让 `I_N` 出现 `log c−log rad` 差项。

Q1（量词范围）：`(1,3^k−1,3^k)` k=1..60 + 20 个 c≤20000 三元组（设计级，未数值）；
Q3（丢失检验）：去掉 `3^k−1` 因子信息，两机制的 `R_p`/`m`/`I_N` 形式完全不变；
Q4：Q2 答不出 ⇒ **STOP-NO-TOUCHSTONE**，不进入 A3″ 数值化。
