# GROUP-CONDITIONS — 分组充分条件实验

日期：2026-11-12；qpilot（A1050）。**仅 Python**。数据：`coord/c1_local_terms_e_exact.jsonl`，N≤2000 admissible（ℓ=5, 2604 条）。

## 1. 条件与分组

逐坏素数 p（p=2,3 的 H 为 wild 模型，p=ℓ 剔除；p>3 的 T=(sF−1)A_p/nC）：
```
V_p := H_p,  gap_p := Ind2_p,  A_p := v_p logp/(2ℓ)
组条件 C_G:  Σ_{p∈G}(V_p+gap_p) ≥ (sF−1)Σ_{p∈G} A_p,   sF=2.5
```
（这是 c1 MODEL 的逐组充分条件；若所有组成立则 Σ over group 成立，但组间不需要逐位成立。）

## 2. 分组结果（2604 条 admissible）

| 分组 | 可行曲线 | 失败曲线 | 说明 |
|---|---:|---:|---|
| singleton_p（每个 p 单独） | **2603/2604** | 1 | 858k2 p=13 |
| size1（2 / 3 / 5–11 / 13–31 / ≥37） | 2603 | 1 | 同 858 p=13 |
| size2（2–3 / 5–11 / 13–31 / ≥37） | 2603 | 1 | 同 |
| v=1 vs v≥2 | 2603 | 1 | 858 v≥2 组：2,3,13；margin −0.02224 |
| v odd/even | **2604/2604** | 0 | 858 odd 组 {11,13} 足够 |
| v=1/2/≥3 | 2603 | 1 | 858 v≥3 组 {2,3,13} fail |
| all（全局） | **2604/2604** | 0 | 全局条件全成立 |

## 3. 失败细节与最细可行分组

唯一失败：`858k2`，p=13 singleton：
```
LHS = V_13+gap_13 = 5.899384
RHS = (sF−1)·A_13 = 8.079590
margin = −2.180207 < 0
```
该 p=13 的 v=21（I21）；单独 p=13 失败；但：
- {p=11,p=13} 组合：LHS=11.414543，RHS=8.439275，margin=**+2.975268** ⇒ 成立；
- {p=2,p=3,p=13}：LHS=8.057347，RHS=8.079590，margin=**−0.022243** ⇒ 仍差一点；
- 全局 {2,3,11,13}：margin=+5.133231 ⇒ 成立。

因此 **最细可行分组**：
```
2603 条曲线：singleton_p（每个 p 单独都成立）
858k2：{p=2}, {p=3}, {p=11,p=13}  （3 组；不能拆成 p=11/p=13 单独）
```
对 858k2，p=11 与 p=13 的 **v 都是奇数**，所以 `v odd/even` 分组也自动成立；但 `v≥3` 组 {2,3,13} 不成立（差 0.0222），说明不能只按 v 大小分。

## 4. 阈值结构

- singleton 失败只在 858k2 p13；需要把 p13 与 p11（另一个奇数 v 的 place）合并；
- p13+p2+p3 仍差 −0.02224，因此低 v 的 p2,p3 不足以补偿高 v p13；p11 的 H/gap 是必要的；
- 逐素数（p=13 单独）不成立，但**按 v 奇偶分组 / 全组**成立；最细层级是 3-组划分 `{2},{3},{11,13}`（对 858）；
- 其他 2603 条曲线最细到 singleton 都成立；因此 **最细可行层级 = 单 place，唯一例外 858k2 需合并 (11,13)**。

## 5. 结论

1. c1 模型下分组充分条件几乎全部可行：**单 place 失败仅 1 条**（858k2 p13）；
2. 最细可行分组：2603 条 singleton；858k2 用 `{2},{3},{11,13}`；这比 `v odd/even` 更细；
3. 阈值结构明确：p13 需 p11（同 odd v）补偿，p2/p3 不够；
4. 全局条件全成立（2604/2604）；逐位失败但全局/parity 成功，说明分组可以绕过局部 deficit。
