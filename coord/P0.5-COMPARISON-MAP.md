## 2. 对齐缺口（精确，不新增 named input）

### 2.1 q alignment

目标：`LQRead I place = nativeQReadout T b`。

- 两边都是 `-|log‖q‖|`；需要 q 的**同一对象**。
- 但 `nativeQReadout` 用 `qVFamily T b`（native T 的 clause-B q），`LQRead` 用 `concreteQCandidate I place`（S1391 的 I 侧 q）。
- 现有接口 `C10BridgeProof.NativeOriginalInputDonors (X : N8NativeInput l)` + `nativeOriginalInputOfDonors` 可从 native donors 构造 `OriginalInput`；但 `T` 不是 `N8NativeInput`，且 P0 没有把 `T.arithmetic` 映射到 `I.initial.arithmetic` 的 donor。
- **唯一缺失**：`T → I` 的 source identification（含 arithmetic/Fmod/place 的等价与 `qVFamily = concreteQCandidate` 等式）。

### 2.2 θ alignment

目标：`LThetaRead I place = nativeThetaReadout T b`。

- `LThetaRead` = log(L-carrier tensor Haar region measure)，区域由 `actualC3LogShellTensorRegionL`（C3L 的 tensor placements）。
- `nativeThetaReadout` = log(native tensor Haar region measure)，区域由 `qVFamTensorPlaces/Tuple`。
- 需要 `tensorPlaces/tuple` 等价 + Haar 归一化一致（两者都用 `Measure.addHaar`，但 carrier 不同、区域是否同构需 landing）。
- **唯一缺失**：tensor landing/measure 归一化等式（可由 `actualSourcePilotRegionDataL.tensorLanding` 与 `qVFamTensorBlock` 的显式 homeomorph/linear equiv 给出，尚未构造）。
