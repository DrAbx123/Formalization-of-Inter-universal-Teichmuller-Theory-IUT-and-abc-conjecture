# EXPLORATION-B-B1PRIME — B1′ 设计：高 support / 多变量 / 分步证书族

**Status: DESIGN**（预登记；先判据后计算）。日期：2026-11-12；qpilot（A929）。**无 Lean。**

## 0. 预登记（写在计算前）

B1 结论：只允许 constant / 单变量 `Q_p(T_p)` / 度 1 线性组合时，N≤500 的 941 条半稳定曲线上发现率仅 11.6%，且 found 子集 degree ≈ N^1.47（非 `(log N)^k`）⇒ 停。
B1′ 的**唯一目的**：检验“扩大证书族”能否把发现率恢复到高比例且 degree 回到 `(log N)^k`。

**预登记判据（不得事后修改阈值）**：
1. **小样本门槛**（先做，N≤200，50 条分层：25 条 N<100 + 25 条 100≤N<200）：
   - 发现率 ≥ **80%**（≥40/50）；
   - 且高半区（100≤N<200）发现率 ≥ **60%**（≥15/25）；
   - 且 found 证书的 degree 中位数 ≤ **6**，max prime ≤ **60**；
2. **全量门槛**（仅当小样本通过才做 N≤500 全 941 条）：
   - 发现率 ≥ **80%**；
   - found 证书 degree 对 N 的 log–log 斜率 ≤ **2**（即 degree ≤ `(log N)^2` 量级）；
   - max prime 对 N 的 log–log 斜率 ≤ **2**；系数高度 ≤ `N^2`；
   - 且出现至少一个**不依赖曲线的构造模式**（例如固定 support 模板/固定分步结构）。
3. **判定**：小样本不达 1 ⇒ **停，不进全量**；小样本达 1 但全量不达 2 ⇒ **停**；全量达 2 ⇒ **进 B2**（B2 仍是设计/实验，不是定理）。

## 1. 设计扩展证书族

### 1.1 基本对象
设 `f` 为半稳定曲线对应的权重 2 新形式（有理系数，`a_p(f)∈ℤ`）；`G` 为全部其它新形式（同层新形式 + 真因子的 oldforms，p∤N 时 oldform 的 `T_p` 特征值与底层新形式相同）。
证书是一个整系数 Hecke 多项式
```
P = Σ_{m∈M} c_m · m,   c_m ∈ ℤ,   m = ∏_{p∈S_m} T_p^{e_p(m)}
```
其中 `M` 是选定的单项式集合（Hecke 算子交换；允许幂与乘积）。要求：
- `P(g)=0` 对所有 `g∈G`（用 `a_p(g)` 的乘积/坐标方程）；
- `|P(f)| = r_f`（其中 `r_f = E.congruence_number()`；B0/B1 已核对 `deg φ=r_f`）。

### 1.2 三个扩展层
1. **高 support 线性层**：`M = {T_p : p∈S}`，`|S|` 可到 10–25；用整数核 + 目标方程求 `c_p`；复杂度 `(s=|{c_p≠0}|, d=1, H=max|c_p|, B=max S)`。
2. **多变量/乘积层**：`M` 含 `T_p T_q`、`T_p^2` 等，度 `d≤3`；对 p≠q 用 `T_pT_q = T_{pq}`（Hecke 关系）把高次数乘积化到 `T_n`，控制 max prime；复杂度 `(s, d, H, B)`。
3. **分步证书**：`P = P₂ ∘ P₁`（Hecke 代数中相乘），`P₁` 先杀掉大部分 `G`（例如取 `Q_p`: 在某个 p 上杀掉所有非 f 形式），`P₂` 在剩余局部化代数上处理残余；target 变为 `r_f/P₁(f)`（若整除；否则用 `P₁(f)·P₂(f)=r_f` 的整数组合）。复杂度按 `P₁`、`P₂` 的 support/degree 相加登记。

### 1.3 复杂度度量（每个证书固定登记）
`s`：support（非零系数项数）；`d`：degree（单项式总次数最大）；`H`：height（max |c_m|）；`B`：max prime（出现的最大 Hecke 素数）。
另记 `r_f` 与 `N`，用于散点/拟合。

## 2. 搜索算法（可执行设计）

1. 对每个 (N, curve) 构造 `G`（同层+oldforms），取素数窗口 `P_B`（`B=60`，p∤N）；
2. 按 degree 层 `d=1,2,3` 生成 `M`（d=1 全窗口；d≥2 限制小素数窗口以控制列数）；
3. 对每个 `g∈G` 和每个 `m∈M` 计算 `m(g)`（代数数；用系数域坐标向量转为 ℚ 方程）；对 f 计算整数 `b_m`；
4. 整数线性系统 `A c = 0`, `b·c = r_f`：求整数核（`right_kernel_matrix`），对核基上的 `b` 值做 gcd/扩展 gcd，求整数目标解；
5. 贪心 support 降维（删列后仍可解则删）；对每层选 `(support, degree, H, B)` 字典序最小的证书；
6. 分步：先跑 `P₁=Q_p`（若 `P₁(f)|r_f`），再在残余 forms 上跑层 1–2；合并。
复杂度：列数 `~B^d/d!`，行数 `~|G|·[系数域次数]`；d=2、B=60 约 1–2k 列，整数核/贪心在 Sage 上可行；d=3 需窗口化。

## 3. 小样本可行性（预登记后的实测，非判据前数据）

实现：`tmp/b1p_proto3.sage`（degree≤2 单项式；`P_B` 至 60，degree2 用 primes≤13；同层+oldforms 全约束；整数核 + gcd 目标 + 贪心降 support）。
样本：**50 条分层**（25 条 N<100，25 条 100≤N<200；来自 `coord/b1_curves_500.json`）。
**结果**：
- 总发现 **25/50 = 50%**；
- 低半区（N<100）：25/25 全找到，但**全部是 constant 证书**（这些 level 没有其它新形式/oldforms，`P=r_f` 是最优；degree/support=0）；
- 高半区（100≤N<200）：**0/25**；degree≤2 单项式族找不到任何非平凡证书（`no monomial certificate`）；
- 因此预登记小样本门槛（总 ≥80% 且高半区 ≥60%）**未通过**；
- 机制本身已实现且可构造（整数核求解器、monomial 约束、目标方程都跑通），但 **degree≤2 + B≤60 的族不足以覆盖 N≥100**。

**限制**：prototype 非穷尽：只到 degree 2、未用分步/局部化、未做 index 优化；因此“0/25”不是“低复杂度证书不存在”的证明。但按**预登记判据**，小样本不达门槛即停，不允许事后调参再判有戏。

## 4. 判定与下一步

- **机制可构造性**：✅ 可构造；搜索器与复杂度度量已定义；整数核路线可运行。
- **是否进 B1′ 全量实验**：❌ **不进**。小样本 50%（高半区 0/25）未达预登记 80%（高半区 60%）门槛。
- **B2**：不启（B1′ 未进入全量；更不满足 B2 前置）。
- **若未来重启**（记录，不执行）：需 (a) degree≥3 或分步局部化；(b) 用 Hecke 关系把乘积降 max prime；(c) 对高 N 使用更窄素数窗口/局部化证书；(d) 重新预登记（不得复用本次失败阈值）；
- **试金石**：deferred（本设计无数值→证明桥；不写 Lean，不声称定理）。
