# OUR-ERROR-C — c1 模型下的 N5 误差缺口 C(m)

日期：2026-11-13；qpilot（A1047）。**仅 Python**。c1 e-exact，N≤2000 admissible（ℓ=5, 2604 条）。

## 1. 定义

```
A = Σ_{p>3,p≠ℓ} v_p logp/(2ℓ)
V = arch + H_tame,  gap = Ind2,  T = Σ T_p,  M = V + gap − T
rhs = M − A
N5 缺口 = −A − rhs = −M
N5Weak(C): −A − C ≤ rhs  ⇔  M ≥ −C
最小经验 C(m) = max(0, max_{sample}(−M))
```

## 2. 结果（2604 admissible）

- `M ≥ 5.016 > 0` 对全部 2604 条成立 ⇒ **N5Weak(0) 在 c1 模型中成立**；
- `−A−rhs = −M < 0` 全部成立（负值=满足下界）；
- 拟合 `M ~ m_max`：slope = **+0.114990**，intercept = 14.2158，R² = 0.0100（m 只解释 1% 方差；c1 M 不随 m 下降）。

## 5. 结论

1. 在 c1 e-exact 模型中，**M 全正（min 5.016），N5Weak(0) 成立**；`−A−rhs` 全负（下界满足）；
2. 所需误差常数 **C(m)=0（O(1)）**，不是 O(log m)；误差版在当前 c1 数据上没有非零需求；
3. c1 M 与 m 几乎无关（slope +0.115, R² .01），大 m 样本（858k2 m=21）M 仍 9.64；
4. **但这是 c1 MODEL**：actual C3/theta 的 N5 下界仍未数值化（见 `coord/OUR-N5-NUMERIC.md`）；c1 全正不能替代 actual N5Weak。误差版是否值得做取决于 actual 数据，而不是 c1 proxy。
