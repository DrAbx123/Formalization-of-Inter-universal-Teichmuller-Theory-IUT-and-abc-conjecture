# EXPLORATION-A-REASSESS — C-D-T → abc 桥的独立重审（A976）

日期：2026-11-12。**Status: REASSESSMENT（不预设 STOP）**。源：`tmp/lit/UDC-arxiv-v4.pdf.txt`（arXiv:2109.09040v4）与 `tmp/lit/Holonomy.pdf.txt`（IAS 讲义）。

**判定（先行）：A 线不是“已被 C-D-T 证明为死”，而是“缺某新数学”**——C-D-T 的所有数论输出都是
**定性**的（代数性/自守性/分母有界 ⇒ 同余），没有高度、导子、水平或 `deg φ` 的定量上界；
因此从 C-D-T 到 abc 的桥**不存在于原文**。要接通 abc，需要一个新的定量/有效版本（见 §4）。

## 1. 做了什么

重读 C-D-T 全文（arXiv v4），逐条列出面向数论应用的定理/推论，以及其**输出类型**：

* Thm 1.0.1（UDC 本身）：输入 `f(τ)∈Z[[q^{1/N}]]`、有限指数 `Γ`、权 `k`、emorphic at cusps；
  输出 `f` 是某个**同余子群**的模形式；`N` 任意，**没有** `N`、导子、水平或高度的界。
* Thm 2.0.1 / Cor 2.0.5：输入 `p,x(t),φ,f_i`（整性与全纯）；输出 `f_i` 代数 + 维数上界
  `m ≤ e·∫log⁺|p∘φ|/log|φ′(0)|`；不含高度/导子/水平。
* Prop 3.0.1：输入 `γ_N` 下界与均值界；输出 `dim_{Q(λ)} R_{2N} ≤ C N³ log N`；
  这是**关于输入水平 N 的维数上界**，不是 N 的界，更不是高度界。
* Thm 5.1.4：精确计算 `|F′_N(0)| = γ_N`（Gamma 闭式/ζ 展开）；纯复分析，不含数论高度。
* Thm 6.0.1：对 `p∈{x^N,x^N/(x^N−1),1/(x^N−1)}` 给 `∫_{|z|=r} log⁺|p∘F_N| ≪ logN/(1−r)`；
  纯分析均值界，常数绝对但只含 N,r，不含曲线高度/导子。
* Thm 7.2.1：`f(x)∈Z[[x]]`、`L` 在 `P¹∖{0,1/16,∞}` 无奇异、`x=0` 局部 monodromy 有限 ⇒
  `f` 代数，且 `f(λ(τ)/16)` 对某同余 `Γ(M)` 自守；证明中 `M≡0 mod N`（N 为局部 monodromy 阶），
  **没有 M 的上界**（更没有 M 与 p/高度/导子的关系）。
* Thm 7.3.3：vector-valued 模形式的整系数分量 ⇒ 该分量是经典同余模形式；
  权 `k` 为输入、固定；**同余子群水平未给界**，故不能给 `log N` 上界。
* Remark 6.3.1（数域系数）、Remark 7.2.2（Puiseux）都只扩大适用范围，不增加定量高度内容。

变量是水平 N/权 k，但**没有把 N 或 k 与椭圆曲线的 `h`、导子、`deg φ` 联系起来的定理**。

## 3. 映射 Frey 曲线与 λ：能否逐条满足 + 能否推出不等式

### 3.1 假设的可满足性

取 `x(t) := (λ(q)/16)^{1/N}`，`q=t^N`，`p(x):=x^N`，`φ(z):=16^{-1/N}F_N(rz)`：

* `x(t)∈t+t²Q[[t]]`（Prop 3.0.1 的 (3.0.2)）；`p(x(t))=λ(t^N)/16∈Z[[t]]`；
* `φ(0)=0`，`|φ′(0)| = 16^{-1/N}|F′_N(0)|r`；由 Thm 5.1.4 的 `γ_N` 下界可选 `r` 使 `>1`；
* `f_i` 取 `Γ(2N)` 上权 2 模形式/Hecke 分量（Frey 曲线的新形式、Legendre 周期等），
  `x*f_i∈Z[[t]]⊗Q`（有界分母/尖点宽度条件；必要时乘整数清分母，不改变 `Q(p(x))`-线性无关性）；
  `φ*f_i` 全纯（由 `F_N` 的覆盖性质/Thm 7.2.1 型）。

所以 **Theorem 2.0.1 / Prop 3.0.1 的假设对 `(λ,N)` 是逐条可满足的**——这正是 C-D-T 证明 UDC 的用法。

### 3.2 从 `f_i` 的整性/自守性到 `deg φ,N,h` 的推导尝试

设 `(a,b,c)` 为 abc 三元素，`E_{a,b,c}` 为 Frey 曲线，`N=rad(abc)`（或导子）。
尝试的推导链：

1. 由模性（外部），`E` 对应权 2 新形式 `f`，有整 q-展开；
2. 取 `f_i` 为 `f` 及 Hecke 分量的 `λ/16` 坐标展开；UDC/Thm 7.2.1 会给 `f_i` 代数/同余；
3. **但是**：这些结论只说明 `f_i` 是（已知的）同余模形式，**没有给出** `f` 的系数、`deg φ`、
   `h(E)` 或 `N` 的任何数值关系；
4. 试图用维数上界：Prop 3.0.1 给 `dim R_{2N} ≤ CN³logN`；要变成 `N` 的下界/上界，
   需一个与 abc 三元组关联的**独立函数族下界** `dim ≥ f(a,b,c)`，原文没有；
5. 试图用 Thm 7.2.1 的 `M≡0 mod N`：只给整除关系，无反向上界 `M≤poly(N)`，
   且 `M` 是局部 monodromy 阶，不是曲线导子；
6. 试图用 Thm 7.3.3 的水平/权控制：**没有水平界**，权 k 是输入；不能给 `log N`。

**缺失环节（精确）**：需要一个把 `f_i` 的模形式水平/分母/维数与 `h(E)` 或 `deg φ` 或 `N_E`
联系起来的定量定理；C-D-T 没有这样的定理，其输出对 `(a,b,c)` 的算术不敏感。

### 3.3 Q2 试金石：`3^k−1` 非近似完全幂信息从哪里进入

**答：在 C-D-T 的框架里没有进入点。**

* UDC/Thm 7.2.1/7.3.3 的输入只看到 `f` 的整性、水平 `N`、局部 monodromy 阶和权 `k`；
  `(3^k−1)` 的因子分解/rad 只在选择 `N` 时可能出现，但定理输出不含 `N` 的界；
* 把 `3^k−1` 换成任一同样“整 q-展开 + 有限 monodromy”的整数，C-D-T 的假设/结论不变；
* 因此若要用 C-D-T 推 abc，必须**新加**一条把 `rad(3^k−1)` 编码进 `N/f_i/p(x)` 的构造；
  原文没有，A3 的人工族也没有。

## 4. 判定：A 线缺新数学；下一步或停止

### 4.1 判定

* **不是“死”**：C-D-T 的定理真实，且对 `(λ,N)` 的假设可满足；没有与 abc 矛盾的已知结论。
* **不是“有唯一可行桥”**：原文没有任何高度/导子/水平的定量输出，因此从 C-D-T 到 abc
  的桥**在现有定理里不存在**；仅靠改写 `p,x(t),f_i` 不能凭空产生高度不等式。
* **判定：缺某新数学**——需要一个**定量/有效的 C-D-T 型定理**，例如以下形式之一（仅为目标陈述，未证）：
  1. **有效水平界**：对满足 C-D-T 假设的 `f`，其同余水平 `M` 满足 `M ≤ C(ε) N^{1+ε}`
     或 `M ≤ poly(N)`；
  2. **高度敏感的 holonomicity 界**：把 `m ≤ eI/log|φ′(0)|` 的右端换成含 `h(E)`/`N_E` 的量，
     使 `m` 的维数下界能反推 `h(E) ≤ C log N_E`；
  3. **从非共轭模形式构造 abc 证书**：给定 `(a,b,c)` 显式构造一个非共轭、分母有界的
     模形式，其水平由 `rad(abc)` 控制——C-D-T 只证明这种形式不存在/必同余，没有构造。

### 4.2 试金石回答

* Q1 量词范围：C-D-T 全称定理（所有 `N`/所有满足假设的 `f`），但**不涉及** `3^k−1`；
* Q2：信息**无进入点**（§3.3），因此任何“C-D-T ⇒ abc”的主张目前是 **NO-TOUCHSTONE**；
* Q3 丢失检验：把 `3^k−1` 换成任意整数，C-D-T 输出不变 ⇒ 无法区分；
* Q4：Q2 答不出 ⇒ 不得声称 A 线有桥；但这不是“C-D-T 错”，而是“原文不含所需定量数学”。

### 4.3 下一步/停止

* **A 线暂停**：在找到上述 4.1 中任一定量定理之前，不继续 A3/A2‴ 的数值/Lean 工作；
* 若继续，最小可攻目标是 4.1(1) 的**有效水平界**：它至少能把“同余水平”与 `N` 挂钩；
  但从 `M≤poly(N)` 到 `h≤C log N` 仍需 4.1(2) 的高度敏感界，二者都是新数学；
* **不伪造**：本文件不提出 C-D-T 已推出 abc，也不把 `N`/`M` 的定性关系写成定量不等式；
* 若 Lead 要求继续，应先立项 4.1(1) 或 4.1(2) 的精确陈述与反例/可行性检查（新路线），
