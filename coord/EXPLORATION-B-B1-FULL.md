## 1. 预登记判据（写在全量计算之前，不得事后修改）

样本：`coord/b1_curves_500.json` 中 N≤500 的全部 **941 条半稳定曲线**。对每条按 A970 的修正目标搜索：
- 证书族：`Q_p(T_p)=∏_{g≠f} minpoly(a_p(g))`（g = 同层其它新形式 + 真因子 oldforms；p∤N，p≤60）的整数组合；取 `min |P(f)|`；G=∅ 时 P=1；
- 记录：`|P(f)|`、`C_obs = log|P(f)|/log N`（N>1）、support、degree、max prime。

**有戏（PROMISING）当且仅当三条同时成立**：
1. **整除性**：`r_f^opt | |P(f)|` 对所有样本成立（`r_f^opt` = 同源类最小模次数；squarefree 半稳定时 = newform congruence number，即证书引理中的 r_f）；同时报告用 B0 的 `r_f^curve = E.congruence_number()` 的版本。
2. **C_obs 稳定**：`max C_obs ≤ C0 = 3`，且 C_obs 不随 N 单调增长；给出 CDF 与散点。
3. **高 N 无系统性爆炸**：N∈[300,500] 子样本中 C_obs 的分布不显著高于低 N（max C_obs ≤3 或中位数不随 N 上升）。

**停（STOP）**：任一条不成立。

## 3. 数据与结果

### 3.1 发现率与缺失
- 941 条中 **找到证书 899 条（95.5%）**；**42 条未找到（4.5%）**，原因均为 `no nonzero Qp values`（该曲线的所有 `Q_p(a_f)` 为 0/被跳过；这是当前 Q_p 族的限制，未进一步更换族）。
- 找到的证书类型：`qp_combination` 869、`constant1` 30（G=∅ 的低层）。

### 3.2 判据 1：整除性
- **`r_f^opt | |P(f)|`：899/899 成立**；**`|P(f)| ≥ r_f^opt`：899/899 成立**（与证书引理一致）。
- 用 B0 的 `r_f^curve = E.congruence_number()`：`r_f^curve | |P(f)|` 仅 **768/899**（非最优曲线的模次数大于 newform congruence，故不整除；说明判据应使用 `r_f^opt`，但这一区分必须显式记录）。

### 3.3 判据 2：C_obs
- `C_obs = log|P(f)|/log N`：n=899，**max = 10.025**，median = **1.218**，mean = 1.755；
- **C_obs ≤ 3：767/899（85.3%）**；**C_obs > 3：132/899**；C_obs > 2：264/899；

- **判据 2 失败**（max C_obs=10.03 > 3；且见 §3.4 随 N 增长）。

## 4. 判定与下一步

**判定：停（STOP）。**
1. 判据 2 **失败**：C_obs max = 10.03 > C0=3；仅 85.3% 的 found 证书满足 `|P|≤N³`；
2. 判据 3 **失败**：N∈[300,500] C_obs 明显升高（max=10.03，>3 者 112 条），C_obs 中位数单调增长；
3. 判据 1：主判据 `r_f^opt | |P|` 899/899 成立，但 42 条未找到证书；若用 literal `r_f^curve` 则仅 768/899，不能全样本成立；
4. 拟合斜率 ≈5.89（全部）/6.79（非 constant），远大于 3；`absP` 随 N 多项式（甚至更快）增长。
