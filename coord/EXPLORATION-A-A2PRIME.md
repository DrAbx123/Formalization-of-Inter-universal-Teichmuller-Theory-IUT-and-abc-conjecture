## 1. 做了什么

### 1.1 目标（A2′ 与 A2 的区别）

A3 的 F4 族 `p(x)=c x^N−a` 只把三元组当系数，`I_N=∫log⁺|cβ^N−a|` 里只有 `log c`，没有 `log rad(abc)`；所以 `cost(m)` 线性、无 abc 增益。A2′ 要构造 p/覆盖，使：

* `I_N` 中出现 `log c − log rad(abc)`（或至少 `log c − Σ_{p|abc} e_p log p`）的差；
* 坏素数处的 p 进半径 `R_p` 携带 `v_p(abc)`（不是只 `≥1`）；
* 从而 Theorem 2.0.1 的 `m ≤ e I_N/log|φ′(0)|` 能化成 `log c ≤ C log rad + sublinear`。

### 1.2 候选构造（显式）

记 `b=3^k−1`，`c=3^k`，`S=primes(b)∪{3}`，`β(z)=4z/(1+z)^2`，`r=3/4`，`φ(z)=β(rz)`，`|φ′(0)|=3`。

**C1（因子嵌入多项式）**：`p(x) := rad(b)·(x^N − 1)`，`x(t) := λ(t)/16`，`f_i(x) := x^i`（`i=0,…,N−1`），`m=N=⌊log c/log3⌋`。

**C2（非平凡 `x(t)` 吸收 rad）**：`x(t) := t·∏_{p∈S}(1 − t/p)^{e_p}`（有限乘积；无限版见 §2.2），`p(x) := M·x`（清分母）或 `p(x)=x^N`；`f_i=x^i`。

### 2.1 C1 的精确核对（Theorem 2.0.1）

* `p(x)=rad(b)(x^N−1) ∈ Q(x)∖Q`，`x=0` 无极点；`p(x(t))∈Z[[t]]`（因 `λ/16∈Z[[t]]`）；
* `φ*p=rad(b)(β(rz)^N−1)∈O(D)`（β 极点在 `z=−1/r`，闭盘外）；
* `x*f_i=(λ/16)^i∈Z[[t]]`；`φ*f_i=β(rz)^i∈O(D)`；`R=Z`；
* 结论：假设全满足，但 `I_N = ∫log⁺|rad(b)(β(rz)^N−1)|` 中 `rad(b)` 只给 `O(log rad)` 加性项：当 `|β(rz)|^N` 不大时 `≈ log rad(b)`；当它很大时 `≈ N log|β|+log rad(b)`。无 `log c−log rad` 差分结构。
* `m=N`，上界 `B_N=e I_N/log3`；`B_N−m` 仍 ∝ k（A3 F4 的线性 cost），`rad(b)` 只改常数/低阶项 ⇒ 无 abc 比较。

### 2.2 C2 的精确核对（整性负判定）

* 有限乘积 `x(t)=t∏_{p∈S}(1−t/p)^{e_p}` 是**多项式**（系数分母为 `∏p^{e_p}` 的有界幂）；清分母需 `p(x)=M·x`，于是 `Q(p(x))=Q(x)`，`m=1`；且 `p(x(t))` 是多项式 ⇒ p 进半径 `∞`（平凡），不携带 `v_p(rad)`。
* 无限乘积 `x(t)=t∏_{p∈S}(1−t/p)^{-e_p}`：`[t^n]x(t)` 分母含 `p^{n}` 型因子；对任意固定非零 `p∈Q[x]`，`p(x(t))` 的 `t^n` 系数在 `p|rad(b)` 处分母无界，**不属于 `Z[[t]]`**；Theorem 2.0.1 的 `p(x(t))∈Z[[t]]` 失败。
* 因此 C2 无合法实例：有限版退化为 `m=1`/平凡半径，无限版违反整性。

## 4. 停止原因与下一步

**停因（精确）**：
1. C1 仅把 `rad(b)` 作为 `p` 的乘法系数，`I_N` 中只有 `O(log rad)` 加性项；没有 `log c−log rad` 差结构，`cost(m)` 仍线性；
2. C2 有限乘积是多项式（`m=1`/p 进半径平凡），无限乘积违反 `p(x(t))∈Z[[t]]`；两种情形都不满足 Theorem 2.0.1 或不能产生 m；
3. Q2 明确“信息未进入 `I_N`/上界” ⇒ **STOP-NO-TOUCHSTONE**；未做 k=2,3 探针（按规则“答不出不许数值化”）。

**下一步**：A2′ 停；若路线 A 继续，需要真正的新机制：把 `rad(abc)` 的因子结构变成 **p 进半径 >1**（不是系数乘法），例如构造 `x(t)` 使 `p(x(t))` 的系数在 p 处有增长型分母，同时被 `p` 的系数按 `v_p` 精确清除；这要求对每个 p 解 p 进整除/分母平衡方程，且不能退化为多项式。这属于新的 A0′/A2″ 设计，需新的预登记；本文件不伪装成已解决。
