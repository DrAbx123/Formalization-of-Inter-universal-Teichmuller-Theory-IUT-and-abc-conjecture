## 1. 做了什么

### 1.1 映射定义（F4 数值族；F1/F2/F3 符号评估）

对每个三元组 `(a,b,c)`（`a+b=c`, `gcd=1`）：

* `p(x) := c·x^N − a ∈ Q(x)∖Q`（`x=0` 无极点，`p(0)=−a`）；
* `x(t) := t ∈ t + t²Q[[t]]`，`p(x(t)) = c t^N − a ∈ Z[[t]]`；
* `β(z) := 4z/(1+z)^2`（Belyi，`β(0)=0`, `β′(0)=4`，系数全整数）；
* `φ(z) := β(r z)`，取 `r=3/4`，故 `φ(0)=0`，`|φ′(0)|=4r=3>1`；β 的极点在 `z=−1/r=−4/3`
  （闭单位盘外），所以 `φ*p = c β(rz)^N − a ∈ O(D(0,1))`；
* `f_i(x) := x^i`，`i=0,…,N−1`；`m=N`；`Q(p(x)) = Q(x^N)`；
* `S := primes(a·b·c)`（坏素数集；对 F4 的实际 p 进半径无影响，见 §1.3）。

**Theorem 2.0.1 假设逐条核对**：

| 假设 | 核对 |
|---|---|
| `p∈Q(x)∖Q`, `x=0` 无极点 | ✓ `p=c x^N−a` |
| `x(t)∈t+t²Q[[t]]`, `p(x(t))∈Z[[t]]` | ✓ `x=t`, `c t^N−a` |
| `φ(0)=0`, `|φ′(0)|>1`, `φ*p∈O(D)` | ✓ `4r=3>1`；β 极点在 `|z|>1` |
| `x*f_i∈Z[[t]]` | ✓ `t^i` |
| `φ*f_i∈O(D)` | ✓ `β(rz)^i` 在闭盘邻域全纯 |
| 分母类型 `R=Z` | ✓ F4 全整数，无 `Z[1/N]` |
| 同一整体坐标 | ✓ 所有半径在 `t`/`z` 固定坐标下算，`φ=β(rz)` 固定 |

（F1 Legendre 缩放、F2 代数分支、F3 乘积/导数只做符号评估，不进入数值表：F1 半径积 ≤1；
F2 分母损失使 `R=Z` 失效；F3 无超乘性增益。）

### 1.2 `m` 选择规则与线性无关性

* 构造：`f_i=x^i`，`i=0,…,N−1`；`N=⌊log c/log3⌋`（对 `(1,3^k−1,3^k)` 即 `N=k`）；
* `Q(p(x))=Q(x^N)`；`1,x,…,x^{N−1}` 是 `Q(x^N)`-基（按 `x^i` 的指数模 `N` 归约，
  次数 `<N` 的多项式唯一），故 `m=N`；无重复/无相关函数；
* `m_max=N`（该构造上限）；与 Theorem 上界比较见 §2。

### 1.3 半径之积口径

* p 进：`R_p(g)=1/limsup_n |[t^n]g|_p^{1/n}`；F4 的 `g_i=f_i(x(t))=t^i∈Z[[t]]`，
  所有有限 p 的 `R_p≥1`（实际 `∞`，因只有单项；保守取 `=1`）；
* 无穷位：`R_∞^φ(f∘x)` 用共形因子 `|φ′(0)|=3`（A0 E4：Belyi 的共形半径；β′(0)=4，r=3/4）；
* `𝓡_S(f,x,φ) := R_∞^φ(f∘x) · ∏_{p∈S} R_p(f∘x) = 3 · ∏_{p∈S} 1 = 3 > 1`；
* 口径约束：同一 `(t,z)` 坐标；`x*f∈Z[[t]]` 与 `φ*f∈O(D)` 给出的 `R≥1` 只是必要条件，
  未在有利侧重复乘 overconvergence；`r` 固定 `3/4`，不随三元组调参；
* 数值精度：I_N 用 20000 点中点黎曼和（Python 3.13, sympy 1.14, 脚本 `tmp/lit/a3_3k.py` /
  `a3_triples.py`，输出 `tmp/lit/a3_3k.out` / `a3_triples.out`）；**数值非严格证明**。

### 1.4 `cost(m)` 定义

`B_N := e·I_N/log|φ′(0)|`（`e=2.718…`, `I_N=∫_0^1 log⁺|c β(re^{2πiθ})^N − a| dθ`），

    `cost(m) := (B_N − m) + cost_denom(m) + cost_cover(m)`

* `cost_denom(m)`：分母类型损失（`R=Z[1/N]` 的 p|m/阶乘分母等）；F4 = 0；
* `cost_cover(m)`：覆盖分歧/次数损失；F4 的 β 系数全整数、次数 2 已吸收在 `I_N`，记 0；
* 实测 F4：`cost(m)=B_N−m ≈4.44m`（3^k 表）；这是随 k 线性增长的损失。

## 3. 与判定条件的对照

### 3.1 预登记判据（A3 前写入，未事后改）

* **PASS**：至少一族得到 `log c ≤ C·log rad + cost(m)`，`cost(m)` 不随 k 线性增长，
  且 `𝓡_S>1` 在所有样本成立；
* **STOP**：`cost(m)` 总是吃掉全部增益（如 `cost(m)≥(1−o(1))k log3`）、或 `𝓡_S≤1`、
  或 `m` 总 ≤ Theorem 2.0.1 上界；
* **PARTIAL**：只有 F4 常数不等式 `1≤e·I_1/log4` 而无 abc 增益。

### 3.2 实测对照

* F4：`𝓡_S=3>1` ✓；`m=N` 始终 ≤ `B_N`，且 `B_N/m` 在 k≥2 后稳定在 **5.43656**
  （表：k=2 起 5.3828→5.43656）；`cost=B−m≈4.4366m` ⇒ **随 k 线性**；
* 20 个高质量三元组：`B/m` 在 5.4–5.7 之间，`cost` 同样是 `(B/m−1)m`，随 `m` 线性；
* F1：`𝓡_S≤|φ′(0)|/16≤1`（Belyi max 16），符号上不可能 >1；
* F2：`R=Z[1/N]` 的分母损失使 `cost_denom(m)` 含 `Σ_{p|m}...`，随 m 增长，吃掉 `|φ′(0)|` 增益；
* F3：无超乘性，`≤max` 因子，不优于 F1/F2。

### 3.3 试金石四问（§12.5）

1. **量词范围**：家族 `(1,3^k−1,3^k)` 的 k=1..60，加 20 个 c≤20000 的三元组，
   条件为 F4 的固定参数 `r=3/4`, `N=⌊log c/log3⌋`, `m=N`；不声称对一般三元组全称。
2. **`3^k−1` 不是近似完全幂的信息从哪一步进入**：**没有进入**。F4 的构造只用 `(a,c)` 定义
   `p(x)=c x^N−a`；`3^k−1` 的因子/rad 只用于表的 `q` 列与样本筛选，不进入半径积、`I_N`、
   定理上界或 `m`。
3. **丢失检验**：去掉该信息后，F4 的构造/数值完全不变；本实验不产生比 `m≤B` 更弱的 abc 主张，
   所以没有“退化陈述”可写。
4. **Q2/Q3 答不出？** Q2 明确答“未使用”，Q3 明确“无退化” ⇒ 按 §12.5，**任何正面的 abc 主张
   都是 STOP-NO-TOUCHSTONE**；本 A3 不提出正面主张，只登记负结果 STOP。

### 3.4 结论

* F4 是唯一 `𝓡_S>1` 且逐条匹配 Theorem 2.0.1 的族，但它的上界只给出
  `m ≤ e I_N/log3`，实测 `B/m≈5.44`，即 `m` 始终远低于上界；**没有 abc 不等式**；
* 不能从它推出 `log c ≤ C·log rad + cost(m)`（`cost` 线性、且无 `log rad` 项）；
* F1/F2/F3 分别因半径积 ≤1 或分母代价失败；
* **判定：STOP（全部候选族）**；不是 PARTIAL，因为 F4 连常数不等式之外的增益都没有。

## 4. 停止原因与下一步

**精确停因**：
1. F4 的 `m=N` 与 Theorem 上界 `B_N` 满足 `B_N/m→5.43656`（k≥2），`cost(m)=B_N−m≈4.4366m`
   随 k 线性；Theorem 2.0.1 不含任何 `log rad` 项，无法转成 `log c ≤ C log rad + sublinear`；
2. F1 的 `𝓡_S≤|φ′(0)|/16≤1`（Belyi max 16），半径积不能严格 >1；
3. F2 的 `R=Z[1/N]` 分母损失计入 `cost_denom(m)` 后随 m 增长；F3 无增益；
4. 试金石 Q2 明确：本实验路线没有使用 `3^k−1` 的“非近似完全幂”信息 ⇒ 不能声称触及 abc 的硬点。
