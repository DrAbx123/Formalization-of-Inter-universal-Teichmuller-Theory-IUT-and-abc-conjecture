## 0. 把缺口写成一条算术不等式

- `sFactor n = (n+1)(2n+1)/6`；n = (l−1)/2 时 s = l(l+1)/12。A = `absLogQ` = log q /(2l)。

## 1. q 侧系数 κ：随便放，不是瓶颈

`SSIneq_κ : (s − κ)·A ≤ V`，κ 越大越弱。代入 V 的上界得 (1/6)·(1 − 12κ/(l(l+1)))·log q ≤ B。
κ 取任意常数乃至 o(l²)，结论不变；κ = θ·l(l+1)/12（θ<1）给指数 6/(1−θ) 的弱形式。
所以 q 侧是 1 还是 0.545 不影响结果，A760 的归一化桥不是瓶颈。

## 6. 困难点上的具体想法

### 6.1 log-shell 体积有精确公式，不需要 a_v、b_v 估计

log 在 O^× 上的核是全部单位根；对大 N，log 把 1+m^N 保测地映到 m^N。数指数得
vol(log O^×) = 1/(q_k·p^r)，其中 q_k = p^f 是剩余域大小，p^r 是域内 p 幂单位根的个数。于是

  μ(𝓘_v) = (1 + [p=2] − 1/e − r/n)·log p （按 n = [k:ℚ_p] 归一）。

检验：非分歧奇素数给 0；温和分歧给 1 − 1/e = d；ℚ_p(ζ_p) 给 (p−3)/(p−1)，与直接计算
log(O^×) = m² 一致。无壳一侧因此完全是闭式，IUT IV Prop 1.2 的两侧包含只在算壳时才需要。

### 6.2 壳的精确指数，以及它给出的"理论真实预言"

- 记 p^{−h_v}·O 为包含 𝓘_v 的最小分式理想。温和且 p > e+1 时 h_v = 1 − 1/e。
- p ≤ e+1 的坏素数（即小于约 l 的坏素数）处 log 不再把 1+m 映进 m，h_v ≈ 1 + log l / log p。
  每个这样的素数给 D 多贡献一个 log l。体积（无壳）看不到这一项，壳看得到。
- l 上方的位：h ∈ [1 − 2/(l−1), 约 2]，贡献 δ_l·log l。
- 于是 D_exact ≈ log f + (ω_{<l}(N) + δ_l)·log l + C₀，其中 ω_{<l}(N) 是小于约 l 的坏素数个数，
  C₀ 来自 2、3、5 和无穷位，是绝对常数。

若 3.12 对精确壳成立，则对每个可用的 l：

  (1/6)·log q ≤ (1 + O(1/l))·[log f + (ω_{<l}(N) + δ_l)·log l + C₀]。

这比论文 Thm 1.10 的 20·d*·l 尖得多，而且形状有意义：
- 取 l ≈ log f：误差约 (ω + 2)·log log f，即 c ≲ rad·(log rad)^{ω+2}，与 Baker 的显式猜想
  c < (6/5)·N·(log N)^ω/ω! 同形。
- 取 l ≈ √(log f)：误差 O(√log f)，与 Stewart–Tijdeman、van Frankenhuijsen 的下界
  6.07·√(log c)/log log c 相容，只差 √(log log) 量级。
- 论文里线性于 l 的误差项来自"小坏素数处 shell 变大"，而已知的极端三元组正是由大量小素数
  构成的。两者对得上，说明精确壳版本与全部已知极端例子相容。

用途：这是一个数值检验台。把 van Frankenhuijsen 的显式好三元组族代入上式，对所有可用 l 都违反
即反驳精确壳版本；我预计是相容的，所以它不会给出证明，只会排除错误的归一化。

### 6.3 逐 capsule、逐素数看：包含式 N3 可以被显式小例子反驳

- capsule j 的墙：(j² − 1)·A ≤ V_j，V_j ≈ (j+1)·D，等价于 (j − 1)·σ ≤ 2l。
- j = 1 时恒真：Θ-pilot 在 j = 1 的值就是 q-pilot 的生成元。
- 分界点 j₀ = 1 + 2l/σ。σ = 6 时 j₀ ≈ l/3：前三分之一的 capsule 有盈余，后面的有亏空，
  均匀平均后刚好在 6 处打平。常数 6 = 2l·avg(j+1)/avg(j²) 来自均匀平均。
- 顶层 capsule 的墙要求 σ ≤ 4l/(l−3)，即常数 4。Masser 已证 6 最优，所以顶层墙对无穷多曲线为假。

包含是逐 capsule、逐素数的，所以比平均体积强得多。在坏素数 p > l 处，顶层 capsule 的包含要求

  ord_p(q) ≤ 4l(l+3)/((l+1)(l−3))，即 l=7 时 ≤ 8，l=11 时 ≤ 6，l 大时 ≤ 4。

Frey 曲线有 ord_p(q) = 2·v_p(abc)。显式反例：
- l = 11：三元组 (1, 13⁴ − 1, 13⁴)，ord_13(q) = 8 > 6.4。
- l = 7：三元组 (1, 11⁵ − 1, 11⁵)，ord_11(q) = 10 > 8.75。

结论：qpilot+shehdd 线若把 N3 写成"q-pilot 的像包含于 Θ 壳"，在忠实模型里是假的，
可以直接证它的否定。N3 唯一可能为真的形式是 procession 平均后的体积不等式，而那就是第 0 节的算术不等式。
（需核对：所选 l 对该曲线是否满足 Θ-data 的条件。）

### 6.4 对每个 D，l 充分大时墙是真的

V 含 l 上方各位的贡献 ((l+5)/4)·h_l·log l，h_l ≥ 1 − 2/(l−1)，权重和为 1。
所以只要 6·(1 − 2/(l−1))·log l ≥ log q·(l+1)/(l+5)，即 l ≳ q^{1/6}，`SSIneq(D,l)` 成立。

- 这是关于真实陈述、真实数据的可证正面定理，证明只用 ℚ_l(ζ_l) ⊆ K_v 这一个事实。
- 它不给出新的算术结论：内容只在 log l = o(log f) 的区间，论文取 l ≈ √(log q) 正在其中。
- 整个缺口可以重述为一个整数不变量：使墙成立的最小可用 l。平凡界是 q^{1/6}；
  把指数 1/6 降到任何更小的数就已经是弱 Szpiro。

### 6.5 两个定义开关，各自让墙平凡成立并让上界失效

- 标签塌缩：若 capsule j 里 Θ 的值允许取 q^{t²}（t ≤ j）而不是固定为 q^{j²}，则每个 capsule
  的壳都含 q·packet，墙平凡成立，上界里的 −s·A 消失。
- 平均改最大：若对 capsule 取最大而不是均匀平均，j = 1 一项就让墙成立。

3.12 的内容恰好是"值由 capsule 大小钉死"加"均匀平均"。任何声称证出墙的共享容器形式化，
先查它是否悄悄拨了这两个开关之一。lana 的 `thetaComponentOn`（`ThetaRegion.lean:170`）里
并集只取位置、指数固定为 (i+1)²，属于未拨开关的一侧。

### 6.6 与 Hodge–Arakelov 比较定理的对应（推测，未核对）

capsule j 对应 Hodge 滤过的第 j 步：(j+1)·D 像第 j 阶导数那一块的次数，j²·A 像 theta 值的次数。
墙的形状就是"比较映射整体次数亏量非负"。概形论的比较定理是已证的，并且把亏量精确算成
Gaussian 极点加无穷位的项。若 lana 的 Arakelov 层（logVol = −平均 degNorm）能表达这个行列式，
`SSIneq` 的亏量会变成一个显式的无穷位量。我对这条的把握很低，只作为方向。

## 9. 论文的 3.12 本身：重新推了一遍之后（纸面推导）

**它是什么。** 假设存在"整体乘性子空间"：M ⊂ E[l]，在所有坏位上都是乘性线 μ_l。那么
- E/M 在每个坏位的 q 变成 q^l，高度的 q 部分乘以 l；
- 同源曲线的 Faltings 高度至多差 (1/2)·log l（Raynaud 公式）。

两条合起来得 (l−1)·log q ≤ 6·log l，高度被压死。作者 2026 年 4 月报告里的原话
"高度等于 N 倍高度，至多差一个小偏差"说的就是这个结构。`SSIneq` 是同一形状：
(l+1)·log q ≤ 6·(l+5)·(log d + log f)。常数 6 相同，偏差由 log l 换成 (l+5)·(log d + log f)。

**为什么已知的整体工具给不出它。** 在 K = F(E[l]) 上每个 M 都有理，但对每个坏位 v_F：
- M 只在 v_F 上方 1/(l+1) 的位上是乘性的，在那里 q ↦ q^l，增益 (l−1)·ord；
- 在其余 l/(l+1) 的位上是 étale 的，在那里 q ↦ q^{1/l}，损失 ((l−1)/l)·ord。

加权和：(1/(l+1))·(l−1) − (l/(l+1))·((l−1)/l) = 0，精确抵消。换到 Borel 不动域 F_M 上一样：
乘性位局部次数 1，étale 位完全分歧次数 l，权重 1 : l，仍然是 0。在 X_0(l) 上这等价于
[∞] − [0] 是挠除子类（Manin–Drinfeld），所以两个尖点高度只差 O(log l)。

结论：任何对全体位求和、Galois 对称的高度论证，在这里只能得到 0 = 0。

**缺的那条引理的精确形状。** 取截面 V（每个 v_F 上方选一个位，使 M 在其上乘性）。需要一个量 h_V 满足
1. h_V(E) = (1/12)·log q；
2. h_V(E/M) = l·h_V(E)；
3. h_V(E/M) − h_V(E) ≤ 约 (l/2)·(log d + log f)。

1、2 是定义，3 是全部内容。它要求"只数 V 上的位"的量仍然满足同源不变性，代价只是 different 量级。
Raynaud 公式、Autissier 的 Hecke 平均公式、高度机器都只对全体位求和的高度成立；
截到 V 上就没有乘积公式。IUT 声称用 Θ-link 加不定性模拟出第 3 条，这正是 LANA 报告说无法按原文形式化的那一步。

## 11. 继续用 IUT、再接一个别的理论：我认为最自然的组合

**先回答"有没有 IUT 是不是一样"。不一样。** IUT 已验证的部分给了三样东西，证明不等式时都用得上：
1. 整条下游链：`SSIneq` ⟹ variant ⟹ ABC（IUT IV 的体积计算加 GenEll/Belyi 归约），这是真的、已验证的数学。
2. 不等式的精确形式，并且 l 是自由参数，每条曲线只需对一个合适的 l 成立。
3. 一个重述：右边的 D = log d_K + log f 只依赖模 l Galois 表示 ρ̄_{E,l}（K 是 ker ρ̄ 的不动域，
   log f 是 ρ̄ 的 Artin 导子），左边的高度不由 ρ̄ 决定。所以

   **`SSIneq(E,l)` ⟺ 高度(E) ≤ (1+O(1/l))·D(ρ̄_{E,l}) + O(log l)，前提是 l 不整除任何 ord_p(q)。**

   即"曲线的高度被它的模 l 表示的导子和 different 控制"。这把问题从经典 Szpiro 的世界
   搬到了模 l 表示与同余的世界，别的理论正是接在这里。

**最自然的搭档：模性方法（Frey–Serre–Ribet–Mazur，以及 Pasten 的 Shimura 曲线版本）。**

- 机制：若 l | ord_p(Δ)（p ∥ N，ρ̄ 不可约），则 ρ̄_{E,l} 在 p 处非分歧，Ribet 降层给出
  级为 N/p 的新形式 g ≡ f (mod l)。低层没有这样的形式，就矛盾，于是 l ∤ ord_p(Δ)。
- 这正是"高度被 ρ̄ 的导子控制"的一个已证实例：
  **素导子情形。** Mestre–Oesterlé 加模性定理：导子为素数 p > 37 的椭圆曲线，|Δ| = p 或 p²；
  全体素导子曲线的 Szpiro 比 ≤ 5。配上第 2 节的精确阈值（≥ 6），得到
  **`paperGap` 对所有素导子椭圆曲线成立**。这一类不是用结论定义的，是一条真正的纵向定理。
- 两边正好互补：IUT 要求 l 不整除任何指数（ρ̄ 满导子，没有降层）；模性方法处理的恰是
  l 整除某个指数的情形（有降层同余）。对每个素数 l，二者必居其一。
- 一般导子时，降层只给出：整除某个指数的素数 l 满足 l ≤ exp(c·N_T·log N)，
  N_T 是指数不被 l 整除的那些坏素数之积。这是指数级的界，也是 Murty–Pasten、Pasten 目前所在的前沿。
  Ribet–Takahashi 把 ∏ ord_p(Δ) 表成两条参数化的次数比，是把它压到多项式级的现有抓手。

**组合路线怎么落到仓库里（三步）。**
1. 形式化第 3 点的重述：把 D 写成 ρ̄_{E,l} 的不变量，把 `SSIneq` 写成"高度 ≤ D(ρ̄)"。

把握：第 1、2 步约 70%（第 2 步依赖外部定理，不是在仓库内重证）；第 3 步达到全称命题约 2%。

## 12. 第 11 节路线的细节（引理清单、常数、做法）

### 12.1 第 1 步：把 `SSIneq` 写成"高度 ≤ Φ(K, l)"

在 lana 的记号下，逐条要证的引理（都是局部计算，不含开放内容）：

- **L1 shell 体积。** 对位 w（剩余特征 p，分歧指数 e，局部次数 n，域内 p 幂单位根 p^r 个）：
  μ(𝓘_w) = (1 + [p=2] − 1/e − r/n)·log p。证法：log 的核是单位根群，对大 N 有 log(1+m^N) = m^N，数指数。
- **L2 壳指数。** h_w := 使 𝓘_w ⊆ p^{−c}·O_w 的最小 c。温和且 p > e+1 时 h_w = 1 − 1/e，
  此时 𝓘_w 就是逆 different。一般情形 h_w = 1 + [p=2] − min_u ord_p(log u)。
- **L3 张量包。** capsule j 的 j+1 个因子落在位 w_0…w_j 上时，
  hull(⊗𝓘) = p^{−Σ h_{w_i}}·M，M 是 ⊗K_{w_i} 的极大序；分量归一下 μ(hull) = Σ_i h_{w_i}·log p。
- **L4 procession 平均。** l* = (l−1)/2。avg_j(j+1) = (l+5)/4；avg_j(j²) = l(l+1)/12。
- **L5 组装。** V = ((l+5)/4)·D_exact，D_exact := Σ_w（权重）·h_w·log p_w + 无穷位项。
  lana 的 identified-copies 模型里 LGP 律是精确的（`IdentifiedCopies.lean:281,444`），所以这里没有取整项。
- **L6 等价。** (l(l+1)/12 − 1) = (l+4)(l−3)/12，于是
  `SSIneq D` ⟺ logQ ≤ T(l)·D_exact，**T(l) = 6·l(l+5)/((l+4)(l−3))**。
- **L7 只依赖 ρ̄。** V 只依赖 (K, 截面, l)。当 l 不整除任何 ord_v(q) 时，坏位处 K_w/F_v 温和分歧、指数含因子 l，
  D_exact = (1 − 1/(e_F·l))·log f + δ_l·log l + C₀，其中 δ_l ∈ [1 − 2/(l−1), 约 2]，C₀ 是 2、3、5 与无穷位的固定贡献。

### 12.2 第 2 步：素导子类上的无条件定理

**陈述。** E/ℚ 导子为素数 p，l ≥ 11 为素数且 l ≠ p。则对应的 Θ-data 满足 `SSIneq`。

**为什么成立（数值余量）。**
- 外部定理给 e_p := ord_p(Δ_min) ≤ 5（p > 37 时 ≤ 2）。
- logQ = e_p·log p（归一化 q 次数在基变换下不变）。
- D_exact ≥ (1 − 1/l)·log p（只取 p 上方各位的贡献）。
- 需要 e_p ≤ T(l)·(1 − 1/l) = 6(l+5)(l−1)/((l+4)(l−3))。l = 11 时右边是 8，l = 13 时 7.62，l→∞ 时趋于 6。
  恒大于 5，余量充足。p > 37 时连无壳版本 `SSIneqNoHull`（阈值约 3）也成立。

**Θ-data 合法性。** l ∤ e_p（e_p ≤ 5 < 11）；半稳定曲线 l ≥ 11 时 ρ̄ 满射（Mazur），
基域含 E[30] 后像仍含 SL₂(𝔽_l)（l ≥ 7 时 PSL₂(𝔽_l) 不是 GL₂(ℤ/30) 子群的商）。

**外部定理清单。** 模性定理（Wiles、Taylor–Wiles、BCDT）；Ribet 降层；Mazur 的挠点与同源定理；
Mestre–Oesterlé 1989（素导子时 |Δ| = p 或 p²，例外 p = 11、17、19、37）。

**Lean 里的做法。** 外部定理写成一条明确的 Prop `MestreOesterleBound`（"素导子 ⟹ e_p ≤ 5"），

`paperGap_of_primeConductor (hMO : MestreOesterleBound) … : SSIneq D`。报告里把它与 class-B 缺口分开列：
它是已发表定理，不是待证猜想。

### 12.3 第 3 步：一般导子，具体怎么攻

**出发点：指数是两个同余数之比。** 设 N = p·M 无平方因子，f 是 E 的新形式，δ 是模参数化次数。
- 在 p 处的特征群 X_p(J₀(N)) 是超奇异点模（Brandt 模），带权单模配对。
- 最优商 π: J₀(N) → E 把 X_p(E) ≅ ℤ 的生成元拉回成向量 v_{E,p}，且 **⟨v_{E,p}, v_{E,p}⟩ = δ·e_p**
  （因为 π∘π^∨ = [δ]，Tate 曲线上生成元的自配对是 ord_p(q)）。
- 所以 e_p = （f 在 Brandt 格里的同余数）/（f 在同调格里的同余数），至多差 Eisenstein 素数处的有界指标。

目标因此是：证明同一个 Hecke 本征线在这两个整结构里的同余数几乎相等，比值 ≤ 6·log N / log p。
素导子时这已是定理（比值 ≤ 5），证明用的是"级 1 没有尖形式"。

**三条具体的线。**

(a) **素导子定理的组合版本（先做，可计算）。**
- 计算：对导子 < 10⁵ 的素导子曲线，从 Brandt 矩阵算本原整本征向量 v，验证 ‖v‖² = δ·e_p。

  离域性；要找的是它对"本原整向量的范数"的推论。
- 否决条件：数据显示 ‖v‖²/δ 的小只能由降层解释、与图的任何可计算不变量无关。

(b) **ω(N) = 2 的第一个未知情形：导子 2p。**
- 在 p 处降层落到级 2，没有尖形式，所以 e_p 没有 ≥ 11 的素因子；剩下 2、3、5、7 部分按 Mestre–Oesterlé 的办法处理。
- 真正的未知量是 e_2。此时 c₄³ − c₆² = ±2^{e_2+6}·3³·p^{e_p}，是只有一个自由指数的 Mordell 型方程；
  Baker 方法给 e_2 ≤ exp(c·p^{1+ε})，需要的是 e_2 ≤ C·log p。这与 Hall 猜想同强度。

(c) **Shimura 曲线上的次数界（Pasten 的前沿）。**

- 所以剩下的是：无级结构 Shimura 曲线的参数化次数 δ_{N,1} ≪ N^{2+ε}。
- 等价的可算形式：Néron 周期格的余体积 ≥ N^{−1−ε}（deg φ = 4π²‖f‖²/(c²·vol(E))，‖f‖² = N^{1+o(1)}）。

  看 capsule 的权重（j² 对 j+1）能否对应到他的高度比较里的某一步。我没有读过 2026 年那篇的正文。

**已有的定量事实（可直接用）。** 若 l ≥ 11 整除 e_r（r ∥ N），降层得到级 N_l 的新形式 g，
且升层条件给 l | Norm((r+1)² − a_r(g)²)，所以 l ≤ (√r + 1)^{4·[ℚ(g):ℚ]}。
g 有理（即对应一条椭圆曲线）时就是 l ≤ (√r+1)⁴，多项式界；指数级损失全部来自 g 的系数域次数。

| sQ3 取壳 + det | `leastHull`、`exists_ind3_logVol_iff` | 加 t，t 取遍 (−∞, V] |
| sQ4 竖直移位 | 已含在 (Ind3) 里 | 不再增加 |

绕一圈的结果是 −s·A + t。闭环闭合 ⟺ 存在可取的 t 使 −s·A + t = −A ⟺ (s−1)·A ≤ V。
这就是 lana 已绿的 `xi_iff_ss`。

**结论。** 沿论文的链走，得到的是同一个命题，不是它的推导。论文在 (xi-e)→(xi-f) 和 3.9.5 (ix)
把"闭环闭合"当作重言式；而仓库里各段已验证的作用合起来给出的偏差是 (s−1)·A − t，不是 0。
`NonDerivable.lean` 是"仅凭这些段的性质推不出闭合"的机器证明。我没有找到绕过它的链。

**如果作者的说法成立，必有某一段的形式化与论文不一致。可核对的只有两处。**
- Θ-link 对次数的作用是否确为乘 s。对照 IUTchIII Def 3.8、Remark 3.6.2 (i)，以及 (xi-a) 的
  "Θ-pilot 对象对应 q-pilot 对象"。
- 两列的体积读数在共享容器上是否确实相容（偏差为 0）。对照 Prop 3.9 (iii)、Remark 3.12.2 (iv)(v)。

第三种可能已被原文排除：(Ob4-2) 的张量幂扭转不定性，论文自己说对对数体积"没有实质影响"（第 8050–8054 行），
所以不存在比 (Ind3) 更大的上移空间；若存在，IUT IV 的上界也得重算。

**能做的正面动作。**

   这把"没明说的那一步"固定成一条可检验的陈述。

## 14. 三条在仓库对象上新搭的候选链（非论文对象；把握都很低）

共同目标：给"闭环闭合"提供隐藏条件，即证 (s−1)·A ≤ V。

### 链一：算术 Kodaira–Spencer（把张量包读成 jet，用 Galois 作用造非零态射）

- 输入（已有）：l-挠点标签与 𝔽_l 对称；theta 值 q^{j²/2l}；log-shell 在温和位就是逆 different
  （lana `hullPacket_tame`）；Gal(K/F) 的像含 SL₂(𝔽_l)。
- 新对象：
  1. 把 capsule j 的 (j+1) 重张量包读成"j 阶 jet"，定义滤过 F^j 与分次片 gr^j。
     次数对应：gr^j 一侧是 −(j+1)·D（逆 different 的 j+1 次幂），theta 一侧是 −j²·A。
  2. 对不保持乘性线的 σ ∈ Gal(K/F)，定义 κ_σ : gr^a → gr^b，取 σ 作用与滤过不交换的那一部分。
- 链：κ_σ ≠ 0（由不可约性）→ κ_σ 在截面 V 的位上是整的 → 非零整态射给出算术线丛的次数不等式
  → 对 j 求和得 (s−1)·A ≤ V。
- 隐藏条件落在：第二个箭头，即 κ_σ 的整性亏量被 (Ind1,2,3) 的壳吸收。
- 外部辅助：Hodge–Arakelov 比较同构（已发表定理），只用来给出 κ_σ 在各位的显式赋值。
- 已知障碍：Gaussian 极点。对全体位求和时增益与极点精确抵消（第 9 节）；要看截到 V 上之后是否留下正项。
- 判定实验：l = 5 或 7，一条显式曲线，逐位列出 κ_σ 的赋值，分 V 位与非 V 位。
- **试验状态（A878）**: **未执行**（设计/接口阶段）；owner qpilot。无局部赋值数据、无结果文档；κ_σ/jet 滤过尚不是 Lean 对象。存活/否决条件见 `coord/THREE-CHAINS-TEST.md` §1；不得把设计当结论。

### 链二：全纯结构族上的容器（让"可能像的并"依赖 q）

- 输入（已有）：单解析数据 G_v ↷ O^{×μ}；pilot 幺半群；log-shell；整体实化 Frobenioid 的次数。
- 新对象：
  1. 𝔥(v) := 与给定单解析数据相容的全纯结构（环结构）的集合，带"pilot 在该结构下的赋值"函数 ord_𝔥。
  2. 可能像 P(v, j) := ⋃_{𝔥} （该结构下 Θ 值作用于 log-shell 的区域）。
  3. 整体约束 G：各位的选择 (𝔥_v)_v 必须给出同一个整体次数（论文 Step (xii) 的刚性）。
- 链：证 q-pilot 在 (1,0) 的实现是族里的一个成员 → q-pilot 区域 ⊆ 受 G 约束的可能像之并
  → 取壳、取体积得不等式；同时证受 G 约束的并的壳体积仍满足 IUT IV 的上界。
- 隐藏条件落在：约束 G。没有 G，并集过大，上界丢失；G 太强，q-pilot 不在族里。
- 外部辅助：Fargues–Fontaine 曲线（untilt 族）作为 𝔥(v) 的具体模型。
- 已知障碍：Teichmüller 元的赋值不随 untilt 变，变的是 p 的相对大小；这是否等价于所需的族，没有定论。
- 判定实验：固定一个坏位，算 P(v, j) 的壳体积作为"允许的 ord_𝔥 区间"的函数；再问 G 把区间限制到多窄。
- **试验状态（A878）**: **局部计算中**；owner abc。无独立结果文档；𝔥(v)/P(v,j) 只是设计，尚无 Lean 对象/数值；存活/否决条件见 `coord/THREE-CHAINS-TEST.md` §2。进行中不等于支持。

### 链三：整体截面（在未实化的整体 Frobenioid 里造一个真态射）

- 输入（已有）：数域在张量包上的作用（Thm 3.11 (i)(c)）；区域与算术线丛次数的对应
