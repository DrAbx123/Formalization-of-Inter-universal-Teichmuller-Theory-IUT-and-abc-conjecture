# EXPLORATION-B-B1-FIX — 证书搜索目标修正：最小化 |P(f)|（Status: NUMERIC）

日期：2026-11-12；qpilot（A970）。**Status: NUMERIC；无 Lean。** 数据：`coord/b1_fix_certificates.csv` / `coord/b1_fix_data2.json`。

## 1. 目标修正（为什么旧 B1 搜索写反）

- 旧 B1 目标：找 P 使 `|P(f)| = r_f`（把证书引理的反向当成构造目标）。
- 证书引理只给：若整系数 Hecke 多项式 P 在所有其它特征形式上为 0、在 f 上非零，则 `r_f | P(f)`。
- 因 `r_f | P(f)` 且 `P(f)≠0` ⇒ **`r_f ≤ |P(f)|`**；所以正确目标是**最小化 `|P(f)|`**，从而给 `r_f` 的**上界**（不是精确等于）。
- 本文件按此目标重跑；旧 B1 的“停”判定基于错误目标，需由本结果修订。

## 2. 搜索族与算法

- 对每个曲线 E（半稳定，N≤200 样本）：取其新形式 f；`G` = 同层其它新形式 + 真因子 oldforms（p∤N 时 oldform 的 T_p 特征值与底层新形式相同）。
- 对每个素数 `p`（p∤N，p≤60），构造
  `Q_p(T_p) = ∏_{g∈G} minpoly(a_p(g)) ∈ ℤ[T_p]`，它按构造杀死所有 `g∈G`。
- 值 `v_p = Q_p(a_p(f)) ∈ ℤ`；P 取 Q_p 的整系数线性组合（仍杀死所有其它形式），
  `P(f) = Σ c_p v_p`；其最小非零绝对值为 `g = gcd(|v_p|)`。
- 在 `{v_p}` 中找**最小 support 子集**使其 gcd 等于整体 gcd，用扩展 gcd 求系数 c_p；得到证书 P；记录 `support`、`degree = max deg Q_p`、`max_prime`。
- 退化情形：`G = ∅`（该层没有其它新形式/oldforms）时取 `P = 1`（support 0, degree 0），`|P(f)|=1`。
- 正确性校验：所有证书 P 按构造在 G 上为 0；用 `|P(f)|` 与 `r_f`（及 `r_f^opt`）比较。

## 3. 数据与结果（N≤200，50 条分层样本）

### 3.1 样本与发现率
- 样本：**50 条**（25 条 N<100 + 25 条 100≤N<200 的跨水平抽样；N 范围 11–186）。
- **50/50 全部找到证书**；`type`：constant1 25（G=∅ 的低 N 层）、qp_combination 25（高 N）。
- 阈值发现率：
  - `|P(f)| ≤ N`：**39/50 = 78%**
  - `|P(f)| ≤ N²`：**50/50 = 100%**
  - **`|P(f)| ≤ N³`：50/50 = 100%**
- **`|P(f)|` 最大 = 27216**（曲线 170c2，N=170；N³≈4.9×10⁶ 仍远低于阈值）。

### 3.2 与 r_f / r_f^opt 的关系
- `r_f`（Sage `E.congruence_number()`，即该曲线的模次数）对同源类中的非最优曲线会大于新形式同余数；故用 **`r_f^opt = min_{E'∈isogeny class} deg φ_{E'}`**（squarefree 半稳定时 = newform congruence number）比较。
- **`r_f^opt | |P(f)|`：50/50 成立**；**`|P(f)| ≥ r_f^opt`：50/50 成立**（与证书引理一致）。
- 比值 `|P(f)|/r_f^opt` 分布：`1`（30 条）、`4`（5）、`8`（4）、`64`（2）、`128`（2）、`36/48/2/512/9/96/324` 各 1；全部为**整数 ≥1**。

## 4. 判定与下一步

### 4.1 判定（小样本）
- **正向信号**：在 N≤200 的 50 条半稳定曲线上，**100% 存在 `|P(f)| ≤ N³` 的证书**（实际上 ≤N² 也 100%）；`r_f^opt` 整除 `|P(f)|` 且 ≤它——证书引理适用，方向正确。
- 复杂度：support ≤3（主要是 2）、degree 7–14、max prime ≤47（N 11–186 样本）。
- **限制**：这是 **Q_p（单变量乘积）族内的最小化**，不是全局最小；N≤200 小样本，且高 N 只到 186；`|P(f)|` 与 N 的指数关系需要全量（N≤500 的 941 条）拟合；constant1 情形只在 G=∅ 的低层出现。

### 4.2 下一步
1. **全量 B1-FIX**：对 N≤500 的 941 条半稳定曲线跑本搜索；统计 `|P(f)|` 对 N 的 log–log 斜率、`≤N^C` 的最大 C、support/degree/max prime 的分布。
2. 若全量仍给出 **`|P(f)| ≤ N^C`（C 固定）且 `r_f^opt | |P(f)|`**，则 B 线弱 ABC 的数值前提取到支持；再进入 B2 设计（证书引理 Lean 化 + 外部输入登记）。
3. 若全量出现 `|P(f)|` 增长超多项式或证书缺失，则按原 B1 规则停。
4. 注意：证书引理本身仍需要 Lean 证明（纯线性代数，B 线原计划），本文件只给数值证据。
