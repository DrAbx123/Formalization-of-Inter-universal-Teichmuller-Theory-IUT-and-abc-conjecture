# SHEAF 单包任务模板

复制所需字段到本包记录即可，不创建新调度平台，不每个小引理写一份长计划。

```text
任务 ID / 所属组 / owner / 日期：
目标节点 / SHEAF 阶段：
文件：精确读写路径；当前版本；是否有其他活动 owner。
集成负责人 / 构建负责人：不需要构建的任务写不适用。
共享接口与冲突：冻结版本；是否改变共同定义；哪些任务能同时进行。
续领范围：交付后可认领的本组相关就绪任务；不逐项等待 root 重发。

数学目标：完整对象、变量、量词、假设、结论。
原文：版本、位置、相关上下文；已有研究记录可直接引用。
实际消费者：现有声明/字段，或已登记目标节点及其待形式化陈述；具体消掉什么前提。
与最终目标的连接：已核实部分；尚待核实部分。

statement_dependencies：准确声明、版本、是否已陈述。
proof_dependencies：准确声明、版本、proved / admitted / gap。
自然语言证明：按步骤写；未知步骤明确标缺口。
可复用 Mathlib / 项目供体：完整适用条件；搜索过什么。

本包范围内自主决定：证明体、等强替代路线、局部 API 修复、验证。
不能暗改：最终对象/量词/假设/结论、目标定义语义、他人活动文件。
验收：本阶段应交付什么；编译/类型比较/公理/语义证据各到哪一步。
停止边界：本包达到什么就不再扩展；什么问题需要新节点。
```

交付时追加：

```text
实际结果：准确声明或准确缺口。
statement_compiles：通过 / 未通过 / 未运行 / 不适用；证据版本。
proof_body_checked：通过 / 未通过 / 未运行 / 不适用；证据版本。
kernel_closed：通过 / 未通过 / 未运行 / 不适用；证据版本。
target_accepted：通过 / 未通过 / 未运行 / 不适用；证据版本。
未证依赖：逐个具名；合法原输入与新欠缺分别写明。
消费者接入：哪项前提消除；仅供体完成则直说。
剪枝：删掉哪些证明依赖/import；是否影响其他目标。
验证证据：命令、退出状态、源码/依赖版本、产物路径；旧证据注明复用。
下一步：一个具体动作；不反复复述历史。
```

声明可编译和最终闭合是不同验收。反例/更短路线草稿也是有价值交付，必须写清未证步骤；不能把草稿当已证依赖。
