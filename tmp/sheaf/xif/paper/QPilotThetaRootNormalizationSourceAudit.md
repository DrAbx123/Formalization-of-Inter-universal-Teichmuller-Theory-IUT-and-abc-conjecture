# q-pilot / theta-value 2l-th root normalization: source audit

Scope: IUT source text only. No Lean objects or guessed normalizations.

## 1. The two q's in IUT I, Example 3.2(iv)

IUT I, Example 3.2(iv) (iut1.txt:3774-3791) first writes `q_v` for the
**classical q-parameter** of the elliptic curve `E_v` over `K_v`:

    q_v  :=  q-parameter of E_v over K_v,

and notes that it admits a `2l`-th root in the relevant log-shell /
completion (`O^⊹(T_Xv)`). It then computes the value of the theta function
`Θ_v` at `√−q_v` and writes the result as

    q_v  :=  q_v^{1/2l},

i.e. the same symbol `q_v` is reused for the chosen `2l`-th root, determined
only up to a `μ_{2l}`-multiple (iut1.txt:3785-3791).

So the source text distinguishes:

* classical parameter: `q_v^param` (often written `q_v` before the root is chosen);
* paper root parameter: `q_v := (q_v^param)^{1/2l}`, determined up to `μ_{2l}`.

## 2. Theta values

IUT I (iut1.txt:6018-6030) states that the theta function value at an
evaluation point with label `j ∈ |F_l|` lies in the `μ_{2l}`-orbit of

    { q_v^{j^2} }_{j ≡ j}.

Here `q_v` is the root of §1. Therefore, in terms of the classical parameter,

    theta_v(j) = (q_v^param)^{j^2/(2l)}

up to a `2l`-th root of unity. In particular `j = 1` gives `q_v`, the root
parameter itself.

## 3. q-pilot and Theta-pilot in IUT III, Definition 3.8

IUT III, Definition 3.8, (i) (iut3.txt:6731-6769):

* the Theta-pilot object is determined by generators of the LGP-monoids,
  i.e. by the theta values `{q_v^{j^2}}`;
* the q-pilot object is determined by the `q_v` for `v ∈ V_bad`, explicitly
  referring back to the notation of [IUTchI], Example 3.2(iv).

Thus the q-pilot object uses the **root parameter** `q_v = (q_v^param)^{1/2l}`,
not the classical parameter. Equivalently, the q-pilot image is the `j = 1`
theta image, and its log-volume is the root log-volume.

## 4. Log-volumes and the q-pilot scalar

IUT III (iut3.txt:891-907) writes

    −|log(q)|  for the log-volume of the q-pilot image,
    −|log(Θ)| for the log-volume of the holomorphic hull of the union of
                possible images of the Theta-pilot object.

Since the q-pilot is generated by the root `q_v` (Definition 3.8(i)),

    |log q| = |log q_v| = (1/(2l)) · |log q_v^param|

for the classical parameter. The factor `1/(2l)` is therefore part of the
q-pilot scalar. It is not optional and cannot be dropped by using the classical
order `order(q_v^param)` directly.

The theta values carry the same root: `theta_v(j) = q_v^{j^2}` has
log = `j^2 · log q_v`, i.e. `j^2/(2l) · log q_v^param`.

## 5. The Corollary 3.12 inequality: inequality, not equality

IUT III, Corollary 3.12 / Theorem B (iut3.txt:1223-1234, 10527-10535) states:

    −|log(Θ)| ∈ R,   and   −|log(Θ)| ≥ −|log(q)|,

equivalently `C_Θ ≥ -1` for every real `C_Θ` such that
`−|log(Θ)| ≤ C_Θ · |log(q)|`.

The statement is a **non-strict inequality** (`≥`). It is not an equality,
and no equality is asserted in the theorem. The proof further observes
(iut3.txt:10532-10534) that one may assume `−|log(Θ)| < 0` in the finite
case, but this is a sign observation, not a claimed equality of the two
scalars. No strictness of the inequality is part of the statement either.

Therefore:

* the paper target is `−|log q| ≤ −|log Θ|`, equivalently
  `|log Θ| ≤ |log q|`;
* equality is a special additional assertion, not Corollary 3.12;
* the comparison is not made strict by the root normalization.

## 6. Consequence for the formal scalar

If `qVFamily T b` denotes the classical q parameter (order = classical order),
then the paper q-pilot magnitude is

    |log q_paper| = (1/(2l)) · |log qVFamily|,

or, at the coefficient level,

    c_b^paper = order(qVFamily T b) / (2l),

not `order(qVFamily T b)`.

Likewise the theta tensor coefficient is

    j^2 · c_b^paper = j^2 · order(qVFamily T b)/(2l),

not `j^2 · order(qVFamily T b)`.

The uncorrected order coefficient is the coefficient of the classical q
parameter, not of the paper root `q_v`, and is too large by exactly `2l`.

Summary:

| object | classical parameter exponent | paper root exponent |
|---|---|---|
| q-pilot | order | order/(2l) |
| theta value at label j | j^2 · order | j^2 · order/(2l) |

Corollary 3.12 compares the root q-pilot scalar with the root theta-hull
scalar by a non-strict inequality.

## 7. Correction used by RootFactorQThetaCoefficientAnalysis

Per the project's RootFactorQThetaCoefficientAnalysis, the operative paper
normalization is:

* q-pilot scalar: classical q magnitude, coefficient `c_b^q = n_b = order(qVFamily T b)`,
  with NO `1/(2l)` division;
* Theta scalar: root-value coefficient `c_b^root = j^2 n_b/(2l)`.

Thus `paperQParameterSigned <= thetaHullLog` is the non-trivial Cor 3.12
inequality; dividing the q-pilot scalar by 2l would make it too small. The
target PaperLevelXiFTargetActual follows this corrected convention.
