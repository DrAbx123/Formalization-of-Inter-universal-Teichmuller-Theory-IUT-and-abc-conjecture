# S82: O-boundary partial log and unit part

Date: 2026-10-29.

## Actual partial log

The source logarithm is defined on

  O-times = (Integers (CommonPrimeCompletion place))^x.

S82 constructs oTimesPartialLog = unitLog on O-times, with actual
oTimesPartialLog_one and oTimesPartialLog_mul.  The same O-times is embedded in
O-boundary by oTimesUnitPartEmbedding = sourceOTimesToBoundary.

Thus the part of O-boundary on which the source log is actually defined is the
unit part O-times; the log-shell is built from this O-times logarithm (S63).

## Exact gaps

* OBoundaryUnitDecomposition: arbitrary O-boundary elements need a canonical
  unit part times an integral exponent (valuation splitting).  The source has
  no chosen uniformizer/splitting, so this is recorded as required, not
  constructed.
* OBoundaryTotalLog: a total log on all nonunit O-boundary elements extending
  the unit log is not supplied.  Recorded as required, no inhabitant.

No fake total log/sorry/axiom/True/PUnit.
