Scope: read-only semantic audit of the actual Lean definitions and source
notes. No Lean file is modified and no norm equality is asserted.

## 1. What `PaperXiFFinalActual.paperLevelXiF_actual` proves

`PaperXiFFinalActual.lean` contains:

    theorem paperLevelXiF_actual
      (T : SourceNativeInitialThetaData l) :
      ActualPaperXiFTarget (l := l) T

with local instances for `Fintype (Bad ...)`, `MeasurableSpace` and
`BorelSpace` on `qVFamTensorBlock T b`. It proves exactly the target
proposition from `PaperLevelXiFTargetActual.ActualPaperXiFTarget`.

`ActualPaperXiFTarget` is defined in `PaperLevelXiFTargetActual.lean` as:

    actualQPilotSignedLogClassical T
      ≤ actualThetaHullLogRoot T

where:

* `actualQPilotSignedLogClassical := - ∑ b, weight_b *
  (QVFamNormalizedGeneratorSupplyActual.qVFamNormalizedCoefficient T b *
   Real.log (qVFamTensorP T b))`;
* `actualThetaHullLogRoot := ∑ b, weight_b * actualLocalHullLog b`;
* `actualLocalHullLog` is the normalized log of the root theta closure hull
  with `actualRootCoeff = c_norm/(2l)`.

`PaperLevelXiFTargetBridgeActual` proves the target by identifying these
target scalars with the proof-local scalars:

    actualQPilotSigned_eq_globalQPilotLog
    actualThetaHullLogRoot_eq_globalThetaHullLog

and then applying `globalQPilotLog_le_globalThetaHullLog`.

## 2. What `c_norm` is

From `QVFamNormalizedGeneratorSupplyActual` and `#print`:

    qVFamNormalizedCoefficient T b
      = - Real.logb (qVFamTensorP T b) ‖qVFamNormalizedGenerator T b‖.

This is the normalized spectral (`CommonPrimeCompletion` normalized) norm,
not the default completion valuation norm.

`QVFamNormalizedCoefficientBridgeActual` proves exactly:

    c_norm * log p
      = localLogMagnitude (qVFamily T b)
        - log (‖qVFamily‖_normalized / ‖qVFamily‖_default).

The file also defines the exact gap

    QVFamNormInstanceGap : Prop :=
      qVFamNormalizedNorm T b = qVFamDefaultNorm T b

and proves

    c_norm * log p = localLogMagnitude (qVFamily T b)
      ↔ QVFamNormInstanceGap T b.

So, without `QVFamNormInstanceGap`, `c_norm` is a **normalized auxiliary
coefficient**, not the default-norm `localLogMagnitude (qVFamily)`.

## 3. What the paper q-pilot scalar is

Source-level: IUT III, Corollary 3.12 / Theorem B defines

    −|log(q)| = procession-normalized mono-analytic log-volume
                of the image of a q-pilot object.

IUT I, Example 3.2(iv) and IUT III, Definition 3.8(i) identify the q-pilot
object as generated by the root parameter

    q_v = (classical q-parameter)^{1/2l},

with theta values `q_v^{j^2}`. The source does not, by itself, identify this
paper log-volume with either the default completion valuation norm or the
normalized spectral norm of the project's tensor block. The choice of
normalized spectral norm is a **tensor-model normalization** forced by the
actual tensor carrier, as recorded in NormChoiceAudit.md.

NormChoiceAudit.md says explicitly:

* a default-norm tensor block is not constructible in the current tree;
* the normalized spectral norm is the only actual tensor norm available;
* the final proof uses `c_norm`, not `localLogMagnitude`;
* no equality `c_norm = localLogMagnitude(qVFamily)` is claimed.

## 4. Same proposition or different?

**Not literally the same proposition as the paper q-pilot scalar with the
default completion norm.** The final theorem proves a normalized-scalar
inequality in `c_norm`; the paper's `−|log q|` is a source log-volume that
has not been identified with `c_norm * log p` in the tree. The exact missing
identification is `QVFamNormInstanceGap` (or an equivalent
normalized/default norm-ratio identity).

It is also not a completely unrelated statement: it is the paper xi-f
inequality evaluated in the **normalized spectral tensor model**, with the
root coefficient `c_norm/(2l)`. If the paper's tensor-packet μ_log is
stipulated to be the normalized spectral normalization, then the target is
the model-level paper statement. That stipulation is a source-semantic
decision, not a proved equality in the current tree.

Therefore the correct verdict is:

| question | answer |
|---|---|
| Is `paperLevelXiF_actual` the paper-level xi-f with the default completion norm? | no |
| Is it a normalized auxiliary/model-level xi-f? | yes |
| Is it semantically the paper xi-f under the normalized spectral tensor convention? | conditionally yes, by definition of that convention |
| Is there a proved bridge `c_norm*log p = localLogMagnitude`? | no; exact gap `QVFamNormInstanceGap` |
| Is the root coefficient consistent with the paper root `q_v^{1/2l}`? | yes: `c_norm/(2l)` |

## 5. Consequences for the final gate

`paperLevelXiF_actual` should be labeled a **normalized tensor-model xi-f
theorem**, not the unconditional paper-level statement with the default
completion q-pilot scalar. Final acceptance of the paper statement requires
one of:

1. a source-semantic theorem identifying the paper q-pilot log-volume with
   the normalized spectral tensor log-volume (the intended normalized model);
   or
2. the exact norm-instance bridge `QVFamNormInstanceGap` (or its equivalent
   ratio identity), which would make `c_norm` the default local log;
3. a direct construction of the default-norm tensor block, which
   NormChoiceAudit.md records as unavailable.

Without one of these, the theorem is a valid normalized auxiliary result but
is not literally the paper-level xi-f sentence `−|log q| ≤ −|log Θ|` with the
paper q-pilot scalar.

## 7. Closing addendum: the paper q-pilot scalar is normalized μ_log

The source text resolves the normalization question in favor of the
normalized tensor/procession μ_log, not the default completion valuation norm.

### 7.1 q-pilot and Theta-pilot use the same normalized log-volume

IUT III, Corollary 3.12 / Theorem B (iut3.txt:10508-10525) defines `−|log(q)|`
as the

    "procession-normalized mono-analytic log-volume of the image of a q-pilot
    object, relative to the relevant Kummer isomorphisms, in the multiradial
    representation of Theorem 3.11, (i)"

which is not regarded as subject to (Ind1), (Ind2), (Ind3). The same passage
(iut3.txt:10499-10507) defines `−|log(Θ)|` as the procession-normalized
mono-analytic log-volume of the holomorphic hull of the possible images of the
Theta-pilot object, relative to the same Kummer isomorphisms. The two scalars
are therefore log-volumes in the **same normalized mono-analytic μ_log**,
differing only by the region (q-pilot image vs. Theta hull) and by the
indeterminacies attached to the Theta side.

The initial definition of the q-pilot log-volume (iut3.txt:891-892) says

    "The log-volume of the q-pilot object will be denoted by −|log(q)| ∈ R"

and the Theta-pilot log-volume is introduced immediately after
(iut3.txt:902-922) with the same μ_log notation, including the explanation that
`−|log(Θ)|` is a positive multiple of `−|log(q)|` plus a possible error term.

### 7.2 The μ_log is the normalized/packet/procession one

IUT III, Proposition 3.9, (i) (iut3.txt:6961-7007) constructs the local
log-volumes with packet-normalization and procession-normalization:

* integral structures have log-volume 0;
* multiplication by `p_v` adds `−log(p_v)`;
* collections of capsules in a procession are normalized by taking the
  **average over the procession**.

IUT III, Remark 3.1.1, (ii) (iut3.txt:5473-5600) further specifies the
normalized weights

    1/[K_v : (F_mod)_v]

and the corresponding normalized weight for direct sums/tensor products, so
that multiplication by `p_vQ` shifts log-volumes by `log(p_vQ)`. This is the
same `nativeBadLocalWeight`/normalized-weight structure used by the final
normalized tensor scalar, not the raw completion valuation `localLogMagnitude`.

### 7.3 Consequence: no default-norm equality is a paper requirement

Thus the paper's `−|log q|` is not defined by the default completion valuation
norm `localLogMagnitude (qVFamily)`; it is the normalized mono-analytic
tensor/procession μ_log. The normalized coefficient

    c_norm = -logb_p ‖q‖_normalized

used in `QFamNormalizedGeneratorSupplyActual` is the normalized tensor
coefficient, and its weighted sum with the actual local weights is the
paper-side normalized q-pilot scalar. The default-norm comparison
`QVFamNormInstanceGap` is therefore **not a paper-necessary bridge**; it is only
an optional comparison between two different normalizations.

In particular, the final target

    weighted Σ c_norm·log p  ≤  normalized root-hull log

is the paper-level normalized xi-f comparison, provided the tensor fractional
lattice/μ_log model is accepted as the normalized mono-analytic μ_log of
Proposition 3.9/Remark 3.1.1. It is not a different auxiliary inequality
requiring the default completion norm.

### 7.4 Remaining semantic obligation

The only remaining semantic obligation is the model identification of the
project's `arithmeticTupleNormalizedLogVolume`/normalized spectral coefficient
with the paper's procession-normalized mono-analytic μ_log of Proposition 3.9.
That is a source-to-model identification, not an equality with the default
