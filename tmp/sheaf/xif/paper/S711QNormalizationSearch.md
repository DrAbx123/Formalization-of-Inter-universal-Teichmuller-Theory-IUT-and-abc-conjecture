# S711: q-pilot degree/weight normalization vs IUT

Date: 2026-10-30. Status: research memo; no Lean file claimed as proof.

## 1. Source definition of the local weight

IUT I, Example 3.5 (i), extract lines 4694-4697:

    log_mod(p_v) |-> 1/[K_v:(F_mod)_v] log_Phi(p_v).

IUT I, Example 3.5 (ii), lines 4758-4784:

    log_mod(p_v)*log(Theta)
      |-> ( log_Phi(p_v)/[K_v:(F_mod)_v] ) *
          ( log_Phi(Theta_v)/log_Phi(q_v) ).

Thus the paper local weight is w_v = 1/[K_v:(F_mod)_v], applied to BOTH q-pilot and Theta.

Lean actual definition (matching source): localCompletionDegree T w = Module.finrank of upper/lower completion; localNormalizedWeight = inverse. Files: ProcessionNormalizationWeightsActual.lean, PaperLevelXiFTargetActual.lean.

## 2. Sympy exact coefficient calculation

Let l = 2m+1, ProcessionLabel = F_l^x (card l-1). For units +-1,...,+-m:

    S_units = sum_{j in F_l^x} j^2 = 2*sum_{j=1}^{m} j^2 = l(l^2-1)/12.

Correct paper theta coefficient with q[2u]=q[1u]^(1/(2l)):

    C_paper = S_units / (2l*(l-1)) = [l(l^2-1)/12]/[2l(l-1)] = (l+1)/24.

C_paper <= 1 iff l <= 23.

Enumerated primes 5..1000: l=23 gives 1 exactly; l=29 gives 30/24=1.25>1; all larger primes fail; max at l=997 is 998/24 ~ 41.58.

Local degree cancellation: if both sides carry the same 1/d_b, the ratio is unchanged. Hence d_b CANNOT repair C_paper > 1. S696's required extra factor ~l cannot be supplied by d_b under the source weight convention.

## 3. Can d_b be l?

K/F is generated by l-torsion; Gal(K/F) is a subgroup of GL_2(F_l) containing SL_2(F_l). Thus [K:F] is at least |SL_2(F_l)| = l(l^2-1) in the Galois case, much larger than l. A local degree d_b=[K_v:(F_mod)_v] divides [K:F], can be 1 at split places, and can be as large as the local orbit degree; it is not uniformly l.

If (incorrectly) 1/d_b were applied only to q-pilot, C_paper/d_b <=1 for d_b >= (l+1)/24 and d_b~l would repair. But this is NOT the source formula: both sides have 1/d_b.

## 4. Candidate Lean statements

Candidate 1 (correct label group/normalization):

    theorem paperThetaAverageCoefficient_eq (l : PrimeGeFive) :
      (sum over ProcessionLabel l of j^2) / (2*l*(l-1)) =
        ((l.value : Real) + 1) / 24

    theorem paperThetaAverageCoefficient_le_one_iff (l : PrimeGeFive) :
      ((l.value : Real) + 1) / 24 <= 1 <-> l.value <= 23

Candidate 2 (local degree cancels):

    theorem localWeight_cancels_in_ratio
      (w : Real) (hw : w != 0) (theta qpilot : Real) :
      (w * theta) / (w * qpilot) = theta / qpilot

Candidate 3 (exact obstruction statement):

    def QPilotNormalizationObstacle : Prop :=
      ((l.value : Real) + 1) / 24 <= 1

No proof of paperThetaAverageCoefficient_eq is claimed yet; the formula is exact over Rational/Real and checked by sympy for primes 5..1000. A future Lean proof must use the actual F_l^x label group and q[2u] exponent 1/(2l), not realThetaValue q^(j^2).

## 5. Conclusion

- Source normalization is 1/[K_b:(F_mod)_b] on both sides (IUT I Example 3.5); Lean matches it.
- d_b can be l (indeed much larger), but cancels from theta/qPilot ratio; it does not provide S696's missing factor.
- With correct paper label group and q[2u] normalization, coefficient is (l+1)/24, <=1 only for l<=23; l=29 fails.
- S679 cannot be fixed by local degree alone. The remaining issue is a normalization/manuscript-consistency issue, not a Lean arithmetic gap.
