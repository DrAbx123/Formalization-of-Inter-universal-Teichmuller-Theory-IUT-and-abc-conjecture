## 1. Two different bounds

### 1.1 Raw container

At capsule level j, IV gives

```
H_C,inf,j ⊂ π^{j+1} B_I,   h_inf,j ≤ (j+1) log π,   j=1,...,m=20.
```

This is a **per-level raw bound**. At j=20 it is `21logπ=24.0393`; at j=1 it is `2logπ=2.2895`.

### 1.2 Procession-average bound

For the full procession, average over j=1..20:

```
(1/20) Σ_{j=1}^{20} (j+1) = 11.5;   A_proc = 11.5 log π = 13.1643936873….
```

This is a bound for the **procession-normalized** h_inf, not for every individual capsule. In particular, `h_inf,j>A_proc` is possible at high j (j≥11) while still satisfying raw container. Therefore

```
h_inf > A_proc  ⇏  h_inf > raw container.
```

The statement “h_inf>A_proc is outside target” is true only if h_inf is the procession-normalized readout / target quantity, not a fixed-level capsule readout. C9's h_inf(C) is procession-normalized; A_proc is its IV upper bound. So for the **global target h_inf**, `h_inf>A_proc` violates C3 (or is defined outside target), hence is an E2 escape; but it is not forced by b=273.

## 3. Container failure theorem

**Theorem E2-ARCH (target-container insufficiency).** Assume the target C has capsule levels j=1..20, B_I-zero normalization, and the IV raw container. Then for every target level j

```
h_inf,j ≤ (j+1)logπ ≤ 21logπ = 24.0393276028…
```

and the finite b=273 deficits are

```
D_A=(38883/41)logp=8931.1745786033…;
D_B=(38463/41)logp=8834.7032846441….
```

Hence

```
D_A - 21logπ = 8907.1352510004… >0;
D_B - 21logπ = 8810.6639570413… >0.
```

So no target-compatible archimedean hull can compensate the b=273 finite deficit. The b=273 no-go under C1/C2/C3 remains; the arch **container is not large enough**. This is a **compensation failure**, not a proof that the b=273 capsule lies outside the raw container.

**Corollary.** `h_inf>A_proc` at fixed level j is not necessarily outside raw container: for 11≤j≤20, `(j+1)logπ>A_proc`. But even the raw max is far below D_A/D_B; therefore such a fixed-level excess cannot rescue b=273. If the global procession-normalized h_inf satisfies `h_inf>A_proc`, then C3/target fails, so the object is outside target; this would be E2, but it is an extra failure not implied by b=273.

## 4. B_I-zero normalization

`logvol(B_I)=0`, `logvol(π^{j+1}B_I)=(j+1)logπ`; this fixes the zero reference. It gives no lower bound and no larger container. It does not allow adding per-factor `π` powers or changing j. In particular:

```
B_I-zero does not imply h_inf,j > A_proc or < A_proc;
B_I-zero does not turn 21logπ into a larger bound;
B_I-zero does not make b=273 capsule lie outside IV.
```

## 5. E2 status

E2 was: at least one of CFTH/TC/arch fails for every actual C. The arch **container failure** could be one of:

```
(E2-a) actual h_inf exceeds the target bound A_proc (global procession);
(E2-b) the b=273 capsule cannot fit in the IV raw container at its level;
(E2-c) arch compensation is insufficient for b=273 under the target bound.
```

This file proves (E2-c), not (E2-a)/(E2-b):

- (E2-a) is not forced by b=273; if true it must be shown from actual h_inf, which is unconstructed;
- (E2-b) is false as a statement about b=273: the profile can sit at target levels j≤20; no source level-b relation;

Therefore **E2 remains OPEN**; the arch side does not supply an escape. Under C1/C2/C3, b=273 still gives F>8800 in both B branches. The only arch-related E2 escape is an actual global `h_inf>A_proc`, which would violate C3/target and is not constructed.

## 7. Conclusion

The b=273 capsule is **not** necessarily outside the IV raw container; `b=273` is a q-order, not a capsule level, and no source forces j=b.
