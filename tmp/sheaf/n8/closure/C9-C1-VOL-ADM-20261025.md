# C9 C1 audit: admissibility of volume-chosen S

Question G3: Is an arbitrary measurable S subset VC(LS) admissible for eta^anab, or only an integral/N-stable S? If not, does volume scaling produce an admissible S? Exact source condition.

Sources: LANA report snapshot tmp/sheaf/n8/closure/C9-STRICT-DEFICIT-LANA-SNAPSHOT-20261024.tex, section "The main goal" lines 2502-2523 and "Minimal structure of the eta-algorithm" lines 2525-2537; C9-C1-ADM-NOGO-20261025.md (T1-T5); C9-C1-ADM-MULTI-20261025.md (Lemma A/B); C9-C1-ADM-ADVERSARIAL-20261025.md; C9-C1-ADM-PROOF.

## 0. Verdict

G3: an arbitrary measurable S subset VC(LS) is NOT admissible. eta^anab_S is not total on measurable subsets. It requires at least:
(T1) S adelic measurable;
(T2) the N-action defined on S and 1·S adelic measurable;
(T3) S an integral structure compatible with the anabelian/Frobenioid comparison;
(T4) M=1·S defines a class in R^ss and the target pilot is well-defined;
(T5) eta^anab_S is a pointed linear isomorphism.
Only (T1) is suggested by the word measurable; (T2)-(T5) are additional construction requirements. LANA's "once we fix S subset VC, this provides an isomorphism" is conditional on S being suitable, not a totality theorem over all measurable S.

Volume scaling does NOT produce an admissible S from the source conditions alone. Choosing a measurable S with the same volume as the q-pilot class matches the volume class [S], but:
- eta^anab_S depends on the actual integral structure S, not only on [S];
- the target pilot of eta^anab_S is [1·S], not [S]; volume scaling of S does not prove vol(1·S)=vol(S);
- scaling an admissible reference region by an arbitrary real/fractional factor need not preserve the integral-structure/N-stability conditions;
- the q-pilot diagonal lives in the value-group/target container and is not automatically a subset/integral structure of the source log-shell container VC(LS).
Thus volume matching is a necessary pilot-class condition, not a sufficient admissibility condition. The exact source condition is (Adm_vol) in section 4; no source theorem proves it.

No extra assumptions are introduced. The obstruction is structural.

The word "suitable" is essential. LANA does not say "for every measurable S"; it says "once we fix S" after the construction context. The report also states that the required compatibility is not yet reconstructed (C9-C1-LITERATURE).

## 2. Why arbitrary measurable S is not admissible

The construction of eta^anab_S uses the action of N on VC and S as an integral structure. The following are needed and not consequences of measurability:

(T1) S adelic measurable. A product-measurable subset need not be adelic (restricted-product/compactness support).
(T2) N-action defined on S, and 1·S adelic measurable. The action of the Gaussian monoid N is not defined on an arbitrary measurable subset in a way that preserves the adelic/measurable class; LANA does not prove closure.
(T3) S integral structure. The eta^anab construction uses S as the integral structure/reference; an arbitrary measurable set need not be VC(O)-compatible or an integral structure.
(T4) 1·S defines a class in R^ss. If 1·S is not adelic measurable or has infinite/undefined volume, its class does not exist.
(T5) eta^anab_S pointed linear isomorphism. This is an output property, not automatic from a measurable S.

ADM-NOGO gives the exact counterexample schema: a measurable S whose translate 1·S has non-adic/unbounded support is measurable but M=1·S has no class in R^ss; eta^anab_S is undefined. This is a type-level obstruction; no totality theorem exists.

Verdict: only S satisfying (T1)-(T5), in particular an integral/N-compatible S, is admissible. "Arbitrary measurable" is NOT sufficient.

## 3. Volume scaling: what it fixes and what it does not

Suppose one chooses S by volume to match the q-pilot class:
    vol(S) = vol({q_vO_v}) = exp(Q), or logvol(S)=Q.
If the q-pilot class is defined in R^ss, this gives [S]=[q-pilot] in R^ss. That is only a class equality.

Three gaps remain:

(V1) eta^anab_S depends on S, not only on [S]. LANA writes eta^anab_S with subscript S; the construction uses S as the integral structure. There is no source theorem that two S with the same volume (same class in R^ss) give the same eta^anab_S. The quotient R^ss by volume does not make the construction S-independent.

(V2) The target pilot of eta^anab_S is [1·S], not [S]. Even if [S]=[q-pilot], one still needs
    [1·S]=[S], i.e. vol(1·S)=vol(S),
for the target pilots of eta^anab_S and eta_q to match (Lemma B/B5 of ADM-MULTI). The equality vol(1·S)=vol(S) is a nontrivial N-volume-preservation/equality condition; LANA does not assert that 1 in N acts volume-preservingly on S. The whole point of eta_q/eta^anab is to compare two constructions; one cannot assume it.

(V3) Scaling an admissible reference region to the required volume may destroy admissibility. If S0 is an integral structure (e.g. VC(O) or a p^k VC(O) lattice), scaling by a real c generally does not preserve the VC(O)-submodule/integral-structure property, the adelic measurability, or N-stability. If one restricts to p^k scalings, the achievable log-volumes are k log p; matching Q=-(b/41)logp requires fractional exponent b/41, not an integral p^k scaling. A fractional ideal q_vO_v may have that volume in a local field, but it is not proved to be an admissible S in VC(LS); this is the container/type mismatch of ADM-PROOF.
If one instead scales S by a real parameter and then takes its volume class, one obtains a measurable set with the right volume but no proof of (T2)-(T4); this is an arbitrary measurable S, not an admissible one.

Thus volume scaling produces at best a measurable set with the correct volume class. It does not produce an admissible integral/N-stable S.

## 4. Exact source condition (Adm_vol)

The exact sufficient condition for a volume-chosen S is:

(Adm_vol) S subset VC(LS) satisfies:
  (a) S is adelic measurable;
  (b) S is an integral structure compatible with the anabelian/Frobenioid
      construction;
  (c) the N-action is defined on S and 1·S is adelic measurable;
  (d) M=1·S defines a class in R^ss, and vol(1·S)=vol(S);
  (e) eta^anab_S is a pointed linear isomorphism and its target pilot matches
      the q-pilot class.
Then eta_q=eta^anab_S (Lemma A/B), and C1 may follow if the eta equality is
bridged to an actual output D0 with logVol(D0)=Q.

The volume condition vol(S)=exp(Q) is only part of (d) (or its premise), not all of (a)-(e). No source theorem proves (Adm_vol) for a volume-chosen S. LANA's "suitable S" is exactly this condition; the main goal is to construct it.

## 5. Could volume-only selection be sufficient in principle?

No source statement supports it. The only volume-level fact is that R^ss is a quotient by volume, so measurable sets with equal volume have the same class. But:
- eta^anab_S is a map depending on S, not a function of [S];
- the target pilot is [1·S], involving the N-action;
- admissibility/integrality/N-stability are not determined by volume.
Therefore volume-only selection is not a source-valid construction of an admissible S. Any claim that "choose S of the right volume" proves C1 would need to prove (Adm_vol), which is exactly the open compatibility, not a consequence of the volume quotient.

## 7. Conclusion

An arbitrary measurable S subset VC(LS) is not admissible for eta^anab; the construction requires an integral/N-compatible S satisfying (T1)-(T5). Volume scaling can match the q-pilot volume class [S], but eta^anab_S depends on the actual S, its target pilot is [1·S], and volume scaling does not prove N-stability, integrality, or [1·S]=[S]. The exact source condition is (Adm_vol); it is precisely the missing suitability/admissibility of LANA's main goal and is not implied by volume matching. Volume-chosen S therefore does not supply a source-valid C1 route. No arbitrary S, no Lean, no mixed/E3.
