## 0. Context and C1 reduction target

C1 (C9-C1-MASTER) is the existence of an output D0 of the multiradial
algorithm with logVol(D0)=Q=-|log q|. The eta-reduction attempts to prove C1
by comparing two pointed R-linear isomorphisms of one-dimensional real lines:

    eta_q      : R^val -> R^ss   (native q-pilot construction),
    eta^anab_S : R^val -> R^ss   (anabelian construction depending on S),

using Lemma A (pointed one-dimensional linear isomorphisms with the same pilot
are equal) and Lemma B (the two maps send the pilot to [S_q] and [1·S_q]).
If the target pilots agree, Lemma A would give eta_q=eta^anab_S and hence the
q-pilot value would be represented in the output, giving C1.

This file verifies Lemma A and Lemma B from LANA §9.2 (Project LANA interim
report, papers/LANA_report_202607.pdf; extracted text
tmp/LANA_report_202607.txt) and basic linear algebra, and identifies the exact
missing nondegeneracy/nonzero-pilot condition and the exact target-pilot gap.

## 1. LANA §9.2 setup

LANA §9.1-§9.2 (extracted text lines 2489-2589), especially lines 2567-2589:

  - R^val is the one-dimensional oriented real line C (value-group part of the
    BPS), equipped with a canonical pilot (the value-group pilot).
  - R^ss = {T subset VC(I_v) | T adelic and measurable}/~, where T~T' iff the
    volumes of T and T' coincide. Thus R^ss is a one-dimensional real line of
    volume classes, and its pilot is a class [M].
  - Fix S subset VC(I_v). Define M=1·S (the action of 1 in N), which represents
    "LGP·S" (cf. §6.2(h)), and put the class [M]=[1·S] in R^ss to be the pilot.
    The isomorphism
        eta^anab_S : R^val ~-> R^ss
    is a pointed R-linear isomorphism depending on S.
  - For the q-pilot BPS, there is another isomorphism
        eta_q : R^val ~-> R^ss,
    whose target pilot is the class of {q_v O_v} embedded "diagonally" into the
    large volume container VC(I_v).
  - The main goal (9-1) is to show that there exists a suitable S such that
        eta_q = eta^anab_S.

The pilots are class-valued: equality of pilots means equality of volume
classes in R^ss, not equality of the underlying subsets. The maps are pointed
R-linear isomorphisms of one-dimensional real lines.

## 2. Lemma A: pointed one-dimensional linear isomorphisms with same pilot

Statement A (exact form). Let V,W be one-dimensional real vector spaces. Let
p in V be a nonzero pilot vector. Let T1,T2: V -> W be R-linear isomorphisms
such that T1(p)=T2(p) (the same target pilot vector, not merely the same
volume class). Then T1=T2.

Proof. T2^{-1}T1 is an R-linear automorphism of the one-dimensional V. Since it
fixes p != 0, it is multiplication by a scalar lambda with lambda p = p, hence
lambda=1. Therefore T2^{-1}T1=id_V and T1=T2. QED.

Lemma A is valid under the conditions:
  (A1) V,W are one-dimensional real vector spaces;
  (A2) p is a pilot vector and p != 0;
  (A3) T1,T2 are R-linear isomorphisms (or at least linear maps defined on the
       line and nonzero on p);
  (A4) T1(p)=T2(p) as actual target vectors, not merely as volume classes
       [T1(p)]=[T2(p)].

Necessity of nonzero pilot (counterexample). Take V=W=R, p=0,
T1=id, T2=2id. Both are pointed R-linear isomorphisms and T1(0)=T2(0)=0, but
T1 != T2. Hence without p!=0 Lemma A is false. If p!=0 but only the target
class [p] is known (projective/volume-class equality up to positive scalar),
then T1 and T2 need not be equal: they may differ by a scalar. Thus the
nonzero-pilot condition is not sufficient by itself; exact target-pilot
equality (or a known normalization/scaling) is also required.

Orientation/sign note: if V,W are oriented and the maps are required to be
orientation-preserving, that normalization can fix the sign, but the scalar
ambiguity remains if only the class of the pilot is known. Lemma A as stated
uses actual vector equality, so orientation is not needed for the equality
proof, but it is part of the "pointed" data.

## 3. Lemma B: target pilots of eta_q and eta^anab

Literal LANA §9.2 pilots:
  (B1) eta_q target pilot = class of {q_v O_v} embedded diagonally in
       VC(I_v) (lines 2583-2584);
  (B2) eta^anab_S target pilot = class of M=1·S, i.e. [1·S] (lines 2571-2573).

The task's notation "eta_q pilot=[S_q]" is correct only if S_q is defined to be
the diagonal q-pilot subset {q_v O_v} (or a representative of its volume class).
If S_q is the same parameter used in eta^anab_{S_q}, then "eta_q pilot=[S_q]"
requires S_q to represent the q-pilot diagonal class; it is not an independent
computation. The literal LANA statement is (B1), not "eta_q pilot=[S_q]" for an
arbitrary S_q.

With S_q chosen so that [S_q]=[{q_v O_v}], Lemma B gives:
  (B3) eta_q(pilot) has target class [S_q];
  (B4) eta^anab_{S_q}(pilot) has target class [1·S_q].

For Lemma A to conclude eta_q=eta^anab_{S_q}, one needs the exact target pilots
equal:
  (B5) [S_q] = [1·S_q] in R^ss,
i.e. the volumes of S_q and 1·S_q coincide (definition of ~ in R^ss).
If (B5) fails, the two maps have different target pilots; by one-dimensional
linearity they differ by a nonzero scalar (the ratio of the two pilot classes),
and eta_q != eta^anab_{S_q}.

## 4. Verification of Lemma B

### 4.1 What is correct

  - eta^anab_S(pilot)=[1·S]: by definition M=1·S and the pilot of R^ss is
    [M] (LANA §9.2). This is correct.
  - eta_q target pilot is the diagonal q-pilot class {q_v O_v}: correct in
    LANA §9.2; if S_q denotes that class, then [S_q] is the eta_q target pilot.
  - R^ss is one-dimensional and the pilot is a volume class: correct.

### 4.2 What is missing

  (M1) Nonzero pilot. The pilot class [S_q] must be nonzero, and the source
       pilot p in R^val must be nonzero. If [S_q]=0 (e.g. S_q has volume 0, or
       S_q is empty), Lemma A cannot distinguish the maps: both send the pilot
       to the zero class. The q-pilot value Q is nonzero (|log q|>0), but this
       must be explicitly propagated to S_q and 1·S_q. A zero-volume S_q is a
       degenerate choice; no arbitrary S_q may be chosen.
  (M2) Exact target-pilot equality. Lemma A needs [S_q]=[1·S_q] as actual
       classes, not just nonzero classes. Equality of classes is
       vol(S_q)=vol(1·S_q), since R^ss is defined by equality of volumes.
       LANA does not assert vol(1·S)=vol(S) for arbitrary S; the 1 in N acts by
       LGP (represented by M=1·S), not by the identity. Thus (B5) is a genuine
       condition, not a definitional identity.
  (M3) The action of 1 in N is not known to preserve the class of S. LANA
       §6.2(h) defines the LGP^N action on log-shells; §9.2 uses 1·S as
       "LGP·S". The whole point of eta_q/eta^anab is to compare two different
       construction processes; one cannot assume their target pilots coincide.
       The equality (B5) is exactly the nontrivial eta_q-in-orbit condition
       (9-1), not a consequence of Lemma A.
  (M4) Finiteness/measurability and well-definedness. S_q must be adelic and
       measurable with finite positive volume for [S_q] and [1·S_q] to be
       well-defined in R^ss; otherwise the volume-class comparison is not
       meaningful.
  (M5) Pointed structure/orientation. Both maps are pointed R-linear
       isomorphisms; the pilot must be a nonzero element of the pointed line.
       If only a projective/class pilot is specified, Lemma A gives equality
       only up to the corresponding scalar.

### 4.3 Counterexample/obstruction to Lemma B as an equality

Take S_q chosen so that [S_q] is the q-pilot class but vol(1·S_q) != vol(S_q).
Then eta_q target pilot = [S_q], eta^anab target pilot = [1·S_q], and these
are different classes in R^ss. The two pointed R-linear isomorphisms R^val->R^ss
send the pilot to different target classes; they cannot be equal by Lemma A.
Thus Lemma B does not imply eta_q=eta^anab_{S_q}; it exhibits exactly the
missing volume-invariance/equality condition.

This is not a source counterexample to C1; it is the exact logical obstruction
to the eta-reduction. LANA's (9-1) asks for a suitable S satisfying the
equality; Lemma B alone does not supply it.

## 5. Corrected conditional lemma

Lemma B' (corrected). Let S_q be an adelic measurable subset of VC(I_v) with
finite positive volume, representing the diagonal q-pilot class:
[S_q]=[{q_v O_v}]. Then:
  (i) eta_q(pilot)=[S_q];
  (ii) eta^anab_{S_q}(pilot)=[1·S_q];
  (iii) if additionally vol(1·S_q)=vol(S_q) (equivalently [S_q]=[1·S_q] and both
        nonzero), then eta_q=eta^anab_{S_q}.
  (iv) without (iii), eta_q and eta^anab_{S_q} differ by the scalar
        [1·S_q]/[S_q] in the one-dimensional R^ss, and no equality follows.

Lemma A is the linear-algebra step: (iii) plus nonzero pilot gives equality;
without nonzero pilot or without class equality, it fails.

## 6. Consequence for C1

The eta-reduction would establish C1 if:
  - Lemma A applies with a nonzero pilot and exactly equal target classes;
  - Lemma B gives [S_q]=[1·S_q].
But Lemma B as stated gives [S_q] for eta_q and [1·S_q] for eta^anab; their
equality is exactly the volume-invariance condition (B5), which is not proved
and is generally not automatic. Therefore the eta-reduction does NOT prove C1.
The exact missing input is:
  (E-eta) there exists a source-valid S_q representing the q-pilot diagonal
          class such that vol(1·S_q)=vol(S_q), with nonzero pilot and finite
          positive volume, and with the anabelian construction well-defined.
Equivalently, eta_q belongs to the orbit of eta^anab_{S_q} at the pilot class;
this is LANA (9-1), not a consequence of Lemmas A/B.

No arbitrary S_q, no zero pilot, and no volume-class equality may be assumed.
No mixed/E3 profile is involved; no Lean/Project edits.

## 7. Verdict

Lemma A: TRUE for pointed one-dimensional R-linear isomorphisms with a
nonzero pilot and exact target-pilot equality. FALSE without nonzero pilot
(the zero-pilot counterexample T1=id, T2=2id). If only projective/volume-class
equality is known, equality holds only up to scalar.

Lemma B: The eta^anab target-pilot statement [1·S] is correct; the eta_q
target-pilot statement is [S_q] only when S_q denotes the q-pilot diagonal
class (literal LANA target is {q_v O_v}). The needed equality [S_q]=[1·S_q] is
NOT automatic: it requires vol(1·S_q)=vol(S_q), i.e. N/LGP class invariance,
and nonzero/finite positive volume. Without these, Lemma B is not an equality
of pilots and Lemma A cannot conclude eta_q=eta^anab_{S_q}.

Missing nondegeneracy/nonzero-pilot conditions:
  - pilot != 0 in R^val;
  - [S_q] != 0 and [1·S_q] != 0 (finite positive volume, not zero/empty);
  - exact target-pilot class equality, not merely nonzero or same line;
  - well-defined adelic measurable S_q;
  - orientation/pointed normalization if only projective data are used.

C1 is not obtained by the eta-reduction as stated. The exact gap is
(E-eta): source-valid S_q with vol(1·S_q)=vol(S_q), equivalently the orbit
condition (9-1). This is consistent with C9-C1-MASTER: C1 remains an
independent attainment/open lemma. target_accepted=false.
