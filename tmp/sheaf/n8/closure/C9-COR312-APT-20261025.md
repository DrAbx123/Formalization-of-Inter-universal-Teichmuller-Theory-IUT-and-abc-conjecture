## 0. Verdict

Cor3.12 的 APT 不是一个 set-theoretic parallel transport 映射；它是 Theorem3.11 的 **construction algorithm**，由三个 source-level 属性描述：

```
(IPL) input prime-strip link: output possibilities linked to the q-pilot input
      by isomorphisms of F⊩▶-prime-strips;
(SHE) simultaneous holomorphic expressibility: the algorithm and output are
      expressible relative to the arithmetic holomorphic structure of the 1-column;
(APT) algorithmic parallel transport: a construction algorithm valid/executable
      simultaneously in domain and codomain, not a set-theoretic function on regions;
(HIS) hidden internal structures: one may forget theta functions/values and treat
      Theorem3.11 as 'some algorithm' with properties IPL/SHE.
```

The q-pilot comparison is then made by:

```
(1) forming the holomorphic hull U of possible output regions;
(2) expressing U via localizations of arithmetic vector bundles (rank>1);
(3) taking a suitable positive tensor power of the determinant;
(4) applying the j-normalized log-volume;
(5) comparing the possible output log-volumes R_{≤−|log Θ|} with
    the q-pilot value −|log q|.
```

The source-level proof of Cor3.12 is valid as a **semantic/logical deduction** from Theorem3.11 + IPL/SHE/APT + determinant/log-volume normalization. It is not an explicit algorithm computing regions, and it does not give a concrete map q-pilot → theta-pilot. The exact source gaps are listed in §4.

## 1. Source steps

### 1.1 APT definition (Remark3.11.1(iv))

Source explicitly:

```
APT: this parallel transport mechanism does not consist of a simple instance of
transport of a set-theoretic region via a set-theoretic function; rather, it is a
construction algorithm simultaneously valid/executable/well-defined with respect to
the arithmetic holomorphic structures in the domain and codomain of the Θ-link.
```

The source also warns that the algorithm may yield various possible regions that cannot necessarily be directly compared with codomain structures; comparisons typically require further techniques (Remark3.9.5(vii)). HIS says one may forget theta values and treat the algorithm abstractly with IPL/SHE.

### 1.2 Cor3.12 setup (statement)

`−|log Θ|` is the procession-normalized mono-analytic log-volume (average over `j∈F_l^×`) of the holomorphic hull of the union of possible images of a Θ-pilot object, subject to Ind1/Ind2/Ind3. `−|log q|` is the same readout for a q-pilot object, not subject to Ind1/2/3. The target inequality is

```
−|log Θ| ≥ −|log q|,   equivalently C_Θ ≥ -1.
```

### 1.3 Step (xi-a)–(xi-b)

A q-pilot at (1,0) is interpreted via holomorphic log-shells; the Θ×μ LGP-link from (0,0) to (1,0) is a gluing isomorphism relating the arithmetic holomorphic structures and matching Θ-pilot at (0,0) to q-pilot at (1,0). Theorem3.11's multiradial construction yields output possibilities in U satisfying IPL/SHE/APT; Step (xi-b) says one only uses qualitative logical aspects, forgetting theta values (HIS).

### 1.4 Step (xi-c)

The algorithm yields output possibilities in `1,◦U ⊆ 1,◦U_Q`, linked by F⊩▶-prime-strip isomorphisms to the q-pilot representation on `1,◦U_Q` via the log-Kummer correspondence in the 1-column, and expressible entirely relative to the 1-column arithmetic holomorphic structure. Enlarging to the holomorphic hull `1,◦U` expresses the output not as regions in tensor products of local fields but as **localizations of arithmetic vector bundles** over local rings `O_{K_v}`. This is needed to compare with the q-pilot arithmetic line bundle.

### 1.5 Step (xi-d)

The output localizations are rank>1 vector bundles, while q-pilot is a line bundle in global realified Frobenioids. Comparison requires:

```
take a suitable positive tensor power of the determinant of the rank>1
localizations; apply the j-normalized log-volume to the region U and to the
q-pilot region; obtain R_{≤−|log Θ|} ⊆ R and −|log q|∈R.
```

The source notes the essential use of the log-Kummer correspondence in the 1-column to rectify the vertical shift/mismatch between units and log-shells.

### 1.6 Step (xi-e)–(xi-g)

SHE means expressibility subject to the condition that the q-pilot log-volume equals the fixed value `−|log q|`. The algorithm followed by holomorphic hull and log-volume yields a collection of possible output log-volumes `R_{≤−|log Θ|}` linked to `−|log q|`. Since the q-pilot value is one possible value, `−|log q|∈R_{≤−|log Θ|}`, hence `−|log q|≤−|log Θ|`; Cor3.12 follows formally. Step (xi-g)/Fig.3.8 summarizes the two tautologically equivalent computations.

## 3. Conditional APT theorem

**Theorem 3.1 (source-schema, conditional).** Let `A` be the Theorem3.11 multiradial construction algorithm with invariants IPL/SHE/APT on a fixed Θ×μ LGP-link. Suppose:

```
(A1) the q-pilot object at (1,0) is a possible input/representation in the codomain;
(A2) holomorphic hull U and the determinant/log-volume comparison are those of Step(xi-d);
(A3) the q-pilot log-volume −|log q| is the fixed value used in SHE.
```

Then the algorithm yields possible output values `−|log Θ|` with

```
−|log q| ∈ R_{≤−|log Θ|},   hence −|log Θ| ≥ −|log q|.
```

Proof. A1/A3 put q-pilot value in the output comparison set via IPL/SHE; A2 computes the same normalized log-volume on both sides; inclusion gives the inequality. QED

This is exactly the logical shape of Cor3.12 Step(xi-f); it does not construct APT explicitly.

## 4. Exact source gaps / what is not proved

1. **APT is not an explicit algorithm/map.** The source defines it by properties, not by a computable set-theoretic function on regions; no explicit output region formula or q→Θ map is given. The proof works at the level of possible log-volumes, not actual region transport.

2. **IPL/SHE are properties, not an identification of q-pilot and theta-pilot objects.** IPL gives F⊩▶-prime-strip links; SHE gives expressibility. Neither supplies a direct equality of the Θ-pilot region with the q-pilot region; the comparison goes through determinant/log-volume, not object identity.

3. **Determinant/log-volume comparison is not an explicit metric equality.** The rank>1 localizations are replaced by a positive tensor power of their determinant; the j-normalized log-volume is applied. The source does not give an explicit determinant norm equality or compute the resulting constants; it argues the two normalized log-volumes are comparable because they are both in R and the q-pilot value is in the output set.

4. **The inclusion `−|log q|∈R_{≤−|log Θ|}` is semantic/tautological** from the construction of possible outputs, not an independent numerical theorem. It depends on the q-pilot being represented as one possible output and on the hull/log-volume normalization; no explicit region-level proof is supplied.

5. **No explicit handling of Ind1/Ind2/Ind3 in the q-pilot comparison** beyond saying the q-pilot is not subject to them; the output set is subject to them. The source's logical argument uses the hull of possible images; a concrete region comparison would require resolving the indeterminacies.

6. **Hidden internal structures:** the source explicitly permits forgetting theta functions/values; any reconstruction of the actual theta-pilot comparison from APT alone is not possible. APT is a black-box-like construction algorithm in the logical proof, but the source itself justifies this via HIS; it is not an explicit theta computation.

These are source-level gaps, not counterexamples: Cor3.12 is a valid conditional/logical consequence of Theorem3.11 + IPL/SHE/APT + determinant/log-volume. The gaps matter if one wants an explicit algorithmic construction or a numerical q-pilot comparison.
