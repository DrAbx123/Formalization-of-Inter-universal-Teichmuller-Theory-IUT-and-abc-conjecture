## 4. Large-capsule construction: exact scenario and why it is outside IV

    k >= D/log pi.                                                (4.1)

For D_3: k>=93.7149712746/1.1447298858=81.8664..., so k>=82 factors at the shell radius pi. The target has at most j+1<=21 factors (j<=20). For k=21 the required radius is

    R >= exp(D_3/21)=exp(4.4626...)=86.72... > pi,                 (4.2)

which violates the per-factor shell radius pi and hence the IV container. More generally, any pair (k,R) satisfying k log R>=D with k<=21 requires R>=exp(D/21)>>pi; any R<=pi requires k>=ceil(D/log pi)>=82>21. Thus no target-compatible large capsule exists.

## 5. Product-formula lower-bound attempt (conditional hypothesis)

Another possible construction is via the product formula. If the actual archimedean possible-image set of a fixed C contains a global point x (or a positive-measure region with a generic point) whose image lies in H_C,inf, then

    sum_{v|infty} alpha_v log|x|_v + sum_p alpha_p v_p(x) log p = 0,   (5.1)

and hence

    h_inf(C) >= sum_{v|infty} alpha_v log|x|_v = -sum_p alpha_p v_p(x) log p.  (5.2)

To get h_inf>=D_3 one would need a source point with finite weighted valuation sum <= -D_3, e.g. a point divisible by p^{-N} with N log p >=D_3. The E_j q-pilot has positive p-valuation at the bad place (q has v_p(q)=6), which gives the opposite sign; the p^{-1} log-shell normalization is a construction step, not a global possible-image point automatically in H_C,inf. No source theorem supplies such a global point with the required negative valuation sum. Thus (5.2) is only a conditional criterion:

    H_prod: there is an actual global possible-image point x in H_C,inf
    whose finite weighted valuation sum is <= -D.                   (5.3)

Under H_prod, h_inf>=D is proved. Without H_prod, the product formula does not give a hull lower bound; it only gives pointwise lower bounds for points that exist in the hull. No actual H_prod is established. H_prod is an explicit extra hypothesis, not an arbitrary r_v assignment.

Independently, even if H_prod held, the resulting h_inf would have to satisfy the IV upper bound h_inf<=13.164; for D_3=93.7 this is a contradiction. Therefore H_prod plus IV containment is impossible for this profile; a source point with such negative finite valuation cannot lie in the IV-contained archimedean hull.
