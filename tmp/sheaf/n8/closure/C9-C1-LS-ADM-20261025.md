Question G3/G4: Is S_q^LS admissible/integral for eta^anab, and is eta^anab_{S_q^LS} a pointed linear isomorphism? Exact source condition; accept/reject.

Inputs: C9-C1-LOGSHELL-CONSTRUCTION-20261025.md; C9-C1-VOL-T1-20261025.md (task-441); C9-C1-ADM-NOGO; C9-C1-ADM-MULTI; LANA report snapshot C9-STRICT-DEFICIT-LANA-SNAPSHOT-20261024.tex, lines 2502-2523; IUT III xi-d.

## 0. Verdict

G3 and G4 are REJECTED as proved.

S_q^LS is a proposed log-Kummer image of the q-pilot value-group data in the log-shell container VC(LS). But:

(G1) S_q^LS is not constructed as an actual adelic measurable subset of VC(LS) with finite positive volume, and it is not shown to be canonical independent of the log-Kummer/permutation/root choices. The source IUT III xi-d gives a representation/hull of the q-pilot, not a single canonical region S_q^LS."

(G2) The key class equality T_1(S_q^LS)=[S_q] uses a map T_1:VC(LS)->VC(I), S|->1·S that is not source-defined. LANA's N/LGP action is defined on the LARGE container VC(I), not on VC(LS); task-441 already rejected this map. The class equality is exactly the q-pilot/SHE compatibility C1, so using it is circular.

(G3) S_q^LS is not proved to be an **integral structure** in the LANA sense (VC(O)-compatible/N-compatible/reference). A log-Kummer image region is a measurable subset candidate, not automatically an admissible integral structure. Admissibility requires the exact conditions (Adm_LS) in section 6; none is proved.

(G4) eta^anab_{S_q^LS} is not proved to be a pointed linear isomorphism. LANA says the anabelian construction gives such an isomorphism after fixing a suitable S; it does not assert this for S_q^LS. The target pilot [1·S_q^LS] is not proved equal to the q-pilot class; nonzero/finite-volume and pointedness are unproved. Even if eta equality were obtained, the output bridge G5 remains.

Therefore the S_q^LS route does not establish C1. No extra assumption is introduced; the exact obstruction is the missing source construction/admissibility of S_q^LS and the missing T_1/class compatibility.

## 2. G1: existence/properties of S_q^LS

IUT III xi-d represents the q-pilot object at (1,0) on 1,circU_Q via the 1-column log-Kummer correspondence. That representation is a collection/hull of possible images, subject to (Ind1)-(Ind3) and root/permutation ambiguities. It is not a canonical single subset S_q^LS of VC(LS).

To be an admissible S for eta^anab, S_q^LS must be:
- an actual subset S_q^LS subset VC(LS);
- adelic measurable;
- of finite positive volume;
- independent of arbitrary choices (or with a source-fixed choice).
None of these is proved in the construction doc:
- the log-Kummer image is described but not constructed set-theoretically;
- the representation is a collection, not a canonical section;
- the root/permutation ambiguities may change the subset while preserving its class;
- finite positive volume/adelic measurability is asserted, not proved.

G1: REJECT as proved. This is not a small technicality: without an actual S_q^LS subset, eta^anab_{S_q^LS} has no input.

## 3. G2: T_1 and class equality

The route defines T_1:VC(LS)->VC(I), S|->1·S, where 1 in N acts by LGP. LANA's N-action is on VC(I), not VC(LS):
- Step 8/line 2503: action of N on VC(I_v), constructed anabelianly after fixing the BPS/Hodge-theater isomorphism, subject to Ind1/Ind2.
- The source action is multiplication by LGP on VC(I), a measurable bijection with constant Haar Jacobian there (task-441), not a map from the small/log-shell container VC(LS) to VC(I).
- There is no canonical embedding VC(LS)->VC(I) in LANA; choosing one is an extra assumption. Different embeddings give different images/volumes.
- Even if a map T_1 is postulated, the class equality [T_1(S_q^LS)]=[S_q] is exactly the q-pilot/SHE compatibility (the C1 bridge), not a source theorem.

G2: REJECT as proved; T_1 is not source-defined, and the class equality is circular with C1. The volume-scaling audit task-441 already reached this conclusion.

## 4. G3: admissibility/integral structure

LANA's eta^anab_S construction uses S as an **integral structure** compatible with the anabelian/Frobenioid comparison, not merely as a measurable subset. Admissibility requires at least:
(A1) S_q^LS subset VC(LS) is adelic measurable;
(A2) S_q^LS is an integral structure compatible with the N/anabelian construction;
(A3) the N-action is defined on S_q^LS and 1·S_q^LS is adelic measurable;
(A4) M=1·S_q^LS defines a class in R^ss with the correct target pilot;
(A5) eta^anab_{S_q^LS} is a pointed linear isomorphism.

The route proves none of (A2)-(A5). S_q^LS is a log-Kummer image region, not proved to be a VC(O)-module/integral structure or N-compatible. The claim "S_q^LS is admissible because it is the source log-Kummer representation" is exactly the missing source condition, not a proof.

G3: REJECT as proved; admissibility is not established. If "admissible" is weakened to "measurable subset", then eta^anab_S is not total on such S (ADM-NOGO), so weakening does not help.

## 5. G4: pointed linear isomorphism

LANA says: once fix S subset VC(LS), this provides an isomorphism eta^anab_S of pointed real lines, constructed via anabelian methods. This is conditional on S being suitable; it is not a theorem for every S and in particular not for S_q^LS unless G1-G3 hold.

Even assuming eta^anab_{S_q^LS} is defined:
- the target pilot is [1·S_q^LS], not [S_q^LS]; one needs [1·S_q^LS]=[S_q] in R^ss;
- the pilot must be nonzero and finite-volume; this is not proved for S_q^LS;
- pointed linear isomorphism is an output property, not automatic from measurability;
- the route's G2 (class equality) is exactly what would give the pilot matching, and G2 is rejected.

G4: REJECT/conditional. No proof that eta^anab_{S_q^LS} is a pointed linear isomorphism with target pilot equal to the q-pilot class.

## 6. Exact source condition (Adm_LS)

The exact sufficient condition for the S_q^LS route is:

(Adm_LS) There is a canonical/source-fixed subset S_q^LS subset VC(LS) such that:
  (a) S_q^LS is adelic measurable with finite positive volume;
  (b) S_q^LS is an integral structure compatible with the anabelian/Frobenioid construction;
  (c) the N/LGP action is defined from S_q^LS to a class in R^ss, and [1·S_q^LS]=[S_q] (q-pilot class);
  (d) eta^anab_{S_q^LS} is a pointed linear isomorphism.
Then eta_q=eta^anab_{S_q^LS} by Lemma A, and C1 may follow if the eta equality is bridged to an actual output D0 with logVol(D0)=Q (G5).

No source theorem proves (Adm_LS). The construction doc's G1-G5 are precisely this condition and the output bridge; G1-G4 are not closed.

## 8. Conclusion

S_q^LS is a promising candidate because it is in the correct small/log-shell container, unlike S_q={q_vO_v}. But the construction does not establish:
- an actual canonical S_q^LS subset VC(LS);
- adelic measurability/finite positive volume;
- integral/N-compatibility/admissibility;
- a source-defined T_1 from VC(LS) to VC(I) and the class equality [T_1(S_q^LS)]=[S_q];
- that eta^anab_{S_q^LS} is a pointed linear isomorphism with the q-pilot target.
The exact missing condition is (Adm_LS). The route therefore does not prove C1. No extra assumptions, no arbitrary S, no mixed/E3, no Lean.
