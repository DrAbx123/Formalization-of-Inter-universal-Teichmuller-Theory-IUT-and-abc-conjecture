## 0. Result

There is a valid short conditional theorem: if the target hull contains the
B=I sibling region R_B and the archimedean readout satisfies
`h_inf>=-S_3`, then the b=3 B=O_K P6 inequality holds. Its proof is just
monotonicity of normalized log-volume plus the B=I local value.

But the rescue is empty in the current corpus: `R_B subset H_C` is exactly
the target-saturation/TC-B input (or an arbitrary enlargement of H_C), not a
source theorem, and `h_inf>=-S_3` is not known. If R_B is not an actual image
in H_C, the rescue changes the target object. So it is a conditional rescue
theorem, not a source proof of P6.

## 2. Conditional rescue theorem

Theorem 2.1. Assume:

(C1) the finite profile is the b=3 uniform B=O_K profile with the corrected
     C1 finite assembly;
(C2) the actual target hull contains the B=I sibling region,
     `R_B subset H_C`;
(C3) the archimedean readout satisfies `h_inf(C)>=-S_3`.

Then `h_C>=Q_p`; equivalently P6 holds for this C.

Proof. Since `R_B subset H_C`, monotonicity of the normalized log-volume
gives `h_C >= h_B + h_inf(C)` (other finite places are zero relative to the
reference; R_B contributes at least h_B). Therefore

    Q_p-h_C <= Q_p-h_B-h_inf(C)
              = -(h_B-Q_p)-h_inf(C)
              = -S_3-h_inf(C)
              <= 0,                                      (2.1)

by (C3). Hence h_C>=Q_p. QED.

At equality h_inf=-S_3 the bound is zero; if h_inf>-S_3 it is strictly
negative.

Equivalently, the B=O_K deficit D_3 is rescued by the B=I surplus S_3 only
when the B=I region is actually inside the target hull and the archimedean
term is not too negative. The B=I surplus alone (2.756 natural) is much
smaller than D_3 (93.715), so without `R_B subset H_C` it cannot rescue the
B=O_K profile.

## 3. Exact obstruction

The rescue theorem is valid but its hypotheses are not source facts:

1. **`R_B subset H_C` is TC-B/target saturation, not a theorem.** The
   B=O_K/B=I distinction is a branch of the source action; under the natural
   trace alignment B=O_K, the B=I region is not an actual source image.
   Including it in H_C is an enlargement of the original target hull. The
   target-container condition TC-B (H_C is the hull of the full actual union,
   or F is an allowed target automorphism) is missing. Without TC-B the
   inclusion is an arbitrary target enlargement.
2. **The B=I region itself is not constructed.** B=I is conditional/
   type-gapped; there is no actual source generator producing R_B. Thus even
   the local h_B=9/41 value is a conditional formula, not an actual hull
   value.
3. **`h_inf>=-S_3` is not known.** Under the B_I-zero normalization there is
   only the upper bound `h_inf<=A=13.1643936873`; no lower bound is available.
   The actual archimedean hull/radius is missing. In particular the B=I
   b=3 corridor has F<0 only when h_inf>-S_3; if h_inf<-S_3, even the B=I
   sibling does not rescue the B=O_K profile.
4. **Target saturation may change the target object.** If one defines H_C
   as the hull of all possible images including both B branches, then
   `R_B subset H_C` is definitional, but this H_C is not the original target
   hull of the fixed C. Proving P6 for the enlarged H_C does not prove P6
   for the original target.
5. **Even a legitimate full-Ind1 union** of possible images would require the
   full Ind1 target-container theorem (TC-A..H/TC-S); the current corpus does
   not prove it. Full Ind1 is the procession automorphism group, not finite
   branch translation.

Therefore the exact obstruction is:

    the rescue hypothesis `R_B subset H_C` is equivalent to the missing
    target-saturation/TC-B (or to an arbitrary enlargement), and the
    archimedean lower bound `h_inf>=-S_3` is missing.

No source-derived proof of the rescue exists.

## 4. Could another mechanism realize `R_B subset H_C`?

Checked alternatives:

- **Full Ind1 orbit / target saturation.** Legitimate only with TC-B/TC-S;
  not proved. The hull of the full orbit may contain more than one branch,
  but the actual full-Gamma branch is undetermined and H_A-full is open.
- **B=O_K actual and B=I sibling as a hull boundary.** If the target hull is
  defined by all possible images of the source object, B=I could be included
  only if the source actually produces it; under B=O_K it does not.
- **Theta/BPS gluing.** Gives local volume data, not an inclusion of the
  alternative branch region; no positive term follows.
- **Monotonicity alone.** Monotonicity requires the inclusion as input; it
  cannot create it.
- **Archimedean enlargement.** Increasing `h_inf` to exceed -S_3 helps only
  if the hull is in a large-radius regime; IV gives only an upper bound, not
  a lower bound, and the actual r_inf is missing.

None avoids the TC-B/h_inf hypotheses.

## 5. Truth dichotomy for b=3 B=O_K

(A) If `R_B subset H_C` is actual (target saturation/TC-B holds) and
    `h_inf>=-S_3`, then P6 holds for this C; the B=O_K deficit is rescued.
(B) If `R_B` is not in the original H_C (the natural B=O_K situation), then
    the local bound is only h_A, and the B=O_K conditional residual remains
    D_3-A=80.55>0; P6 fails for that C if the profile/target data are actual.
(C) If B=I is actual rather than O_K, the b=3 B=I corridor gives P6 when
    h_inf>=-S_3 and a counterexample when h_inf<-S_3.

Current corpus: B branch/H_A-full/TC-B/h_inf are all missing, so no branch
is decided. The rescue theorem is conditional only.

## 7. Conclusion

The B=I sibling region gives a valid conditional P6 theorem for the b=3
B=O_K profile: if `R_B subset H_C` and `h_inf>=-S_3`, then monotonicity plus
h_B=9/41 log p rescues D_3. But the inclusion is exactly the missing
target-saturation/TC-B input (or an arbitrary target enlargement), and the
archimedean lower bound is unproved. Without them the B=O_K residual remains
positive. The rescue is therefore conditional, not a source proof; no
arbitrary inclusion or enlargement is used.
