## 1. Verdict

C1 is NOT derivable from A1-A3 alone. The exact gap is a **type/functional
mismatch**:

- A1 gives a **link/relationship** between output data and the fixed q-pilot
  input via full poly-isomorphisms of F^value-prime-strips (F^unit x mu
  subject to Ind1/2/3);
- A2 gives log-volume invariance for actual objects/prime-strips in the same
  full-poly class;
- A3 gives the hull/determinant/log-volume framework for possible images;

but A1-A3 do not define a log-volume functional on an **arbitrary output
possibility D** and do not assert that any such D is the q-pilot input or has
log-volume Q. The equality that would be needed,

    logVol(D) = logVol_III(pi(D)) = Q,                        (1.1)

where pi(D) is the F^value-prime-strip linked to the input, is not a theorem
of A1-A3. It is the extra xi-e/xi-f construction step.

Therefore C1 is an **extra existence/identification assumption**, not a
consequence of the stated A1-A3. If one adds xi-f (source construction of the
pilot log-volume up to indeterminacies), C1 becomes a source-conclusion
candidate; it is not proved by IPL plus full-poly invariance alone.

## 2. Types and maps

Input:

- QP = q-pilot object determined by q_v, v in V_bad; Q=-|log q| is its
  canonical packet+procession log-volume (Def3.8(i), Prop3.9).
- F_QP = the associated F^value x mu-prime-strip; Q is a functional on the
  value-group portion.

Output of A1:

- O = collection of possible output data (regions in 1,circ U) produced by the
  multiradial algorithm under Ind1/2/3.
- For each D in O, A1 gives an F^value-prime-strip pi(D), linked to the
  F^value portion of F_QP by a full poly-isomorphism; the F^unit x mu side is
  subject to Ind1/2/3.
- A1 does **not** give a map D -> logVol(D) with D itself an F^value x mu
  prime-strip. The output data are possible regions/collections, not
  automatically q-pilot objects.

A2:

- logVol_III is invariant under full poly-isomorphisms of actual
  F^value-prime-strips/prime-strip objects in the same class:
      pi(D) ~ F_QP  =>  logVol_III(pi(D)) = Q.               (2.1)
- A2 does not assert that logVol(D), the normalized volume of the output
  region D, equals logVol_III(pi(D)). The region's log-volume is defined
  after hull/procession normalization in xi-d, not by pi(D).

A3:

- Hull H of the union of possible images; determinant/localization/log-volume
  framework.
- A3 gives h=-|log Theta| as hull log-volume, and the possible output
  log-volumes are subject to Ind1/2/3. It does not assert that the specific
  value Q is attained by an output region D0.

## 3. Why (1.1) does not follow

There are three possible readings, and none gives C1 from A1-A3:

(a) **D is the q-pilot object itself.** Then logVol(D)=Q trivially, but D is
    the input, not an output possibility. IPL links output to input; it does
    not say the input is one of the outputs. This is the semantic handwave
    C1 must avoid.

(b) **D is an output region with its own normalized log-volume.** A1 gives
    only pi(D) full-poly isomorphic to the input prime-strip; A2 gives
    logVol_III(pi(D))=Q. There is no A1/A2/A3 theorem
    logVol(D)=logVol_III(pi(D)). The output region's log-volume is defined
    after hull/procession normalization (A3), and source xi-d says it is h,
    not Q.

(c) **D is the full linked prime-strip.** Then D is not an output region but
    the F^value-prime-strip class of the input; again D is the input object,
    not a new output possibility. C1's existential quantifier over output
    possibilities is not satisfied.

Thus A1-A3 give a **relation** between output and input prime-strips, not an
**attainment** of Q by an output possibility. C1 is exactly the missing
attainment/identification step.

## 4. Countermodel to derivability (type-level)

The following abstract model satisfies the A1/A2/A3 structure but not C1; it
shows C1 is not a formal consequence of the stated types.

- Let Q=5 be the q-pilot input log-volume.
- Let O={D} be a one-element output collection. Let pi(D) be a prime-strip
  full-poly isomorphic to F_QP, so A2 gives logVol_III(pi(D))=Q=5.
- Define the output region D to have hull log-volume h=2 (a separate
  normalized-volume functional on regions), with A1's link pi(D) only on the
  prime-strip portion.
- A1 (IPL link) holds for pi(D); A2 holds on prime-strips; A3 gives the hull
  H of the possible images with h=2.
- But there is no output D0 with logVol(D0)=5, because the only output region
  has volume 2. C1 fails.

This is not an actual IUT target; it is a **type-level countermodel** showing
that A1-A3 do not force C1. Actual source xi-f adds the bridge
"output possibilities constitute the input pilot log-volume up to
indeterminacies"; that bridge is not in A1/A2/A3.

## 5. If xi-f is added

The source xi-e/xi-f step says the multiradial construction of output
possibilities constitutes a construction of the pilot-object log-volume of the
input, perhaps only up to indeterminacies. Under that source step:

    Q in R_{<= -|log Theta|}

is the source's formal inclusion. C1, read as "there is an output possibility
with log-volume Q", is then a source-conclusion candidate, but:

- it depends on xi-f, which is not A1/A2/A3;
- the source qualifies it as "perhaps only up to some sort of approximation";
- it is a statement about possible log-volumes, not necessarily an exact
  output object D0.

Without xi-f, C1 is not derived.

## 6. Exact gap

The missing statement is:

(C1-bridge) For every output possibility D of the multiradial algorithm,
or at least for one D0, the normalized log-volume functional on the output
region agrees with the F^value-prime-strip log-volume of the linked input
prime-strip, and the output data realize the input q-pilot value Q:

    logVol(D0) = logVol_III(pi(D0)) = Q.                      (6.1)

A1 supplies the full-poly link pi(D0) ~ F_QP. A2 supplies
logVol_III(pi(D0))=Q. Neither supplies the first equality logVol(D0)=...
A3 supplies hull/determinant framework but not the existence of such D0.

This is an exact gap, not a numerical error. It is distinct from the
normalization identities N1-N4 and from the object identity T_can.

## 8. Conclusion

C1 is not a consequence of A1 (Theorem3.11), A2 (Prop3.9), and A3
(Remark3.9.5) alone. IPL gives a full-poly link between output prime-strips and
the q-pilot input, and Prop3.9 makes the linked prime-strip log-volume Q, but
there is no A1-A3 theorem identifying the output **region** log-volume with
that prime-strip log-volume or producing an output possibility with log-volume
Q. The equality logVol(D0)=Q is exactly the xi-e/xi-f construction step, not
IPL invariance. Therefore C1 is an extra assumption; the exact gap is
C1-bridge (6.1). With xi-f added, C1 becomes a source-conclusion candidate
subject to the source's approximation clause, not a theorem of A1-A3.
