## 1. Capsule-full poly-automorphism data

IUT I Def4.10: an n-procession P_1->...->P_n has P_j a j-capsule; each arrow is the collection of all capsule-full poly-morphisms. At a level, a capsule-full poly-automorphism consists of:
- a permutation sigma of the capsule index set (a finite factor permutation);
- for each factor, a D-prime-strip isomorphism (full poly-isomorphism of the local components).

At a nonarchimedean finite place p, the D-prime-strip isomorphism acts on the local K_+ by an actual Out(G_K)-type additive map alpha_+. The local unit group O_K^x is reconstructed; alpha^+ acts on it by an isometry (valuation preserving), and the log compatibility is
    alpha_+(log u)=log(alpha^x u),  u in O_K^x.                       (1.1)
For the tame e=41<p-1 type, log identifies the principal units U^1=1+m with J=m; (1.1) shows alpha_+(J) is again the log of a principal unit, hence alpha_+(J) subset J. Since alpha_+ is invertible (D-prime-strip isomorphism), equality holds:
    alpha_+(J)=J.                                                     (1.2)
More precisely, the valuation filtration m^n is preserved by alpha^x and log; alpha_+ maps m^n to m^n, so (1.2) is an equality of Z_p-lattices (not only Q_p-subspaces). It need not be O_K-linear/scalar; a GL_e(Z_p) lattice automorphism is enough.

## 2. Tensor and row argument

For a B=I row j, r=j+1, s=s_j=floor(bj^2/e),
    L_B,r=p^{s-r+1}J^{tensor r}.                                     (2.1)
The capsule action is:
- index permutation: permutes the r tensor factors, so J^{tensor r} maps to itself (up to factor order); p^{s-r+1} is unchanged;
- D-prime-strip isomorphisms: alpha_+ acts factorwise on J^{tensor r}; by (1.2),
    alpha_+^{tensor r}(J^{tensor r})=J^{tensor r};                    (2.2)
- Q_p-linearity: alpha_+(p^{s-r+1}y)=p^{s-r+1}alpha_+(y), so the p^... scalar is preserved.
Therefore
    g(L_B,r)=p^{s-r+1}J^{tensor r}=L_B,r.                            (2.3)
If the row/rank is permuted by the capsule action, g(L_B,r)=L_B,r' for another allowed row r'; the envelope R_B is the union over allowed rows, so the image remains inside it.

The B=O_K row hull R_A is contained in R_B (task-298); hence any B=O_K possible image also lies in the envelope. B=O_K/B=I are the only local branch classes by TAME §6; no third local lattice.

Consequently every finite possible-image lattice is contained in some R_B,r; adding the arch component gives H_C subset R_B+arch and h_C<=H_B+h_inf. This proves NPC/U under (I1)-(I3).

## 3. Ind2/Ind3/BPS/Theta factors

## 4. Exact non-invariance if J is scaled or moved

If a source action violates (I1)/(I3):
(a) alpha_+(J)=p^k J with k!=0. Then
      alpha_+(L_B,r)=p^{s-r+1}(p^k J)^{tensor r}=p^{kr}L_B,r.        (4.1)
  For k<0, p^{kr}L_B,r is larger (fractional p-power toward I), not contained in R_B; its normalized height shifts by -kr>0:
      nu(p^{kr}L_B,r)/logp = nu_B,r/logp-kr.                         (4.2)
  This would be a uniform source-valid extra image outside R_B and would violate NPC/U. For k>0, the image is smaller and stays inside; no extra.
(b) alpha_+(J)=I=p^{-1}J (one-step log-shell/B=I normalization): then with r factors,
      alpha_+(L_B,r)=p^{-r}L_B,r,                                   (4.3)
  which is the B=I row normalization already classified; it is not a new third class, and repeated p^{-1} is forbidden by the source log-domain. For k=-1 formula (4.1) gives the B=I shift; for k=-N with N>=2 it would produce an unclassified larger lattice; no source generator is constructed.
(c) An action sending J to a non-comparable lattice would escape R_B; it is not produced by the unit/log/D-prime-strip data, whose alpha_+ is a lattice automorphism of J.

No source-valid generator with k<0 (beyond the single B=I normalization already in L_B) or with non-comparable J has been constructed. If one existed, (4.1)/(4.2) gives the explicit uniform outside-R_B image. The exact remaining source caveat is precisely the proof that full Ind1/Ind2/Ind3 D-prime-strip isomorphisms have k=0 on J (or only the classified B=I shift); the unit/log reconstruction gives k=0 for the actual Out(G_K) unit action, but the full Ind1/2/3 factorization is not a Kondo theorem.
