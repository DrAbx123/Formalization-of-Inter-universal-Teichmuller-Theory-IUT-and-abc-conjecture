## 1. Exact paper statements

### 1.1 Kondo 2026: actual reconstruction map and its image

Let k/Q_p be a finite extension, G = G_k, d = d(G) = [k:Q_p], p = p(G), and let
k_+(G) be the reconstruction of the underlying additive Q_p-vector space. The
paper uses:

- Lemma 1.6: the action
  `Out(G) -> Aut_{Q_p}(k_+(G)) ~ GL_d(Q_p)`
  defined via the mono-anabelian reconstruction algorithm is continuous; the
  induced map `Phi` is continuous and closed.
- Theorem 1.2 gives Jannsen-Wingberg-type generators
  `sigma, tau, x_0, x_1, ..., x_d`, positive integers s,t,u, and
  `x_1' in closure(<sigma,tau,x_1>)`, with the relations
  (3) `sigma tau sigma^{-1} = tau^{p^{f(G)}}`, and
  (4)(a)/(b) the even/odd d relation. For odd d,
  `sigma x_0 sigma^{-1} =
    (prod_{j=1}^{p-1} x_0^{u^{p-j}} tau)^{varpi t/(p-1)}
    x_1^{p^s} [x_1,x_1'][x_2,x_3]...[x_{d-1},x_d]`.
- Following Theorem 1.2, `y_i in k_+(G)` is the image of `x_i` under
  `P(G) -> I(G) -> O^times(G) -> k_+(G)`. Lemma 1.3: if `d(G)>1` and either
  `p(G)>=3` or `a(G)>=2`, then `y_1,...,y_d` is a Q_p-basis of `k_+(G)`.
- Definition 3.2: for odd d, put `g=(d-1)/2` and embed
  `Sp_{2g}(Z_p) -> GL_d(Q_p)` by
  `A |-> diag(1, A)` (the displayed matrix is
  `[[1, 0_{1 x 2g}], [0_{2g x 1}, A]]`).
- Lemma 3.3: if `d(G)>=3`, then `Phi(Out(G))` contains this embedded
  `Sp_{2g}(Z_p)`; in particular
  `dim(Im Phi) >= 2g^2+g`.

The proof of Lemma 3.3 uses the earlier set-theoretic map

`rho : Mod(S \ {P}) -> Out(G)`

which is *not necessarily a group homomorphism* (Remark 2.18), but which fits a
commutative diagram with the surjective map `Mod(S \ {P}) -> Sp_{2g}(Z)` and
`Phi`. The closed subgroup `D` of `Out(G)` topologically generated by the
image of `rho` then satisfies `Phi(D) superset Sp_{2g}(Z_p)`. This is a
containment of a closed subgroup image, not an assertion that `rho` splits or
that `Out(G)` contains a specified copy of `Sp`.

### 1.2 Kondo 2025: boundary-word presentation, trace, mapping class rho

- Theorem D is the Jannsen-Wingberg presentation quoted in the context file:
  generators `sigma, tau, x_0,...,x_d`; `P(G)` pro-p and topologically
  normally generated by the `x_i`; `sigma tau sigma^{-1}=tau^{p^f}`; one
  further relation, with odd-d form
  `sigma x_0 sigma^{-1} =
    (x_0')^t x_1^{p^s} [x_1,x_1'][x_2,x_3]...[x_{d-1},x_d]`.
- `F : G -> k_+` is the composite of the abelianization/reciprocity map, the
  projection to `O_k^times`, and the p-adic logarithm; `y_i=F(x_i)`; these
  `y_i` are a basis of `k_+` for odd p and d>1.
- Theorem 1.3: for p odd and d_k>=2, the trace kernel is
  - for odd `d`: `ker(Tr_{k/k^{(d=1)}}) = <y_2,...,y_d>_{Q_p}`;
  - for even `d`: `ker(Tr) = <y_1,y_3,...,y_d>`.
  In particular, for odd d the trace is nonzero on `<y_1>` and vanishes on
  `<y_2,...,y_d>`.
- Section 2 constructs `rho` from the mapping class group by assigning the
  generators `a_i,b_i` of the punctured surface group to the JW generators
  `x_{2i},x_{2i+1}` in the odd-d case, lifting boundary-fixing mapping classes
  to `Aut(pi_1)`, and using the JW presentation to induce actual automorphisms
  of `G_k`. The map `rho` is a map of sets, not known to be a homomorphism;
  Remark 2.16 identifies the Dehn twist generators `phi_i, phi_i', phi_i''`
  with longitude/meridian/adjacent-hole twists. Theorem 2.17 states that the
  natural map `Mod(S \ {P}) -> Out(pi_1) -> Aut(H_1) ~ GL_{2g}(Z)` has image
  `Sp_{2g}(Z)`.
- The 2026 Theorem 2.6 proof contains the commutative diagram
  `alpha_+ o log_k = log_k o alpha^times`; this is the exact compatibility of
  the reconstructed additive action with the actual unit logarithm.

## 2. Assembled actual donor statement

Let K/Q_p be finite with `d=[K:Q_p]=2g+1>=3`, p odd (in the intended C9 local
type p>e+1, hence p>=5), G=G_K, and Phi as in Kondo 2026. Define

`D = closed subgroup of Out(G) topologically generated by rho(Mod(S \ {P}))`

and, using the embedded `Sp_{2g}(Z_p) subset GL_d(Q_p)` of Definition 3.2,

`H = Phi^{-1}(Sp_{2g}(Z_p)) subset Out(G)`.

Then:

1. `H` is a closed subgroup of `Out(G)` and `Phi(H)=Sp_{2g}(Z_p)`.
   *Proof of what is used:* `Phi` is continuous and `Sp` is closed, so the
   preimage is closed. The reverse inclusion follows because
   `Phi(Out(G)) superset Sp`: for each `A in Sp` choose an outer class with
   `Phi(alpha)=A`; it lies in `H`. Thus `Sp subset Phi(H)`, and the other
   inclusion is by definition. This is the correct replacement for "the image
   of rho is Sp"; it does not assume a homomorphic section and does not claim
   `H` is isomorphic to Sp.
2. If the 2025 trace basis `y_1,...,y_d` is the same basis used in the 2026
   embedding (see the basis-alignment caveat), then, with
   `U=<y_1>`, `W=<y_2,...,y_d>`:
   `k_+=U direct-sum W`, `dim U=1`, `dim W=2g`,
   `gamma_+|U = id_U`, and `Phi(H)` acts as `Sp_{2g}(Z_p)` on `W`.
   This is the precise form of the context file's equation (2). The paper
   itself only gives the matrix embedding and the containment, not this
   decomposition as a separate theorem.
3. For `gamma in H`, the trace formula
   `Tr_{K/K^{(d=1)}}(gamma_+ x)=Tr(x)`
   holds, because `gamma_+|U=id` and `W=ker Tr` (2025 Theorem 1.3). In the
   tame totally ramified C9 local type, `K^{(d=1)}=Q_p`, so this is the
   `Tr_{K/Q_p}` formula used in the context file.
4. Every actual automorphism representing a class in `H` preserves
   `O_K^times`; by the log compatibility it preserves
   `J = log(O_K^times) = m_K` in the low-ramification regime
   `e<p-1`. This is an actual lattice action, not merely an abstract
   linear-algebra action.

  relation (2026 has the extra `(prod ... tau)^{varpi t/(p-1)}` factor), so

- The construction `H=Phi^{-1}(Sp)` with `Phi(H)=Sp`; this is valid, but the

- The classification of full-rank `Sp_{2g}(Z_p)`-stable lattices in `W` as
  scalar multiples of the standard lattice; this is a standard symplectic
  lemma, but it is not stated in Kondo 2026/2025.
- The orbit-generation consequences (closed span of `H`-orbits of
  `pi^t O_K` equals `m`, the length/trace computations, and the normalized

  standard lattice lemma and the actual trace formula, but they are not
  theorems of the cited papers.

### Exact hidden hypotheses / convention issues

1. **rho is not a homomorphism.** 2025 Remark 2.18 explicitly says it is not
   clear whether suitable liftings make `rho` a group homomorphism. Therefore
   one cannot write `rho(Mod) = Sp`, cannot choose a homomorphic section
   `Sp -> Out(G)`, and cannot multiply chosen lifts to get the expected
   symplectic matrix product. The closed subgroup `D` and the preimage `H`
   are the correct constructions. `H` may be larger than the abstract Sp; its
   image is exactly Sp on `k_+`.
2. **Boundary-word free automorphisms are not automatically actual Galois
   automorphisms.** The context file says one may take free group
   automorphisms preserving the JW boundary word. The cited papers do not
   prove that every such free automorphism lies in the image of the mapping
   class group `Mod` or in `Out(G_K)`. The actual source construction is
   `rho` restricted to the mapping class group/Dehn twists. The single
   substitution `x_2 |-> x_2 x_3, x_3 |-> x_3` is a valid illustration of a
   Dehn twist preserving `[x_2,x_3]`, but it does not prove that all Sp
   generators or all Sp matrices come from such simple pair substitutions.
   The full Sp donor must cite 2026 Lemma 3.3 / 2025 Section 2, not the
   boundary-word substitution claim alone.
3. **Basis alignment.** The trace theorem is stated for the 2025 JW basis;
   the symplectic embedding is stated for the 2026 basis. If these are not
   the same (or related by an outer automorphism whose matrix is the identity
   on the trace-adapted decomposition), then `H` fixes a different line, the
   matrix `diag(1,Sp)` need not be adapted to `ker Tr`, and the trace formula
   (3) of the context file does not follow. This is the main convention gap
   in the package. The natural reading is that both are the standard
   Jannsen-Wingberg normalization `y_i=F(x_i)`, but this should be stated as
   an explicit compatibility assumption or checked against [N-S-W]/[H-N].
4. **Trace target.** 2025 Theorem 1.3 is for
   `Tr_{k/k^{(d=1)}}`, not always `Tr_{k/Q_p}`. The identification with
   `Tr_{k/Q_p}` used in the C9 local type requires `k^{(d=1)}=Q_p`, which
   holds in the tame totally ramified cyclic case `e=ell`, `f=1`, but must not
   be transported to extensions with nontrivial residue degree without the
   corresponding `k^{(d=1)}`.
5. **Paper standing assumptions.** 2026 Lemmas 1.3/1.6 need
   `d(G)>1` and `p(G)>=3` or `a(G)>=2`; Lemma 3.3 needs `d(G)>=3`. For the
   local type `d=2g+1>=3`, `p>e+1>=6`, these hold, but the extra hypotheses
   should be recorded. The 2026 paper's "nontrivial finite Galois extension"
   framing is not itself needed for Lemma 3.3; no Lubin-Tate or
   Hodge-Tate non-intrinsicality statement is imported into C9.
6. **Lattice/orbit inference.** `J=m` requires the low-ramification
   `e<p-1` computation from the previous package; the identification of
   `H`'s action with the actual unit action requires 2026 Theorem 2.6 and the
   AbsTopIII reconstruction (the latter was not re-proved here). The
   standard-lattice classification and the resulting orbit generation are
   mathematically standard but are not part of the cited Kondo theorems.
7. **Integrality of the relevant Sp matrices.** The standard symplectic
   matrices used (including `diag(1,-I_W)`) are integral because p is odd;
   `1/2 in Z_p` is used for the `U/W` projections. This is a genuine
   hypothesis, not a convenience.
8. **Convention direction.** AbsTopIII transfer conventions can invert the
   unit action; if `alpha^times` is replaced by its inverse, the symplectic
   matrix is replaced by its inverse, and the line `U` and `W` are still
   fixed. The orbit-generation statements are unchanged, but a written proof
   must fix the convention once and use it consistently.
