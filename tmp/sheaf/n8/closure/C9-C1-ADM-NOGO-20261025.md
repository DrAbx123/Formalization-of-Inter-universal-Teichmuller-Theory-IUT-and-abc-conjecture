## 0. Verdict

**eta^anab_S 不是在任意 measurable S 上 total 的。** LANA 的 `R^ss` 是 **adelic and measurable** 子集的 volume 类；要定义 `eta^anab_S`，至少要 `M=1·S` 也在 `R^ss` 中（adelic measurable，且 action 可定义）。`S` measurable 本身不保证 `1·S` adelic measurable 或 N-stable；因此 measurable 域上的 totality 未证且一般不成立。

C1 的 S_q 路线还需要 q-pilot diagonal 满足 exact admissibility，尤其是它必须位于 `VC(LS_uv)` 的 source log-shell container 并作为 integral structure，而 q-pilot 是 codomain/large volume container 的 target；这个 type/container compatibility 未证。故 totality 加 S_q 不能直接给 C1；LANA 继续称 main goal unproven 是 consistent 的。

## 1. LANA 的 exact definitions

LANA §9.2:

```
R^val, R^ss are pointed one-dimensional real lines;
R^ss = { T ⊂ VC(I_uv) | adelic and measurable } / ~,
T ~ T' iff vol(T)=vol(T');
for S ⊂ VC(LS_uv), M=1·S (action of 1∈N) represents LGP·S;
the class of M in R^ss is the target pilot;
eta^anab_S : R^val → R^ss is the anabelian comparison.
```

Note the source writes `S⊂VC(LS_uv)`, while the target pilot is the class of `M=1·S`. It does not state a theorem that this construction works for **all** measurable subsets; it states the construction after fixing S.

## 2. Totality on measurable S?

No. The following conditions are implicit in `eta^anab_S`:

```
(T1) S is adelic and measurable (not just measurable in a product sense);
(T2) the N-action is defined on S and 1·S is adelic measurable;
(T3) S is an integral structure compatible with the anabelian/Frobenioid comparison;
(T4) M=1·S defines a class in R^ss and the target pilot is well-defined;
(T5) the resulting map is a pointed linear isomorphism.
```

Only (T1) is stated by the word measurable; (T2)-(T5) are construction requirements. A measurable subset S with `1·S` not adelic measurable is an immediate counterexample to totality: M has no class in R^ss, so eta^anab_S is undefined. The source gives no theorem that the N-action preserves adelic measurability for arbitrary measurable S.

### Counterexample schema

Take a measurable `S` whose translate `1·S` has non-adic/unbounded support (e.g. a subset whose local components fail the restricted-product compactness condition defining `VC(LS_uv)`). Then `S` is measurable but `M=1·S` is not an element/class of `R^ss`; `eta^anab_S` has no target pilot. This is a type-level counterexample, not an arithmetic counterexample; the source does not exclude it. No totality theorem.

## 3. If totality were granted, where does C1 fail?

Suppose eta^anab_S were total on all measurable S. Then to conclude C1 via S_q one still needs:

```
(Q1) S_q (q-pilot diagonal {q_v O_v}) is measurable and lies in VC(LS_uv);
(Q2) S_q is N-stable / admissible integral structure;
(Q3) 1·S_q has the same class in R^ss as the q-pilot pilot {q_vO_v};
(Q4) eta^anab_{S_q} and eta^q are both pointed linear isomorphisms.
```

The source's S_q is described as the q-pilot diagonal embedded in the large volume container `VC(I_uv)` (target/codomain), whereas eta^anab_S takes `S⊂VC(LS_uv)` (source log-shell container). This is a container/type mismatch: q-pilot diagonal is target data, not automatically an admissible source integral structure S. The LANA main goal is precisely to find some suitable S; it never proves S=S_q is admissible. Thus totality of eta^anab_S on measurable S would not by itself solve (Q1)-(Q4), and LANA's “unproven” status is not a flaw but consistency: the missing step is S_q admissibility/container compatibility.

Even if (Q1)-(Q4) held, Lemma A/B of C9-C1-LANA-ETA-REDUCTION gives map equality only if eta^anab_{S_q} is defined and its pilot class matches; total measurable-domain would supply only the first if S_q measurable/admissible.

## 4. Exact admissibility condition for S_q/C1

The exact sufficient statement is:

```
(Adm_q)  S_q ⊂ VC(LS_uv) is adelic measurable; stable under the N-action;
         the class of M=1·S_q in R^ss equals the q-pilot pilot class;
         and eta^anab_{S_q} is a pointed linear isomorphism.
```

Under (Adm_q), C1 follows from the linear/pointed comparison (Lemma A/B). (Adm_q) is exactly the missing LANA main goal for S=S_q; it is not a consequence of measurable totality alone. No source theorem proves (Adm_q); choosing S_q by hand would be arbitrary.

## 5. Why LANA still calls it unproven

LANA's main goal is

```
∃ suitable S with eta^q = eta^anab_S.
```

The word “suitable” encodes (Adm_q)/(T1)-(T5). The report's sentence “once we fix S … this provides an isomorphism” is conditional on the construction being defined; it is not a totality theorem on all measurable subsets. The report does not prove S_q is suitable, and it does not prove that the N-action preserves adelic measurability. Therefore LANA's unproven label is correct: the missing content is admissibility/container compatibility, not a contradiction with totality.

## 7. Conclusion

eta^anab_S is not total on arbitrary measurable S: `R^ss` requires adelic measurable classes, the N-action and integral-structure conditions are undocumented for general S, and `1·S` may fail to define a class. The q-pilot diagonal S_q is target data in a different volume container; its admissibility as a source S in VC(LS_uv) is unproven. Therefore C1 does not follow from measurable totality plus S_q; the exact missing condition is (Adm_q) — S_q lies in VC(LS_uv), is adelic measurable/N-stable, has matching pilot class, and yields a pointed linear isomorphism. LANA's main goal remains open; no arbitrary S, no mixed/E3, no Lean/Project edits; P6 open.
