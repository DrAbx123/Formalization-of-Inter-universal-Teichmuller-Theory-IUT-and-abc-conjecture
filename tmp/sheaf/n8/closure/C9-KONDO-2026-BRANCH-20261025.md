## 2. What Kondo 2026 actually states

### 2.1 Q_p-basis y_i

Theorem 1.2 gives a Jannsen-Wingberg-Diekert presentation of G by
sigma,tau,x_0,...,x_d.  After the theorem the author writes (mining quote):

"for each i=1,2,...,d(G), write y_i in k_+(G) for the image of x_i in k_+(G)
by the composite P(G) -> I(G) -> O^times(G) -> k_+(G)."

Lemma 1.3 then states (mining quote):

"the d(G) elements y_1,...,y_{d(G)} ... form a basis of the Q_{p(G)}-vector
space k_+(G)."

This is explicitly a **Q_p-basis**, not a Z_p-basis of O_K, J, or a trace-dual
lattice.  No primitive normalization of y1 is given.

### 2.2 Out action and Phi

Lemma 1.6 defines the continuous action Out(G) on k_+(G) and

    Phi: Out(G) -> Aut_{Q_p}(k_+(G)) -> GL_d(Q_p),                 (2.1)

continuous and closed, using the basis y_i.  This is Q_p-linear; the source
does not discuss an integral lattice, O_K, J, or I.

### 2.3 Mapping class subgroup D and Sp embedding

Definition 3.2 defines the mapping class group Mod(S minus {P}) and a map
rho: Mod(S minus {P}) -> Out(G), not necessarily a homomorphism, with
commutative diagram through Phi and Sp_{2g}(Z).  It then defines D subset
Out(G) as the closed subgroup topologically generated by im(rho).

For odd d, Sp_{2g}(Z_p) is embedded in GL_d(Q_p) by

    A |-> [1  0_{1 x 2g}; 0_{2g x 1}  A],                         (2.2)

i.e. the first coordinate is fixed.  Lemma 3.3 proves

    Phi(D) contains Sp_{2g}(Z_p).                              (2.3)

This is the only "fixed first coordinate/fixed line" statement in Kondo 2026.
It is a statement about the Q_p-linear image Phi(D), not about an actual
integral fixed line U=Q_p y1 inside J, not about W=ker Tr, and not about the
full corrected H=Phi^{-1}(Sp).  Kondo 2026 defines D, not H, and proves only
containment Phi(D) contains Sp; it does not prove D=Phi^{-1}(Sp) or that every
element of D has the fixed first coordinate.

### 2.4 alpha_+

Theorem 2.6 characterizes Hodge-Tate-ness by the condition that alpha_+ be a
Q_p-linear combination of elements of Gal(k/Q_p).  This is a Q_p-linear
criterion; the source does not state that alpha_+ preserves O_K, J, or I, and
does not give an integral additive lift.

## 3. Exact gap

Kondo 2026 leaves all of the following missing:

(G1) **No Z_p-basis/integral lattice.**  y_i are only a Q_p-basis; no
     Z_p-span, no O_K, no J=pi O_K, no I=p^{-1}J.

(G2) **No trace pairing.**  There is no trace form, no trace-dual lattice, and
     no W=ker Tr in the paper.  The Q_p first-coordinate line of (2.2) cannot
     be identified with a trace-kernel decomposition.

(G3) **No integral fixed-line normalization.**  The fixed first coordinate is
     a matrix condition in GL_d(Q_p).  It does not make y1 primitive in J,
     does not determine the p-coefficient a in y1=a p+l, and does not give
     alpha_+(J)=J or alpha_+(O_K)=O_K (H_A-lite/full).

(G4) **No y1=lambda y0.**  The JW-F relation y1=lambda y0 used in tasks
     282/328/335 is derived from the Kondo 2025 relations; it is not stated in
     Kondo 2026.  In any case it gives only kappa(y1)=kappa(y0), not kappa.

(G5) **No B=O_K/B=I statement and no kappa.**  The paper has no B-branch
     theorem, no kappa, no H_A-full, and no comparison with I/J.  Its main
     theorem is about Aut-intrinsic Hodge-Tate-ness of Lubin-Tate
     representations, a different question.

Therefore the actual B branch cannot be settled from Kondo 2026 alone.
