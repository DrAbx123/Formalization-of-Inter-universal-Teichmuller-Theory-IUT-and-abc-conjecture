## 0. Verdict

**Tool IV 不成立：没有 source 定理使 `O_vol` 是 closed interval，也没有 Ind1/2/3 机制强制 Q 在 `O_vol` 或其 closure 中。** 该猜想把目标 C1 的一个充分条件（Q 已被 output volumes 逼近/包含）当成结构性质；A1-A3 不提供 O 的连通性/闭性/log-volume 连续性，Ind1/2 保 volume、Ind3 只给 upper semi inequality，不生成新值。

## 1. Definitions and target

```
O = multiradial possible output set (mod Ind1/2/3);
O_vol := { logVol(D) | D∈O } ⊂ R;
h = -|log Θ| = logVol(hull), upper bound for outputs if monotonicity;
Q = -|log q|.
```

Tool IV conjecture: `O_vol` is a closed interval in `(-∞,h]` and contains values arbitrarily close to Q from above (or Q is a limit point forced by Ind1/2/3). Then Q∈O_vol, so ∃D0∈O with logVol(D0)=Q (C1).

## 2. What A1/A2 actually give

A1 gives O as possible output data/regions subject to Ind1/2/3, with IPL/SHE/APT; A2 gives normalized log-volume on the relevant prime-strip data; A3 gives hull/determinant geometry. None gives:

The possible output set is a union of possible images under Ind1/2/3; there is no source connectedness/convexity theorem for it. The hull H is a region containing O, not O itself; h=logVol(H) need not be attained by any output.

## 3. Ind1/2/3 cannot force Q

From the explicit action analysis (C9-C1-IND):

```
Ind1 (label/procession permutations): logVol invariant;
Ind2 (tensor-factor/unit isomorphisms): logVol invariant (unit log 0);
Ind3 (upper semi-compatibility): only inequality, no exact new volume value.
```

Hence `O_vol/Ind1,2 = O_vol`, and Ind3 adds at most upper-semi closure. If Q is not already in `O_vol` or a limit of its values, no Ind action creates it. In particular:

```
O_vol = {0} and Q > 0  is compatible with Ind1/2/3 actions;
Q is not in O_vol and not a limit point; C1 fails in that model.
```

The source does not exclude this model via A1-A3 alone; xi-f is the missing assertion.

## 4. Countermodel to the formal inference

Take an abstract multiradial output set

```
O = {D1} with logVol(D1)=0,  h=1,  Q=1/2.
```

Then:

```
- O_vol={0} is closed (finite) but not an interval containing Q;
- Ind1/2 preserve 0; Ind3 only gives upper semi inequalities;
- Q∉O_vol and Q is not a limit point (distance 1/2).
```

All structural A1/A2/A3 properties used by Tool IV (O exists, logVol, hull upper bound h, Ind actions) hold in this abstract model, yet C1 fails. This is a countermodel to the **inference**, not an actual admissible C; it shows Tool IV needs additional source theorems not in A1-A3. If one adds xi-f as a target theorem, the model is excluded by xi-f itself — circular.

## 5. Conditional lemma (valid but insufficient)

**Lemma 5.1.** If

```
(IV-a) O_vol is a closed interval [a,b];
(IV-b) a ≤ Q ≤ b;
```

then Q∈O_vol, so ∃D0∈O with logVol(D0)=Q. Similarly, if O_vol is closed and Q∈closure(O_vol), then Q∈O_vol.

Proof. Closed interval contains all points between endpoints; closed set contains its closure. QED

But (IV-a)/(IV-b) are exactly the unproved source properties. One cannot use `h≥Q` (or `Q≤h`) as (IV-b): `h≥Q` is the Cor3.12/P6 target, not a premise.

## 6. Exact missing statements

To make Tool IV a proof, one needs at least:

```
(T4-a) a topology/measurable structure on O and continuity of logVol;
(T4-b) compactness/connectedness of O or of the relevant possible-image family;
(T4-c) a theorem that O_vol is an interval and closed (or Q∈closure(O_vol));
(T4-d) a bracketing output with volume ≤Q and one with volume ≥Q, independent of C1;

```

None is in A1-A3/Theorem3.11/Prop3.9/Remark3.9.5. The source's xi-e/f is the target membership, not an interval/closedness theorem.
