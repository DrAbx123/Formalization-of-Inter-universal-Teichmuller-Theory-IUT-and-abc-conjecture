source-level BPS alternative. The source value profile is the product

    g_{r,v,j} = zeta_{r,v,j} a^{j^2},   a^{2l}=q,   l=41,   (0.1)

not the root `a` alone. Under

    a' = zeta a,   zeta^{82}=1,

one has `g'_{r,v,j}=g_{r,v,j}`. The Gaussian generators, Kummer classes,

## 1. Source data and root/cyclotome normalization

For the b=273 profile, E_{546} gives an actual local Tate parameter q with
q^{1/41} and qhat=q^{1/82}; the local value formula is

    theta(U_j)/theta(U_0)=q^{-j^2/2},
    g_{r,v,j}=zeta_{r,v,j} a^{j^2},   j=1,...;               (1.1)

where `a` is a chosen 82nd root of q and `zeta_{r,v,j}` is the source
finite root unit (mu_{2l} ambiguity, covering/sign/inversion included in the
realization r). The source cyclotomic rigidity identifies the coefficient
systems; the ambiguity in `a` is exactly the finite root/cyclotome ambiguity
of the value formula.

The BPS label contains the value profile, monoid, Kummer classes, and
cyclotomic rigidifications, not an isolated numerical root `a`. Thus the
correct source object is the class of pairs `(a,zeta_j)` under the root
rotation (0.2), or equivalently the product `g_j`.

## 2. Absorption theorem

Theorem 2.1. Let `a'=zeta a` with `zeta^{82}=1`, and set
`zeta'_j=zeta^{-j^2} zeta_j`. Then:

(i) `g'_j=g_j` for every j;
(ii) the Gaussian monoid `Gamma_{r,v}=Delta(U_v) * xi^N` with
     `xi=(g_j)` is unchanged;
(iii) the Kummer class/restriction and the Theta/Gaussian value profile are
      unchanged;
(iv) the q-pilot/target column, which uses q and the b=273 q-order, is
     unchanged.

Proof. Direct computation:

    g'_j = zeta'_j (a')^{j^2}
         = (zeta^{-j^2} zeta_j)(zeta a)^{j^2}
         = zeta^{-j^2} zeta^{j^2} zeta_j a^{j^2}
         = g_j.                                             (2.1)

The monoid is generated by the values `g_j`, the diagonal unit part
`Delta(U_v)`, and the source torsion; none changes. The Kummer class of a
theta unit depends on the class of its root, not on the chosen representative;
changing `a` together with `zeta_j` leaves the Kummer restriction unchanged.
q is unchanged, so qhat=q^{1/82} changes only by the same root `zeta`; its
order b=273 and the target q-column are unchanged. QED.

Corollary 2.2. The two BPS presentations in the C9-B273-GLOBAL-BPS
non-determination argument are related by the source-allowed root rotation
(0.2). They are not two genuinely different value profiles. The argument
that changes `a` while holding `zeta_j` fixed changes `g_j`, but that is not
a source-allowed alternative: the root unit `zeta_j` and `a` are tied by the
source value formula/cyclotomic normalization.

## 3. Canonical gluing

The canonical gluing can be constructed at the level where the target
actually depends:

1. Choose any root `a` with `a^{82}=q`; define `g_j` by (1.1) using the source
   `zeta_j`. Corollary 2.2 makes `g_j` independent of the root choice.
2. Form the Gaussian monoid `Gamma_{r,v}=Delta(U_v)*xi^N`, `xi=(g_j)`, and
   the zero-label splitting; these depend only on `g` and the source units.
3. Glue the resulting Gaussian data to the Theta-pilot 0-column using q and
   the q-order b=273; no root coordinate enters the gluing.
4. Record the BPS label as the equivalence class under the root rotation
   (0.2), not as an absolute root. This is the source-normalized label.

At this level the root ambiguity is completely absorbed. The global BPS
gluing is canonical **up to the same source cyclotomic/root equivalence**,
which is part of the BPS data.

## 4. What the ambiguity does NOT do

- It does not change Theta values `g_j`, since the root change is compensated
  by the source root unit.
- It does not change the target column: Q depends on q and the b=273 q-order,
  not on the auxiliary root `a`.
- It does not change the Gaussian monoid or Kummer classes; only the
  representative `a` changes.
- It does not block the b=273 complete C.

## 6. If one insists on absolute-root labels

If a convention treats the absolute root `a` (not the pair class) as part of
the BPS label, then two labels related by (0.2) are literally different.
But this is a presentation choice; the target/Theta/Gaussian data are
isomorphic and the gluing is canonical up to that presentation. It cannot be
used to prove a genuine no-go for the b=273 target column, because the target
depends on q/b=273, not on the absolute root. A no-go would require a
source-invariant that changes under (0.2); the value profile, monoid, Kummer
class, and q-column are all invariant.
