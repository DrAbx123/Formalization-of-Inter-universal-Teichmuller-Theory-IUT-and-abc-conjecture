## 0. Exact C1 statement

Fix an admissible initial Theta-datum C. Let O be the collection of possible
output data produced by the multiradial construction algorithm of Theorem3.11
from the Theta-pilot object, in the region 1,circ U, modulo the
indeterminacies (Ind1),(Ind2),(Ind3). Let logVol be the packet+procession-
normalized log-volume of Prop3.9, defined on the Ind1/Ind2-invariant
mono-analytic log-volume data (Ind3 enters as upper semi-compatibility, not as
a group action). Put

    Q := -|log q|    (fixed q-pilot input value),
    h := -|log Theta| (procession-normalized log-volume of the holomorphic
                       hull H of the union of O, subject to Ind1/2/3),
    R_possible := { logVol(D) | D in O }  (possible output log-volumes).

C1 (exact existence/attainment form):

    there exists D0 in O such that logVol(D0) = Q.                 (C1)

Equivalently, because R_possible is defined as the logVol-image of O:

    Q in R_possible.                                              (C1')

C1 is an existence/attainment statement about an element of the output set,
not about a link of prime-strips and not about a formal membership in a
closure/approximation set.

Equivalent/related statements (kept separate; they are NOT C1):

  (C1_xi) Q in R_{<=h} := { x in R | x <= h }, where R_{<=h} is the source
           set of possible pilot-object log-volumes of output data. This is
           the conclusion asserted in source xi-f. If R_{<=h} is defined as
           R_possible cap (-infinity,h], then C1_xi is equivalent to C1 plus
           logVol(D0)<=h; if R_{<=h} is a formal/approximate set, C1_xi is
           weaker than C1.
  (C1_approx) there exists D0 in O and an explicit epsilon with
           logVol(D0)=Q+epsilon, or Q+epsilon in R_{<=h}, with a proved
           sign/bound on epsilon. Source xi-f mentions "perhaps only up to
           some sort of approximation" but supplies no signed epsilon.
  (C1_scalar_weak) Q <= h, with no assertion that Q is attained by an output.
           This is the scalar inequality equivalent to Cor3.12; it is weaker
           than C1 in proof content and is exactly what xi-f's final inclusion
           would give.

P6_can needs Q<=h. C1 (exact) plus monotonicity R_possible subset (-infinity,h]
suffices; C1_xi/approx may also suffice under their own definitions. C1 is the
strong statement; C1_xi is the source's formal statement; C1_scalar_weak is the
proper conclusion.

## 1. What A1-A3 give and do not give

A1 = Theorem3.11 + Remark3.11.1:
  - multiradial construction algorithm from the Theta-pilot object;
  - output collection O in 1,circ U, subject to Ind1/Ind2/Ind3;
  - IPL: output data linked to fixed q-pilot input by full poly-isomorphisms of
    F^⊩▶×mu-prime-strips (F^value full, F^unit×mu subject to Ind1-3);

  A1 does NOT give an evaluation map from the algorithm to a distinguished

A2 = Proposition3.9:

## 2. Strongest valid derivation from A1-A3

### 2.1 Unconditional consequences of A1-A3

Proposition 2.1. A1-A3 imply:
  (i) O is nonempty (the algorithm produces a collection of possible output
      data) and R_possible is a nonempty set of real numbers (where logVol is
      finite; h may be +infinity);
  (ii) h = logVol(H) with H the hull of the union of O;
  (iii) R_possible subset { x in R | x <= h }  (monotonicity of the hull/
      log-volume on regions; A2/A3);
  (iv) the formal quotient Ob9-1 makes logVol comparable across determinant/
      tensor/vertical indeterminacies, but does not select a representative.

In particular A1-A3 give the upper bound x<=h for every attained output volume
x, hence any C1 output D0 would give Q<=h. But A1-A3 do not give the existence
of such D0.

### 2.2 Conditional C1 theorem from local realization/assembly

Theorem 2.2 (C1 from Hloc+Hasm+Hcompat). Assume:
  (Hloc) for each vQ there is a possible local output D_vQ with
         logVol_vQ(D_vQ)=Q_vQ, where Q=sum_vQ Q_vQ;
  (Hasm) a source-allowed assembly map prod_vQ O_vQ -> O with
         logVol(assembly(D_vQ))=sum_vQ logVol_vQ(D_vQ);
  (Hcompat) the assembled object lies in the same possible-output set O modulo
         Ind1/2/3 and is compatible with the q-pilot/IPL link.
Then C1 holds: D0=assembly((D_vQ)) has logVol(D0)=Q.

Proof. Additivity A2 plus Hloc/Hasm/Hcompat. QED.

The hypotheses are exactly the missing local realization/global assembly/
compatibility inputs; they are not A1-A3. This is the strongest positive C1
theorem available from the three assumptions plus explicit realization data.

### 2.3 Conditional C1 theorem from an evaluation/attainment principle

Theorem 2.3 (E1/E2/E3 ⇒ C1). C1 follows from any one of:
  (E1) an evaluation/attainment principle: the algorithm has a canonically
       selected output D0 and logVol(D0)=Q;
  (E2) a strengthened xi-f: Q is the log-volume of an actual output element,
       not merely a possible/approximate value in R_{<=h};
  (E3) a direct construction of D0 from the q-pilot line bundle and the hull
       determinant, with exact equality of log-volumes.
Proof. Immediate from the respective statement. QED.

None of E1-E3 is in A1-A3.

### 2.4 What is proved vs assumed

PROVED from A1-A3:
  - O, R_possible, h exist; monotonicity R_possible subset (-inf,h];
  - A2 additivity/local decomposition;
  - A3 determinant/hull comparability and Ob9-1 formal quotient;
  - conditional C1 from Hloc/Hasm/Hcompat or E1/E2/E3;
  - if C1 holds, then Q<=h and Cor3.12 follows.

ASSUMED/OPEN:
  - C1 itself (or Hloc/Hasm/Hcompat, or E1-E3);
  - xi-f exact membership Q in R_{<=h} (source assertion, not A1-A3);
  - a signed epsilon if only C1_approx is available;
  - any actual evaluation map/representative modulo Ind1/2/3.

## 3. Counterexample search

### 3.1 What a counterexample would be

A counterexample to C1 under A1-A3 is a fixed admissible C together with
A1-A3 true, an output set O/logVol as above, and Q not in R_possible (no output
D0 with logVol(D0)=Q). It is not enough that the proof of C1 is missing; one
must exhibit the source objects and show the value is not attained.

### 3.2 Attempts and why they fail

(1) Abstract additive model. O={0}, logVol=id, Q=1, h=0. A2 additivity and A3
    comparison hold trivially; C1 fails. This proves A2's additive/log-volume
    properties alone do not imply C1. It is NOT a source model: it does not
    satisfy A1's Theorem3.11 algorithm/IPL/SHE/APT/HIS content. It is a
    minimal logical model showing the implication is not formal.

(2) Local model. O_vQ={single object with volume Q_vQ}, but no global assembly
    map into O. A2 local additivity holds; C1 fails. This shows local
    additivity does not produce a global output. Again not a source model: A1
    supplies a global multiradial algorithm, but not the local-to-global
    realization map Hloc/Hasm/Hcompat.

(3) APT/SHE/Ind quotient attempt. Use APT/SHE to define O as the collection of
    possible regions modulo Ind1/2/3, and try to read Q as an orbit. This gives
    an object-level link/IPL and a formal quotient, but no representative D0
    with exact logVol Q. The quotient can identify/approximate values without
    producing a representative. No contradiction/attainment theorem is
    obtained.

(4) xi-f formal inclusion attempt. Read xi-f as Q in R_{<=h} and try to infer
    C1. If R_{<=h} is defined as the attained log-volume set R_possible cap
    (-inf,h], this is exactly C1 (plus x<=h); if R_{<=h} is a formal/
    approximate possible-value set, the inclusion does not produce an actual
    output D0. The source's wording "perhaps only up to some sort of
    approximation" is not an exact attainment statement. This is the exact
    location of the gap, not a counterexample.

(5) Source-valid complete-C attempt. Constructing O/logVol for an actual C
    requires the complete uniform C/BPS/Theta-pilot/1-column algorithm and an
    explicit determinant/log-volume computation. That is the same missing
    object as C1/Cor3.12; no source-valid counterexample is constructed in the
    frozen corpus.

### 3.3 Counterexample status

No source-valid counterexample to C1 under A1-A3 is constructed. C1 is not
disproved. The abstract/local models show only that A1-A3, viewed as abstract
property lists, do not formally imply C1; they do not satisfy the full
Theorem3.11 source situation. The exact obstruction remains the absence of an
evaluation/attainment theorem (E1-E3) or local realization/assembly
(Hloc/Hasm/Hcompat).

## 4. Relation to xi-f and Cor3.12

Source xi-f (IUT III lines 10705-10715) says the construction of
R_{<=-|logTheta|} is subject to the condition that it constitutes, perhaps
only up to some approximation, a construction of the input pilot log-volume
-|logq|. It asserts the formal inclusion and the inequality. It does NOT state
an actual output element D0 with exact logVol(D0)=Q.

Therefore:

  - If xi-f is accepted as a source assertion of exact membership, then
    Q in R_{<=h}; if R_{<=h} is the attained set, C1 follows; if it is a
    formal/approximate set, only C1_xi/C1_approx follows.
  - If xi-f is only approximate (as its wording allows), then C1 is not
    obtained; a signed epsilon is needed but not supplied.
  - A1-A3 alone do not imply xi-f's exact membership either: they supply the
    construction, log-volume, hull/determinant comparability, but not the
    input-value attainment.

Thus the strongest valid statement is:

    A1 + A2 + A3 + (C1 or exact xi-f membership) => Q<=h (Cor3.12),
    A1 + A2 + A3 + (Hloc+Hasm+Hcompat) => C1,
    A1 + A2 + A3 alone do not imply C1.
