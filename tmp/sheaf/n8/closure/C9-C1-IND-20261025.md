# C9 C1 via Ind1/2/3 action：证明/否证与 exact obstruction

## 0. Verdict

**C1 不能由 A1 的 Ind1/2/3 作用 + A2 的 log-volume 推出。** 精确地：Ind1/2 保持 normalized log-volume，Ind3 只给 upper semi inequality；它们不会把某个 output 的 log-volume 变成 q-pilot 值 Q。C1 等价于 “Q 已经在 output log-volume set 中”，而不是 “Ind 作用可生成 Q”。A1 的 IPL 是 output 与 q-pilot **input** 之间的 poly-isomorphism link，不是 q-pilot 作为 output 的 membership。Exact obstruction 是 xi-e/xi-f 的 compatibility，而非 Ind 作用的手续。

## 1. Objects and actions

Let

```
O = set of possible output data/regions of the multiradial algorithm in 1,circ U;
logVol : O → R ∪ {+∞},  normalized packet+procession log-volume (A2/Prop3.9);
Q = -|log q|  (q-pilot input log-volume, fixed, not subject to Ind);
Ind1 = procession automorphisms / label permutations;
Ind2 = tensor-factor copy/unit isomorphisms;
Ind3 = upper semi-compatibility (nonarch inclusions, arch surjections).
```

C1:

```
∃ D0 ∈ O modulo Ind1/2/3  such that logVol(D0)=Q.
```

## 2. A1 does not give an output element with value Q

A1/Theorem3.11 gives:

```
- the multiradial construction algorithm and O;
- IPL: output data linked to the fixed q-pilot input by full poly-isomorphisms
  of F^value × mu-prime-strips;
- APT: construction algorithm, not a set-theoretic region map;
- SHE: expressibility relative to the 1-column structure;
- Ind1/2/3 on output possibilities.
```

The q-pilot is an **input and a prime-strip object**, not one of the output regions in O. IPL links the output **prime-strip data** to the q-pilot prime-strip; it does not assert that a region D∈O has the q-pilot’s log-volume. A full poly-isomorphism of F^value×mu-prime-strips is not an equality of regions or a value membership. So A1 alone gives no D0.

## 3. A2 and the Ind action on log-volume

A2/Prop3.9 gives a normalized log-volume on the F^value×mu-prime-strip data. Its behavior under the Ind actions is:

| action | effect on logVol | source/direction |
|---|---|---|
| Ind1 procession/label permutation | invariant (labels averaged/permuted; normalized volume unchanged) | A2/Prop3.9 + normalized averaging |
| Ind2 tensor-factor copy/unit | invariant (unit/μ actions have log 0 under B_I-zero normalization) | A2/Prop3.9; unit log-volume zero |
| Ind3 upper semi-compatibility | inequality, not equality (nonarch inclusions/arch surjections) | A1/Theorem3.11; A2 |

Hence for g∈Ind1/2: `logVol(gD)=logVol(D)`, and Ind3 only gives an inequality/closure. The set of log-volume values of the Ind-orbit is the same as the set for the original outputs:

```
logVol(O/Ind1,2) = logVol(O);   Ind3 adds only upper-semi closure.
```

Therefore Ind action cannot create a new value Q. If Q is not already in `logVol(O)`, no composition of Ind1/2/3 transforms an output into one with log-volume Q. This is a rigorous non-generation statement, not a semantic assertion.

## 4. C1 is exactly the missing membership

C1 ⇔ `Q ∈ logVol(O/Ind)`. Under Ind1/2 invariance this is equivalent to `Q∈logVol(O)`; Ind3 cannot add it except via inequality. A1’s IPL/SHE/APT/HIS give links and expressibility, but not the membership. The source’s xi-e/xi-f “constructs Q” is precisely the extra compatibility:

```
(C1-source) the multiradial construction of output possibilities produces
Q as one of the possible output log-volumes.
```

This is not a consequence of the group actions; it is a statement about the image of the construction. No Ind action proof can replace it.

## 5. Conditional theorem / exact obstruction

**Theorem 5.1 (conditional).** If

```
(M) Q ∈ logVol(O)  (before or after Ind1/2, equivalently; Ind3 only helps via inequality)
```

then C1 holds; Ind1/2 orbits preserve the value and Ind3 does not destroy it (upper semi-compatibility gives an inequality in the correct direction for the hull). Conversely, if `Q∉logVol(O)`, no Ind1/2/3 transformation can produce a D0 with logVol Q. Thus

```
C1 ⇔ (M)  modulo the Ind1/2 invariance and Ind3 direction.
```

**Exact obstruction:** (M) is not supplied by A1/A2/A3. A1 gives O and links; A2 gives logVol; A3 gives hull/possible-image geometry. None states that the construction’s output log-volume set contains Q. The source’s xi-e/xi-f is the missing membership; calling it an Ind-action consequence would be a semantic handwave. No explicit C/counterexample is constructed; this is a proof obstruction.

## 6. What would prove C1

One would need one of:

```
(P1) an actual output possibility D0∈O with logVol(D0)=Q;
(P2) an explicit construction algorithm from the q-pilot input to such D0;
(P3) a proof that the multiradial algorithm’s output set includes the q-pilot
     prime-strip/region as a possible output (xi-e/xi-f compatibility).
```

None is an Ind1/2/3 action theorem. Ind1/2 preserve values, Ind3 gives only upper semi-compatibility; they cannot create Q.
