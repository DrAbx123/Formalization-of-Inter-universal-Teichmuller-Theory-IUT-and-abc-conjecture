## 0. Verdict

The mixed bad/good profile formula of TAME §5 is a **different profile**: it uses a mixed bad/good tuple at the same p, which for F_mod=Q is not available because the V-section selects one place per rational p and the uniform profile has rho=1. C9-GLOBAL §1 explicitly forbids replacing unselected conjugates by a new rho=1/2 average. Thus the mixed region is not a possible image in the fixed uniform C target; it is an E3 (different profile) object. Task-299's theorem "H_C contains mixed region" is conditional on a scope assumption that fails here.

If one nevertheless puts the mixed region into H_C, it would indeed violate NPC/U dramatically:
- b=273, rho=1/2 TAME bound: h_mix/logp >= -(1/20)sum_j (1/2)^{j+1}(s_j+1/41) ≈ -0.98262577, so h_mix≈-9.2538 natural;

So the mixed region would be far above the U envelope and would make the b=273 counterexample disappear (it would help P6). This is precisely why its profile status must be settled; it cannot be used as an extra region inside the fixed b=273 target.

The source-valid countermodel to NPC is therefore not constructed. Task-301/302 confirm: row-only saturation gives H_C^row⊂R_B+arch conditionally, but no global U/NPC; the exact obstruction is the missing target-exhaustion theorem. NPC remains the decisive missing statement; conditional on NPC, U follows and b=273 has F>=8821.538890...>0.

No arbitrary region is introduced: the mixed formula is quoted only to show what would happen if its profile were in the target; it is not inserted.

Let U_row be the TAME §6 all-bad row subfamily, R_A/R_B its B=O_K/B=I hulls, and U_other the remaining possible-image branches (good places, arch, aggregate, other local types, full Ind1/BPS/Theta). ## 2. The task-299 mixed-profile challenge

TAME §5 constructs, for a **mixed bad/good profile** at the same p, a region D_tuple by moving the Gaussian marker to a good factor. Its target-coordinate hull is O_{E_tuple}, with the lower bound

    h_p^aligned/logp >= -(1/m)sum_j rho^{j+1}(s_j+1/e),  0<rho<1.    (2.1)

For b=273 and rho=1/2, the exact TAME bound is approximately -9.2538 natural, which is far above H_B+A_proc=-8884.245 and Q_p=-62.706. If this region were a possible image of the fixed uniform C, NPC and U would fail, and the b=273 counterexample would be invalid (indeed P6 would be favored).

Task-299 concludes that H_C contains this mixed region and hence is not generated only by B rows. That conclusion is correct for the **full mixed-profile target** if the profile is included, but it is not a statement about the fixed uniform F_mod=Q C.

## 3. Scope obstruction: the mixed profile is not the fixed uniform C

For F_mod=Q:
- I Def3.1(e) V->V(F_mod) is a section; each rational p has one selected place; the uniform profile is rho=1.
- C9-GLOBAL §1 states explicitly that one cannot replace unselected conjugate places by a new rho=1/2 average to avoid the uniform case.
- TAME §5's mixed bad/good profile requires a tuple with some good factors at the same p (or an allowed mixed profile); it is a different profile, not a possible image of the fixed all-bad uniform C. The normalized weights and target column of that profile differ.
- Good places at other rational primes have normalized finite h=0 in the C9 normalization; they do not add a positive-volume complement. The arch component is already h_inf.

Thus task-299's mixed region is not in the fixed uniform H_C; it is an E3 profile change. Using it as an NPC countermodel would change the target, which is not allowed. Task-301/302's statement "no source-valid countermodel" is consistent: the only known countermodel candidate is outside the fixed profile; the row-only part is contained in R_B by task-298.

This is the exact scope obstruction. It is not a claim that mixed-profile P6 statements are false; they are simply not the b=273 uniform target.

## 4. Proof attempt for NPC

A source proof of NPC would need:

(N1) TAME §6 local saturation: every local row lattice is B=O_K or B=I (available only as inferred source consequence for the fixed all-bad tuple).
(N2) Row ordering R_A subset R_B (proved task-298).
(N3) No other target possible-image class in the fixed profile: good/arch are bounded/zero+cap, full Ind1/factor permutations/BPS/Theta/gluing transport the same rows and preserve volume (task-285 conditional), aggregate/other local types do not add positive volume outside R_B+arch.
(N4) Hull-of-union does not enlarge beyond R_B+arch (the hull/exhaustion direction, not merely per-row volume).

(N1)-(N2) are available conditionally; (N3) is the task-285 no-new-region statement, conditional on the saturation model; (N4) is the missing target-exhaustion/NPC theorem. The proof attempt stops at (N4): TC-B is a lower inclusion, TC-C is volume preservation, and the row classification is not a global upper bound. Therefore NPC is not proved from the frozen source.

No source-valid countermodel:
- The TAME mixed region is excluded for the fixed F_mod=Q uniform profile (section 3).
- Task-285 found no new source lattice/q-BPS class beyond B=O_K/B=I; the full Ind1/procession actions permute/transport the same rows.
- The abstract extra-region countermodel (task-300) is TC-valid logically but not source-constructed; it cannot be used as an actual NPC countermodel.
- No explicit full-target possible image outside R_B+arch with positive volume is constructed.

Thus NPC is neither proved nor refuted; the exact obstruction is (N4).
