## 1. Strongest valid conditional theorem

Theorem 1.1 (b=3 B=I P6). Assume:

(H1) actual B=I branch: the B=I source configuration is realized at b=3, so
     the local possible-image region R_B is an actual source branch;

(H2) TC-B target saturation: H_C is the normalized holomorphic hull of the
     full possible-image union, including R_B and the full Ind1/Ind2 transports;

(H3) normalized-volume identity: this transported R_B contributes
     h_B=(9/41)log p for b=3;

(H4) archimedean lower bound: h_inf>=-S3.

Then

    h_C >= h_B+h_inf = (9/41)log p + h_inf,                    (1.1)
    F=Q_p-h_C <= -S3-h_inf <= 0,                               (1.2)
    h_C >= Q_p.                                                 (1.3)

Proof. By H1-H3 and task-272, R_B subset H_C and monotonicity of normalized
volume gives (1.1). Subtract from Q_p=(-3/41)log p:

    F <= (-3/41-9/41)log p - h_inf = -S3-h_inf.

By H4 this is <=0. Hence h_C>=Q_p. QED.

arch work. It is conditional on H1-H4.

## 4. Exact obstruction

The b=3 P6 assembly cannot be made unconditional from the current source
because:

1. **B=I is not actual.** The branch is controlled by the uncomputed kappa.
2. **TC-B/H_C is not constructed.** The inclusion R_B subset H_C is
   definitional under TC-B, not an independent source theorem; without an
   actual H_C there is no target hull to contain R_B.
3. **R_B is a conditional lattice.** Its actual gamma-orbit/tensor transport
   and normalization are missing; assigning it as a possible image would be
   arbitrary without H1.
4. **h_inf>=-S3 is not proved.** Only upper bounds are available; no lower
   bound from B_I-zero, container inclusion, or product formula.
5. **Complete C/TC are missing.** The target-column and BPS/Theta data are not
   constructed.

No false sign is used: the BI region gives a lower bound on h_C, and together
with h_inf>=-S3 it gives P6. This is the correct direction, unlike the b=273
