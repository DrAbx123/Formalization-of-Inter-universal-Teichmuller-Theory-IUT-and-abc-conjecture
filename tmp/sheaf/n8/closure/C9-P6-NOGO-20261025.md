## 1. No-go theorem

Theorem 1.1 (b=273 no-go). Assume:

(C1) C is an admissible complete C of the C9 target with the uniform b=273
     profile at the single rational bad prime p=12301;
(C2) the corrected finite donor formulas of CFTH hold, in either branch
     B=O_K or B=I;
(C3) the target-container conditions TC-A..TC-H/TC-S hold and the
     archimedean hull is contained in the source container, so the B_I-zero
     bound h_inf<=A_proc of (0.2) applies.

Then

    F(C) = Q_C-h_C >= 8821.538890... > 0,                          (1.1)

so h_C<Q_C and P6 is FALSE for C. The conclusion is independent of the
B=O_K/B=I branch.

Proof. Under the uniform profile, Q_p=(-273/41)log p. The corrected finite
branch values are:

    B=O_K: h_A = (-39156/41) log p,
           F_A = Q_p-h_A = (38883/41) log p;
    B=I:   h_B = (-38736/41) log p,
           F_B = Q_p-h_B = (38463/41) log p.                        (1.2)

At the archimedean place, F=Q-h=sum_p alpha_p(Q_p-h_p)-h_inf, so

    F_A >= (38883/41)log p - A_proc,
    F_B >= (38463/41)log p - A_proc.                               (1.3)

Exact evaluation:

    (38883/41)log p = 8931.174578603...
    (38463/41)log p = 8834.703284644...
    A_proc          =   13.164393687...

    F_A >= 8931.174578603 - 13.164393687 = 8918.010184... > 0,
    F_B >= 8834.703284644 - 13.164393687 = 8821.538890... > 0.      (1.4)

Both lower bounds exceed 8800 and are positive. Hence F>0, so Q_C>h_C and
P6 fails. The B branch was not used beyond the two displayed finite values;
the sign is the same in both. QED.

Thus, **inside the stated C9/CFTH/TC/arch assumptions, the b=273 profile is
a P6 counterexample in both B branches.** It is not a positivity theorem, not
an "arch gap", and not branch-dependent.

## 2. The exact escape

Theorem 1.1 is a conditional no-go. The only ways to avoid the conclusion are
exactly:

(E1) **No admissible complete C realizes the b=273 profile** (the profile is
     not actual, or no complete C exists, or the branch is not realized).
(E2) **At least one of CFTH/TC/arch fails**: the corrected finite donor
     formulas (C2) do not hold as target identities, or the target-container
     conditions TC-A..TC-H/TC-S (C3) fail, or the actual archimedean hull is
     not contained in the source container so h_inf<=A_proc is not a target
     bound.
(E3) **The b=273 profile is replaced by a different profile** whose finite
     deficit is at most A_proc; then the number 8800 changes. This is a change
     of profile, not an escape for the stated b=273 profile.

If h_inf>A_proc is asserted, then (C3) fails: the hull is outside the IV
source container, so the object is not the admissible target hull. That is an
escape of type (E2) (target condition failure), not a proof of P6 inside the
target. No third escape exists: once C1/C2/C3 and b=273 both hold, the
inequality F>0 is forced.

In particular, a proof of P6 cannot retain the b=273 profile together with
CFTH/TC/arch; it must prove (E1) or (E2). No such proof is supplied by the
current corpus. This is the precise no-go boundary.

## 4. Why earlier weak Arakelov/arch attempts do not evade this

Earlier attempts tried to supply a positive archimedean/Arakelov term to push
h_C above Q_C. That is the wrong direction:

- P6 is h_C>=Q_C, i.e. F=Q_C-h_C<=0. A positive F is exactly failure.
- For b=3 B=O_K, deg L_diff=h_C-Q_C=-93.714971 with arch at most -80.550578;
  a positive term of size 80.55 would prove Q_C<=h_C+80.55, not P6.
- The archimedean IV container gives only h_inf<=A_proc=13.164, far below
  the b=273 finite deficits 8834.70/8931.17; no upper bound can close this
  gap. The b=273 no-go is quantitative and branch-independent.

No arbitrary auxiliary cycle, Green term, or radius is used; such a term would
change the object/target and is not an escape under (E1)-(E3).
