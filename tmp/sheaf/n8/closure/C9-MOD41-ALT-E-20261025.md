## 1. E 的 discriminant 与 bad reduction at 12301

```

      = −2566158921220528

```

`12301` 指数1；A=4,B=−2437249 在 p=12301 是 integral；p≥5；`v_p(Δ)=1<12` 故模型 minimal。且

```
v_p(j) = v_p(1728·4A³) − v_p(4A³+27B²) = 0 − 1 = −1 <0,
```

所以 p=12301 是 **multiplicative reduction type I_1**（不是 additive）。

这是 exact local/global fact；不需要计算 q 的精确值。

## 2. ℓ=7 的 exact point count 与 irreducible Frobenius

E mod7：

直接枚举 F7 的 7 个 x：

```
x: 0  1  2  3  4  5  6
x³+4x+4 mod7: 4  2  6  1  0  2  6
quadratic residues mod7: {0,1,2,4}
y-solutions per x: 2,2,0,2,1,2,0  (sum 9)
#E(F7) = 1 + 9 = 10.
```

故 `a_7 = 7+1−#E(F7) = 8−10 = −2`。Frobenius 的 characteristic polynomial：

```

```

## 3. 群论证书：含 order41 与 irreducible ⇒ full GL2

令 `H = Im(G_Q→GL2(F41))`。已证：

- `H` 含 order41 的非平凡 unipotent u；
- `H` 含 irreducible characteristic polynomial 的 g。

用 Dickson 的 GL2(F41) maximal subgroups 分类：proper subgroup 必含于以下之一：

1. Borel `B`：order `q(q−1)² = 41·40² = 65600`；
2. normalizer of split Cartan：order `2(q−1)² = 3200`；
3. normalizer of non-split Cartan：order `2(q²−1) = 3360`；
4. exceptional A4/S4/A5（projective orders 12/24/60，乘 scalar center order divides40）。

后三类的 group order 都不被41整除：

```
41∤3200,  41∤3360,  41∤12·40, 41∤24·40, 41∤60·40.
```

所以含 order41 元素的 H 若 proper，必含于 Borel B。可是 Borel 的每个元素都有 F41-特征值（stable line），不可能含 irreducible g。矛盾。因此 H 不是 proper subgroup：

```
H = GL2(F41);   SL2(F41) ⊂ H.
```

注意：这里不需要先假设 det surjective 或 H=GL2；两个元素本身迫使 H=GL2。结论比 SL2 containment 更强，但任务只要求 SL2，故满足。

## 4.5 字段 F=Q(zeta12,E[6],F2) 的 degree

任务还要求 account 字段 `F=Q(zeta12,E[6],F2)` 的 degree 是 2,3-smooth。这里：

- `E[6]` 的 splitting field degree divides `|GL2(Z/6)| = 288`；
- `[Q(zeta12):Q]=4`；
- `F2`（2-adic semistabilization）的 degree divides 24（p=2 的 wild 常数）；

故 compositum degree divides `4*288*24 = 27648 = 2^10 * 3^3`，只含素因子2,3；41∤[F:Q]。F/Q 是 Galois（各部分是 Galois closure 的 compositum），且 `E[2],E[3]` rational over F、`i in F`。因此对 `K=F(E[41])`，F/F_mod=Q 的 degree prime to41。**本文件的 mod41 image 结论不依赖这个 field 选择**；这里只确认其 degree 条件。其他 bad primes（19,12301,686229757）若另加 semistabilization，需单独把它们的 degree 纳入；本 task 命名的 F2 只覆盖2-part。
