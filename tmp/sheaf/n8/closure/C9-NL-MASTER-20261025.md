## 2. C1/C3 and the exact inequality direction

Lemma 2.1 (direction). C1 is a LOWER bound on h_C; therefore C3 is an UPPER
bound on F=Q_C-h_C. A positive upper bound on F does not prove F>0, and a

## 3. Theorem 1: conditional b=3 B=I P6 region

Theorem 3.1 (B=I b=3 P6 corridor). Let C be a complete admissible C with the
uniform b=3 profile at p=12301. Assume:

  (B_I) the actual branch is B=I, with the branch finite lower bound
        h_C >= h_B + h_inf = (9/41)log p + h_inf
        (equivalently at the bad prime h_p>=h_B);
  (Hinf) h_inf >= -S_3 = -(12/41)log p.

Then

    F(C)=Q_C-h_C <= Q_p-h_B-h_inf = -S_3-h_inf <= 0,

so h_C>=Q_C and P6 holds for C.

Proof. Q_p-h_B=-(12/41)log p=-S_3. By (B_I), subtract h_C:
F=Q_C-h_C<=Q_p-h_B-h_inf=-S_3-h_inf. By (Hinf), -S_3-h_inf<=0, hence F<=0. QED.

Remarks 3.2.

(a) The inequality direction is the whole point: a lower bound on h_C gives an
upper bound on F; if that upper bound is <=0, P6 follows. This is the valid
C1/TC direction.

(b) (Hinf) is sufficient, not necessary. If h_inf<-S_3, the above only gives
F<=-S_3-h_inf>0, which does NOT prove F>0; proving a counterexample in that
corridor would require a genuine upper bound h_C<=Q_C-eps (or TC equality), not
available here.

(c) The theorem is conditional on (B_I): B=I is unproven/type-gapped in the
frozen source, and the branch finite lower bound h_C>=h_B+h_inf is a conditional
branch statement, not an actual source theorem. Without (B_I), the generic C1
uses the weaker H^Sp=h_A lower bound and Theorem 3.1 does not apply.

(d) The actual complete C and actual h_inf are missing; E38 underdetermination
and H_A-full/E30/E33 obstructions are independent of the sign argument.
