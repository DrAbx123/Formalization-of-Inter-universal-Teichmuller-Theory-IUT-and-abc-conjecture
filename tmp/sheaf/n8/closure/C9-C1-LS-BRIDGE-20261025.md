## 0. Verdict

**REJECT the bridge.** Even if `S_q^LS` is admissible and `eta_q=eta^anab_{S_q^LS}`, the equality is still a statement about pointed one-dimensional real lines / volume classes in `R^ss`; it does not produce an actual multiradial output `D0∈O` with `logVol(D0)=Q`. The appeal to xi-e/f is circular: xi-e/f is precisely the missing compatibility (C1), not an independent theorem that can be applied after eta equality. The source's own wording allows “perhaps only up to some sort of approximation”; it does not give an exact output element.

## 1. What the log-shell route establishes

The route constructs a log-shell representative

```
S_q^LS ⊂ VC(LS),   eta^anab_{S_q^LS}(p_q) = [M],  M=1·S_q^LS=T_1(S_q^LS).

If G1-G4 hold (existence, class equality [M]=[S_q], admissibility, pointed iso), then

```
eta_q = eta^anab_{S_q^LS} : R^val → R^ss.
```

By Lemma A/pointed linear equality, this gives the target pilot class equality

```
[M]=[S_q] in R^ss,  vol(M)=vol(S_q)=Q.
```

This is still an equality in `R^ss`, the volume-class quotient of adelic measurable subsets. It does not assert an element of `O`.

## 2. xi-e/f content

IUT III Step(xi-e): “expressibility relative to the 1-column arithmetic holomorphic structure” is equivalent to expressibility under the condition that the input pilot log-volume equals `Q`. This is a **condition on the construction**, not an output element.

Step(xi-f): the construction of output data possibilities “constitutes a construction” of the input q-pilot log-volume, perhaps “only up to some sort of approximation”; the inclusion and inequality then follow formally. This is exactly the compatibility sentence. It is not a theorem that from `eta_q=eta^anab_S` one can produce `D0∈O`; it is the statement that would produce it.

Thus applying xi-f to the log-shell eta equality is circular: the eta equality gives a volume class; xi-f is the missing membership; using xi-f to get membership is using C1 to prove C1.

## 3. R^ss vs O

`R^ss` is a quotient of **all** adelic measurable subsets `T⊂VC(I_uv)` by equal volume. `O` is the set of possible output data of the Theorem3.11 multiradial algorithm, subject to Ind1/2/3. The inclusion

```
logVol(O) ⊆ R^ss
```

is not an equality. Even if `[S_q]∈R^ss` and `S_q^LS` is admissible, no source statement identifies a representative of `[S_q]` with an output `D0∈O`. The log-shell representative `S_q^LS` is an integral-structure input, not a multiradial output region.

## 4. What would make the bridge work

To get C1 from the log-shell eta equality, one needs one of:

```
(B1) a representative D0∈O of the R^ss class [S_q];
(B2) a theorem that the multiradial output set O surjects onto the relevant R^ss
     interval/class;
(B3) an exact, approximation-free xi-f theorem that states Q is the log-volume of
     an actual output D0.
```

None follows from G1-G4. xi-e/f is precisely (B3)'s source assertion, not a proof of it.

## 5. Conditional theorem / exact obstruction

**Theorem 5.1 (trivial conditional).** If `eta_q=eta^anab_{S_q^LS}` and moreover there is `D0∈O` with `logVol(D0)=Q`, then C1 holds. This is just C1 plus eta equality; it does not reduce C1.

The exact obstruction is the output membership `[S_q]∩logVol(O)≠∅`, equivalently `Q∈logVol(O)`. The log-shell route establishes at most a class equality in `R^ss`; it does not establish that class is realized by an output.

## 6. Relation to the previous volume-scaling/G5 audit

This is the same obstruction as C9-C1-VOL-BRIDGE: eta equality is at the level of pointed real lines/volume classes; the output set O is not R^ss. The log-shell construction improves the admissibility/type of S (G1-G4), but it does not touch the R^ss/O membership bridge G5. Therefore it does not prove C1.

## 8. Conclusion

The log-shell representation S_q^LS can at best produce an admissible input and an eta equality in R^ss. It does not produce an actual output D0∈O with logVol(D0)=Q. The xi-e/f step cannot be applied as an independent bridge; it is the compatibility C1 itself, and it is qualified by approximation in the source. The exact obstruction is `Q∈logVol(O)` / a representative of [S_q] in O. No Lean/mixed/E3; P6 open.
