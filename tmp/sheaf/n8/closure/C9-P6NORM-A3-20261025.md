## 1. Exact SHE definition

Remark 3.11.1(iii) (lines 9562-9579) defines simultaneous holomorphic expressibility:

(SHE) The construction of the output data, as well as the output data itself, is expressed in terms that are simultaneously valid/executable/well-defined relative to both
- the arithmetic holomorphic structure that gives rise to the Theta-pilot object in the domain of the Theta-link (structures in the domain Theta±ellNF-Hodge theater), and
- the arithmetic holomorphic structure that gives rise to the input data prime-strip (such as the q-pilot F^⊩×μ-prime-strip) in the codomain of the Theta-link (structures in the codomain Theta±ellNF-Hodge theater).

Remark 3.11.1(ii) (lines 9479-9516) fixes the input side: the functorial construction algorithm of Theorem 3.11 may be regarded as an algorithm whose input data is an F^⊩×μ-prime-strip (the codomain q-pilot prime-strip), functorial with respect to arbitrary isomorphisms of input F^⊩×μ-prime-strips. The codomain q-pilot F^⊩×μ-prime-strip, equipped with the rigidification determined by the arithmetic holomorphic structure of the vertical line, is "coric"/fixed throughout the algorithm.

Remark 3.11.1(iii) (lines 9524-9561) defines IPL: the output data is linked/related, via full poly-isomorphisms of F^⊩×μ-prime-strips induced by operations in the algorithm, to the input data prime-strip, the coric/fixed q-pilot F^⊩×μ-prime-strip with its rigidifying arithmetic holomorphic structure. Each intermediate F^⊩×μ-prime-strip may be taken both as the input data of the Theorem 3.11 algorithm and, via the full poly-isomorphisms, as the input data for the Kummer theory surrounding the q-pilot object.

Remark 3.11.1(iv) (lines 9601-9634) defines APT: the parallel transport is a construction algorithm simultaneously valid/executable/well-defined with respect to the domain and codomain arithmetic holomorphic structures, not a set-theoretic transport of a region. HIS says one may forget theta functions/theta values and regard the algorithm as producing "some sort of output data" from "some sort of input data" satisfying (IPL) and (SHE); only qualitative logical consequences are used in Corollary 3.12.

## 2. A3.1: fixed q-pilot input

At (1,0), the q-pilot object is represented, via the Kummer isomorphisms and log-shells of the 1-column, on 1,circUQ; its procession-normalized mono-analytic log-volume is the fixed real number -|log q|, and this representation is not subject to (Ind1), (Ind2), (Ind3) (Theorem B statement, lines 1169-1176; proof setup 10166-10180).

The q-pilot F^⊩×μ-prime-strip is the "coric"/fixed input data of the algorithm (Remark 3.11.1(ii)). Therefore A3.1 is a source definition, not an extra assumption.

## 3. A3.2: IPL links output to the fixed input

By IPL (Remark 3.11.1(iii), lines 9524-9539), the algorithm's output data is linked to the input F^⊩×μ-prime-strip by full poly-isomorphisms induced by the algorithm. The output data itself is a collection of possible data in 1,circU (Step xi-c, lines 10618-10639).

The F^⊩-prime-strip portion of this link is a full poly-isomorphism of F^⊩-prime-strips; the F-dagger×mu portion is more complicated because of (Ind1)-(Ind3) (Step xi-b, lines 10596-10600). For the q-pilot log-volume, the relevant portion is the pilot object/F^⊩×mu data; IPL identifies it with the fixed input's pilot data.

## 5. A3.4: fixed value inclusion

Step (xi-e) conclusion (lines 10696-10704): the algorithm followed by holomorphic hull and log-volume yields a collection of possible log-volumes of pilot-object output data
    R_{<= -|log(Theta)|} subset R
linked via F^⊩-prime-strip isomorphisms (IPL) to the pilot-object log-volume -|log q| of the input.

Step (xi-f) (lines 10705-10715): the construction of R_{<= -|log(Theta)|} is subject to the condition that this construction of output data possibilities constitutes, in particular, a construction [perhaps only up to some sort of approximation, as a result of various indeterminacies] of the pilot-object log-volume of the input, namely -|log q|. Therefore
    -|log q| in R_{<= -|log(Theta)|}.                                (5.1)

The source's inclusion (5.1) is then formal from the definition of R:
    R_{<= -|log(Theta)|} = { lambda in R | lambda <= -|log(Theta)| }.
Hence
    -|log q| <= -|log(Theta)|.                                      (5.2)
If C_Theta is any real number with
    -|log(Theta)| <= C_Theta * |log q|,                            (5.3)
and |log q|>0, dividing (5.2) by |log q| gives
    C_Theta >= -1.                                                  (5.4)

This expands A3 exactly: (5.1) is the fixed-value inclusion; (5.2)-(5.4) are formal algebra.

## 6. A3 as a source-conditional lemma

Lemma A3 (conditional). Assume:
(a) A is the Theorem 3.11 multiradial construction algorithm, with input an F^⊩×μ-prime-strip S up to isomorphism, and output data D linked to S by a full poly-isomorphism (IPL) (Remark 3.11.1(ii),(iii));
(b) D is expressed simultaneously relative to the domain Theta-pilot arithmetic structure and the codomain 1-column arithmetic structure (SHE) (Remark 3.11.1(iii));
(c) the pilot log-volume functional L is defined on the F^⊩×μ-prime-strip and L(S_q)=-|log q| for the fixed q-pilot input S_q; L is invariant under the full poly-isomorphisms of (a);
(d) the construction with input S_q is the one of (xi-e): it is valid under the fixed condition L(S_q)=-|log q|, and the possible output pilot log-volumes after hull/log-volume are R_{<= -|log(Theta)|}.
Then L(S_q)=-|log q| is in R_{<= -|log(Theta)|}; hence (5.2)-(5.4).

Proof. Run A on the fixed input S_q. By (a), the output data D_q is linked to S_q via a full poly-isomorphism; by (c), L(D_q)=L(S_q)=-|log q|. By (b)/(d), the construction is valid relative to the 1-column under the fixed input log-volume; applying the holomorphic hull and the procession-normalized log-volume, L(D_q) is one of the possible output pilot log-volumes, hence lies in R_{<= -|log(Theta)|}. Thus -|log q| in R_{<= -|log(Theta)|}; (5.2) follows from the definition of R, and (5.4) from |log q|>0. QED.

The lemma is source-conditional: (a)/(b) are Theorem 3.11/Remark 3.11.1; (c) is the definition of the pilot log-volume plus the full poly-isomorphism invariance; (d) is the source's (xi-e) interpretation plus the hull/log-volume construction.

## 7. Exact gaps

G1 (approximation semantics). The source says "perhaps only up to some sort of approximation, as a result of various indeterminacies" (lines 10709-10710). The exact inclusion (5.1) treats the fixed input log-volume as an actual element of R, not merely an approximate value. A formal proof must justify that the indeterminacies/approximation do not remove the equality of the fixed value; this is not spelled out in Corollary 3.12. This is the main semantic gap in A3.

G2 (full poly-isomorphism invariance). The step L(D_q)=L(S_q) uses invariance of the normalized pilot log-volume under full poly-isomorphism of F^⊩×μ-prime-strips. The source uses IPL and the definitions of the pilot object/log-volume, but does not display this invariance as a separate lemma. A formal proof must show that the procession-normalized log-volume is invariant under the full poly-isomorphisms induced by the algorithm (including local factor permutations/weights).

G3 (SHE to membership). The implication from SHE plus fixed input value to the membership -|log q| in R is the source's interpretation (xi-e)/(xi-f), not a derived set-theoretic statement. The source asserts that the construction "constitutes ... a construction of the pilot-object log-volume of the input"; a formal proof must define this constitution relation and show it yields membership, not merely a link via IPL.

G4 (hull/log-volume). The finiteness/compactness of the hull and the normalization of the log-volume come from Proposition 3.9/Remark 3.9.5 (lines 10234-10242, 7529-7868); the source does not expand the hull construction in Corollary 3.12. No numerical estimate of C_Theta is produced.

G5 (no explicit C). A3 does not construct a complete C; it is a universal construction-computation comparing two representations of the same q-pilot log-volume. This is not a gap but the intended schema.
