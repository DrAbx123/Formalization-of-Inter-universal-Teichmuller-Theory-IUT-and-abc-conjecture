# C1 NEW MATHEMATICAL TOOLS (research proposal)

Date: 2026-10-25. Status: C1 OPEN. No Lean.

## 0. On option A

Option A (accept IUT xi-f as source lemma) is circular as an *independent* proof:
xi-f is essentially C1, so using it to prove C1 assumes the conclusion. If the
IUT source proof of xi-f is valid, it is a source theorem, not circular; but we
have not verified it. Therefore choose B: build new tools.

## 1. Tool I: rationalized LGP correspondence

Let C_s = VC(LS) (small/log-shell container), C_l = VC(I) (large container),
and C_l^Q = C_l tensor_Z Q.

LGP in VC(O); multiplication by LGP defines
  L : C_l^Q -> C_l^Q,  U |-> LGP*U,
which is bijective on the rationalization. Let
  S^Q := L^{-1}(S_q) in C_l^Q.

Although S^Q need not lie in C_s, it is the exact rational preimage of the
q-pilot class. Tool I studies the restriction
  L_s : C_s -> C_l^Q,  S |-> LGP*S,
and its image.

## 2. Tool II: admissible density

Let Adm be the set of admissible integral structures S subset C_s for the
eta^anab construction (measurable, N-compatible, adelic image).

Conjecture (Density). Adm is dense in the measurable subsets of C_s in a
topology for which L_s and the volume-class map are continuous.

If Density holds, approximate S^Q by a sequence S_n in Adm with
  [L_s(S_n)] -> [S_q] in Rss.

## 3. Tool III: compactness exactification

C_s is a compact log-shell container. If S_n in Adm has a convergent
subsequence S_n -> S with S in Adm (Adm closed), and L_s continuous, then
  [L_s(S)] = [S_q].

Then eta^anab_S and eta_q have the same pilot class, so Lemma A gives
  eta_q = eta^anab_S.

This replaces the failed inverse/volume-scaling route by approximation in a
compact admissible class.

## 4. Tool IV: output-volume interval

Let O be the multiradial output set and
  O_vol := {logVol(D) | D in O} subset R.

Conjecture (Output interval). O_vol is a closed interval in (-inf,h] and
contains values arbitrarily close to Q from above (or Q is a limit point of
O_vol forced by Ind1/2/3).

Then Q in O_vol, so there is D0 in O with logVol(D0)=Q, i.e. C1.

## 5. Tool V: volume-class correspondence theorem

Combine Tools I-IV into:

Theorem (C1-toolkit). Assume
  (i) L_s is continuous on C_s;
  (ii) Adm is dense and closed in the relevant compact topology;
  (iii) volume classes are continuous and Rss is Hausdorff;
  (iv) O_vol is closed and Q is in its closure.
Then there exists S in Adm with [L_s(S)]=[S_q], and an output D0 with
logVol(D0)=Q. Hence C1.

## 6. What is genuinely new

Previous routes tried exact inverse S=LGP^{-1}S_q or volume scaling. Those
fail because LGP is a nonunit and L_s is not invertible on C_s.

Toolkit replaces inverse by:
  rational preimage + admissible approximation + compactness + output interval.

This is a new analytic/measure-theoretic approach, not a restatement of LANA.

## 7. First tests

T2. Is Adm dense/closed?
T3. Is Rss Hausdorff and volume continuous?
T4. Is O_vol closed and is Q in its closure?
