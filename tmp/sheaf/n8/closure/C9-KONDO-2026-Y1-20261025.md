## 4. What the 2025 trace theorem adds

Kondo 2025 Theorem E/1.3 gives, in the tame totally ramified case:

    W=ker Tr=<y2,...,y_d>,  Tr(y1) in pZ_p nonzero.               (4.1)

This yields:

    v_p(Tr(y1)) >= 1,   y1 in J => v_pi(y1) >= 1.                 (4.2)

Thus kappa=e v_p(Tr y1)-v_pi(y1) is an integer, but (4.1)-(4.2) do not give
its value or even the range [0,40]. If v_p(Tr y1)>=2, kappa can exceed40; the
branch B=I range 1..40 is not forced. If v_p(Tr y1)=1, kappa=41-v_pi(y1), but
v_pi(y1) is still unknown.

The actual y1/Tr is exactly the missing input; no 2026 theorem computes it.
