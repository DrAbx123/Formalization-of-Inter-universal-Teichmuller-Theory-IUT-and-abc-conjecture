## 1. A1 statement to expand

A1 (q-pilot input/representation) consists of four assertions:

(A1.1) There is an actual q-pilot object, defined from the q_v at the bad
       places, in the global realified Frobenioid.
(A1.2) There is a q-pilot F^{value x mu}-prime-strip, which is the coric/fixed
       input prime-strip rigidified by the 1-column arithmetic holomorphic
       structure.
(A1.3) The q-pilot object/prime-strip has a representation on the 1-column
       region 1,circ U_Q, via the 1-column log-Kummer correspondence.
(A1.4) The multiradial output possibilities are linked to this input prime strip
       by full poly-isomorphisms of F^{value x mu}-prime-strips, induced by
       algorithm operations; the F^{value} portion consists precisely of full
       poly-isomorphisms, while the F^{unit x mu} portion is subject to
       (Ind1), (Ind2), (Ind3).

A1 is not a black box: A1.1 is Definition 3.8(i); A1.2 is Remark 3.11.1(ii);
A1.3 is Step (xi-a)-(xi-c) plus Remark 3.12.2(iv); A1.4 is IPL in Remark
3.11.1(iii) and Step (xi-b).

## 2. A1.1: q-pilot object from q_v

Definition 3.8, (i), lines 6506-6544, says:

    the object determined by any collection, indexed by v in V_bad, of
    generators up to torsion of the splitting monoid associated to the split
    Frobenioid F^{unit}_{Delta,v} — that is, concretely, determined by the q_v
    for v in V_bad — is a q-pilot object.

Two exact qualifications are part of A1:

- the q_v are taken up to torsion: the generators are not a canonical single
  element but a collection up to torsion;
- the q-pilot object is an object of the global realified Frobenioid, not a
  real number. The real number -|log q| is its log-volume, not the object
  itself.

The log-volume is introduced separately in the Corollary 3.12 discussion
(lines 858-916 and 10682-10704): the q-pilot object's log-volume is denoted
-|log q|, and |log q| > 0.

Thus A1.1 is a source-level construction, not a black box. What it does not
give is a canonical single generator q, hence not a canonical value of
-|log q|; the O_K^times indeterminacy is explicitly discussed in Remark
3.9.5(vii), lines 7758-7779.

## 3. A1.2: q-pilot F-prime-strip is coric/fixed input

Remark 3.11.1, (ii), lines 9505-9516:

    the codomain Theta-Hodge theater of the Theta-link, together with the other
    Theta-Hodge theaters in the same vertical line, i.e., in effect, the
    q-pilot F^{value x mu}-prime-strip, equipped with the rigidification
    determined by the arithmetic holomorphic structure constituted by this
    vertical line, is coric, i.e., remains invariant / may be regarded as being
    held fixed throughout the execution of the algorithm.

Therefore the q-pilot F^{value x mu}-prime-strip is an INPUT datum, fixed and
rigidified by the vertical line. It is not generated by the output of the
algorithm and is not an explicit construction from the local q_v alone; the
rigidifying arithmetic holomorphic structure is part of the input.

Definition 3.8(ii), lines 6545-6585, identifies the Theta x mu LGP-link with
the full poly-isomorphism

    F^{value x mu}_{LGP} -> F^{value x mu}_{Delta}

of F^{value x mu}-prime-strips. This is the source of the poly-isomorphism
language in IPL, not an extra assumption.

## 5. A1.4: IPL poly-isomorphism link to output

Remark 3.11.1(iii), lines 9524-9539, is the exact IPL statement:

    (Input prime-strip link (IPL)) This output data is constructed in such a way
    that it is linked/related, via full poly-isomorphisms of F^{value x mu}-
    prime-strips induced by operations in the algorithm, to the input data
    prime-strip, i.e., the coric/fixed q-pilot F^{value x mu}-prime-strip,
    equipped with its rigidifying arithmetic holomorphic structure.

Each intermediate F^{value x mu}-prime-strip is both the input to the
functional algorithm and, via the full poly-isomorphisms to the q-pilot
F^{value x mu}-prime-strip, the input to the Kummer theory surrounding the
q-pilot object.

Lines 9541-9561 give the explicit composite:

1. inverses of the first two lower horizontal arrows of the commutative
   diagram of Remark 3.10.2;
2. the first vertical arrow (Kummer theory portion of Theorem 3.11(iii)(c),(d));
3. the three upper horizontal arrows (evaluation map portion).

The final evaluation portion involves the Theta-pilot object up to
(Ind1),(Ind2),(Ind3); under the sign conditions of Remark 2.4.2(iv),(vi) and
the product-formula/inverse-system considerations of Remarks 3.9.6, 3.9.7, it
yields the global realified Frobenioid portion of an F^{value x mu}-prime-strip,
together with rigification possibilities.

Step (xi-b), lines 10595-10600, sharpens the split:

    the F^{value}-prime-strip portion of the link/relation consists precisely of
    (full poly-)isomorphisms of F^{value}-prime-strips, while the corresponding
    link for F^{unit x mu}-prime-strips is more complicated, as a result of
    (Ind1), (Ind2), (Ind3).

Thus A1.4 is exact: output is linked to the fixed q-pilot input by full
poly-isomorphisms, not by equality; the unit side carries Ind1-3.

## 6. What A1 gives and what it does not

A1 gives:

- an actual q-pilot object from q_v in the global realified Frobenioid
  (Definition 3.8(i));
- a coric/fixed q-pilot F^{value x mu}-prime-strip input (Remark 3.11.1(ii));
- a 1-column representation on 1,circ U_Q via the fixed ring structure and
  log-Kummer correspondence (Step xi-a-c; Remark 3.12.2(iv));
- an exact IPL link from output possibilities to that input, full poly-
  isomorphisms on F^{value}, Ind1-3 on F^{unit x mu} (Remark 3.11.1(iii);
  Step xi-b).

A1 does not give:

- a canonical single generator q or a numerical value of -|log q|; the q_v are
  up to torsion and -|log q| is a log-volume, not the object;
- a canonical section/equality of the F^{unit x mu}-prime-strip link; Ind1-3
  remain;
- an explicit complete C; A1 is a source-input representation, not a
  construction of the target C;
- an upper or lower bound by itself. Bounds require A2 (determinant/log-volume
  comparison) and A3 (fixed q-pilot value via SHE), as in Steps xi-d-f.

## 7. Exact gaps/status

1. q_v generator indeterminacy: Definition 3.8(i) uses generators up to
   torsion and a collection; no canonical q. This is source-level, not an
   omission.
2. F^{value x mu} input: the q-pilot prime strip is an abstract
   poly-isomorphism class with rigidification, not a canonical object; the
   source explicitly works with full poly-isomorphisms.
3. 1-column representation: precise equalities depend on the fixed 1-column
   arithmetic holomorphic structure (Remark 3.12.2(iv)); in the 0-column only
   upper bounds may be available.
4. IPL: the output is a collection of possibilities; the link is a full
   poly-isomorphism class, not a function/section. The unit side is subject to
   Ind1-3.
5. The q-pilot prime strip is an input datum; it is not constructed from local
   E_j/q data by A1. Any C9 complete-C use would need the actual input
   F^{value x mu}-prime-strip and its rigidification.

A1 is therefore expanded to explicit source steps with the above exact gaps.
No black box remains for A1 itself; the remaining comparison is A2/A3.
