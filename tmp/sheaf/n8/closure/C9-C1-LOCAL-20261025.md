# C9 C1 attack via log-volume additivity/localization

Task: task-433 (C1 via log-volume additivity/localization). Owner: volumedet.
Date: 2026-10-25. Short natural-language proof/obstruction only. A1=Theorem

`target_accepted=false`.

## 0. Verdict

C1 is **not derivable from A1+A2+A3** by log-volume additivity/localization
alone. Prop3.9 gives an additive/local log-volume functional, but C1 is an
**existence/membership** statement:

    C1: there exists an output possibility D0 in O (modulo Ind1/2/3)
        with logVol(D0)=Q.

Additivity can compute logVol(D0)=sum of local volumes only after a global
D0 has been constructed/compatibly assembled. It does not produce D0 from a
decomposition of the scalar Q. The exact missing input is the joint
realization/gluing of the local q-pilot contributions by one source-allowed
global possible output. That is the same compatibility as xi-e/xi-f, not a
consequence of A1-A3.

No source counterexample to C1 is available, so C1 is not disproved; it is
an independent open lemma. A formal additive model shows A2 alone cannot
imply C1.

## 1. Local decomposition

Proposition3.9 gives local log-volumes at places vQ and the global
log-volume by adding them, with packet/procession normalization:

    logVol_global(D) = sum_{vQ in VQ} logVol_{vQ}(D_vQ),
    logVol_{vQ}(tensor/direct sums) additive with the prescribed weights.  (1.1)

By construction,

    Q = Q_can = sum_{v in Vbad} Q_v + (good/arch q-pilot terms),
    h = h_can = sum_{vQ} h_vQ   (hull log-volume).                (1.2)

For the p-adic bad places Q_v is the q-pilot local volume (q_v); h_v is the
local hull volume; arch/good terms are included by (1.1). Additivity is a
property of logVol as a functional, not a statement that every scalar
decomposition is attained by an object in O.

## 2. Attempted additive derivation

The natural attempt:

    (L-v) for each vQ, choose a possible output D_vQ with
          logVol(D_vQ)=Q_vQ;
    then assemble D0 = assembly((D_vQ)_vQ);
    by additivity logVol(D0)=sum Q_vQ=Q; hence C1.                  (2.1)

The first line is local existence; the second line is a **compatibility/
assembly** hypothesis. A1-A3 do not supply either in the required form:

- A1 gives output possibilities in the multiradial algorithm, not an
  independent local choice for each q_v followed by a product assembly.
- The q-pilot input is not subject to Ind1/2/3, while output possibilities
  are; an object-level link (IPL) does not imply that one can independently
  realize every local q-pilot volume and glue them.
- Ind1/2/3 act on the global construction, not factorwise-independently over
  rational places; local choices may not be simultaneously compatible.
- Prop3.9 additivity is a map `logVol: O -> R`; it does not assert that the
  image contains the sum of arbitrary local values.

Thus (2.1) is a conditional derivation: it requires (L-v) plus global
assembly/compatibility. That is not A1-A3; it is essentially C1 itself.

## 3. Exact obstruction

Theorem 3.1 (additivity does not imply C1). A1+A2+A3 do not imply C1. More
precisely, A2 supplies an additive/local functional on the possible-output
set O, A1 supplies O and the q-pilot link, A3 supplies the determinant/
log-volume comparison, but none supplies the statement

    Q in logVol(O).                                            (3.1)

Proof/obstruction. C1 is (3.1). A2 gives identities of the form
`logVol(union/tensor of already constructed outputs) = sum`, i.e. a
homomorphism property conditional on the object being in O. It never
asserts surjectivity of logVol onto a prescribed sum, nor existence of an
object with a prescribed value. A1 gives the output algorithm and IPL links;
an F^⊩▶×mu-prime-strip poly-isomorphism is not a log-volume membership
statement. A3 gives comparability after determinant; it is not an existence
theorem. Hence no formal derivation of (3.1) from A1-A3 is available. QED.

Minimal logical model (not a source model): take O={0}, logVol=id (additive),
Q=1. A2's additivity/localization holds, A3's comparison holds trivially,
but C1 fails. This shows the additive/local form of A2 is insufficient; only
extra source-specific realization can exclude such a model.

## 4. Conditional C1 theorem

Theorem 4.1 (local realization + assembly ⇒ C1). Assume:

(Hloc) for each vQ there exists a possible local output D_vQ in O_vQ with
       logVol_vQ(D_vQ)=Q_vQ;
(Hasm) there is a source-allowed assembly map
       assembly: prod_vQ O_vQ -> O, with
       logVol(assembly((D_vQ))) = sum_vQ logVol_vQ(D_vQ);
(Hcompat) the assembled object is in the same possible-output set modulo
       Ind1/2/3 and compatible with the q-pilot link.

Then C1 holds: D0=assembly((D_vQ)) has logVol(D0)=Q.

Proof. Additivity (1.1) plus Hloc/Hasm. QED.

The theorem is valid but its hypotheses are exactly the missing
local-realization/global-assembly/compatibility inputs. They are not in
A1-A3; Hloc/Hcompat encode the xi-e/xi-f bridge.

## 5. What additivity does give

- It decomposes h and Q into local sums (1.2).
- It proves uniqueness/consistency of logVol once an object D0 is known.
- It shows that if a source output is a disjoint/tensor assembly of local
  outputs, its volume is the sum.
- It does **not** show that Q is in the image, or that the q-pilot value is
  an output value.

## 6. No theta-value/log-volume confusion

The q-pilot Q is defined from the q_v (and their local volumes). The
Theta-pilot hull h uses theta values q_v^{j^2}. Additivity applies to the
log-volumes of the corresponding regions; it does not identify q_v with
theta values or infer Q from theta-value algebra. C1 is about the q-pilot
value lying in the possible-output log-volume set, not about equality of
theta values.

## 7. Conclusion

Log-volume additivity/localization is necessary but not sufficient for C1.
It supports the conditional theorem (local realization + assembly ⇒ C1) but
does not derive the missing global realization. The exact obstruction is
that A1-A3 describe the output algorithm, the additive functional, and the
determinant comparison, but not the existence of one possible global output
with the fixed q-pilot value. C1 remains an independent open lemma (the
xi-e/xi-f compatibility). No source counterexample is constructed.
