## 1. What C1 asks

C1 is a numerical/set-membership statement:
    exists D0 in O (mod Ind1-3), logVol(D0)=Q.
It is not an object-level poly-isomorphism statement. The q-pilot object is an input; O is output data. A full poly-isomorphism from output prime-strip data to the input q-pilot prime-strip does not give an output region whose log-volume equals Q.

C1 is equivalent to the xi-f inclusion Q in R_{<=h_can} once R_{<=h_can} is the set of possible output log-volumes bounded by h_can. It is the compatibility step C9-COMPATIBILITY-LOCATION calls the open xi-e problem.

## 2. What A1 (Theorem3.11) gives

A1 gives:
- a multiradial construction algorithm;
- possible output data O in 1,circU, subject to Ind1/2/3;
- IPL: output data linked to the fixed q-pilot input by full poly-isomorphisms of F^value×mu-prime-strips;
- SHE: construction expressible relative to the 1-column arithmetic holomorphic structure;
- APT: construction algorithm simultaneously valid in domain/codomain, not a set-theoretic region map;

None of these says there exists an output element D0 whose log-volume is Q. IPL is object-level, not value-level. SHE is expressibility under the fixed input value condition, not equality of an output value. APT explicitly denies a set-theoretic region transport. HIS permits forgetting the theta data, so it cannot manufacture a numerical membership. Ind1-3 are indeterminacies/quotients of output data, not a membership proof.

Verdict: A1 does not imply C1. It supplies the objects and properties, not the bridge.

## 3. What A2 (Prop3.9) gives

A2 plus A1 gives logVol(O) as a set of possible values, but no statement that Q is in that set. The set could be empty, or could contain values different from Q, while all A1/A2 properties hold.

Verdict: A2 does not imply C1.

## 4. What A3 (Remark3.9.5) gives: closed loop, cQ3/cQ4, Ob9-1

### 4.1 The closed loop

Remark3.9.5(ix) lines 8383-8405 asserts the chain
    q-pilot codomain -> LGP-link to domain -> sQ1/sQ2 -> sQ3/sQ4 -> q-pilot
forms a closed loop, up to formal quotient indeterminacies. The source does not derive this loop from cQ3/cQ4; it asserts it (C9-CAN-A3-COMPATIBILITY-DERIVATION lines 8-13, 92-98). The loop's content is a prime-strip simultaneously equipped with the Theta-intertwining (up to Ind1/2/3) and the q-intertwining (lines 8417-8424).

The loop starts and ends at the q-pilot object. It does not create an output element in O with log-volume Q; it returns to the input side. The endpoint being q-pilot is not the same as q-pilot being one of the output possibilities. The latter is C1.

### 4.2 cQ3/cQ4

cQ3/cQ4 are compatibility properties of sQ3/sQ4 with the F^⊣×mu-prime-strip/log-Kummer data (Remark3.9.5(ix); Ob7/Ob8; lines 8264-8366). They say the operations preserve the relevant actions/actions-up-to-log-iterate; they do not produce a numerical log-volume equality. Even if cQ3/cQ4 are derived, cQ3+cQ4 do not imply the composite closed loop (C9 compatibility doc), and neither implies C1.

### 4.3 Ob9-1

Ob9-1 says the formal indeterminacies (tensor-power-twist, ⊼, log-link iterates) have no effect on comparability of the objects obtained in Ob5. It is a statement about coarse invariants such as log-volume, not a statement that the q-pilot value Q occurs as a log-volume of an output element. The exact quotient action is not expanded; "no effect on comparability" is weaker than "Q in logVol(O)".

Verdict: A3's loop/cQ3/cQ4/Ob9-1 do not imply C1.

## 5. Proof attempt and its failure

Attempt:
1. Start with q-pilot input S_q, logVol(S_q)=Q.
2. Follow LGP-link/sQ1/sQ2/sQ3/sQ4; closed loop returns to S_q.
3. Hence S_q is an output; therefore Q in logVol(O); C1.

Failure points:
- Step 3 is invalid: a closed loop is a chain of poly-isomorphisms returning to S_q, not a construction of S_q as an output element of the multiradial algorithm. The output data O are in 1,circU; S_q is the fixed input/codomain object. Closed loop does not change the type of S_q from input to output.
- Even if the closed loop's final prime-strip is identified with S_q, that is an **object-level** equality/poly-isomorphism; C1 requires a region/output element D0 with logVol(D0)=Q. Object-level equality does not give value membership unless one also proves that the endpoint is an output and that logVol is the same functional. The first is C1; the second is A2/representation, not loop closure.
- The closed loop is only up to formal quotient indeterminacies; the exact quotient/identification is not given. Ob9-1 no-effect does not supply the missing element.
- cQ3/cQ4 are compatibility, not membership; IPL is object-level; SHE is expressibility; APT is non-set-theoretic. None supplies D0.

Thus the attempted derivation assumes C1 in Step 3.
