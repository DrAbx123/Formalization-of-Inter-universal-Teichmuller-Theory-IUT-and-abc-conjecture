TAME Section 6 B=O_K/B=I all-bad row families for the selected bad places, and
let R_B+arch be R_B times the archimedean factor.

NPC (uniform no-extra-region):

    every source-valid possible image in H_C lies in R_B+arch.       (NPC)

If NPC holds, monotonicity of normalized volume gives

    h_C <= max(H_A,H_B)+h_inf,                                     (U)

because every B=OK/B=I row is at most the max finite value; the arch factor is

## 3. Why the row classification is not an exhaustion

TAME Section 6 states explicitly that its L_A/L_B classification is only for
the listed fixed all-bad r-tuple subfamily, "not an upper bound for the entire
C's log/Theta/infinity output family." The uniform target still contains:

1. **Multiple bad rational primes.** V_bad is a nonempty set of rational
   primes; the fixed uniform profile can have several selected bad places,
   possibly with different local fields/local types. TAME Section 6 classifies
   one fixed all-bad tuple, not the product/aggregate over the full S_bad.
   Tensor products of row lattices may be natural, but no source theorem
   identifies the full global hull with their product.

2. **Other local types at other bad places.** Uniform rho=1 only fixes the
   selected local profiles as bad; it does not force every bad place to have
   e=ell=41 tame type. The R_B row formulas are derived under the tame
   e=ell, low-ramification hypotheses. A wild/other-e bad place has no row
   formula and is not shown to be generated by R_B. (This is not a mixed
   good/bad profile; it is a different local type within a uniform bad set.)

3. **Full Ind1 procession/log iterates.** R_B is a lattice generated by the
   Gaussian/transvection subfamily at a fixed level. H_C uses the full
   procession automorphism group, log-link iterates, and Theta-pilot powers.
   TAME Section 6 does not prove that all such actual images have row volume
   classes inside R_B; the source says the row classification is not the
   entire log/Theta/infinity family.

4. **Aggregate B=I configurations.** Multiple bad primes can have B=I rows
   whose tensor/weighted aggregate is not a single R_B row. Aggregate B=I
   counts in C9 are conditional and do not supply an NPC classification.

5. **Good places and arch.** Good finite places have zero normalized volume,
   but they still have labels/integral regions; arch is a separate factor.
   They do not create a positive finite volume class, but a complete NPC proof
   must still account for their labels/product structure.

6. **No actual complete C/H_C.** The source has no actual complete C with
   target hull/TC-B; without it, NPC is a statement about an unconstructed
   object.

Thus NPC is not a consequence of TAME Section 6; it would require a new
exhaustion theorem for the full uniform target family.

## 4. Conditional NPC => U theorem

Theorem 4.1. Assume (NPC) and TC-B/normalized-volume monotonicity. Then

    h_C <= max(H_A,H_B)+h_inf.                                     (4.1)

Proof. H_C is contained in R_B+arch. The row volumes are bounded by
max(H_A,H_B) (B=OK/B=I values), and the arch factor contributes h_inf;
normalized volume is monotone. QED.

This is a valid conditional implication, not a proof of NPC. It shows exactly
why the task matters: NPC is precisely the missing saturation-exhaustion
hypothesis.

## 5. Exact obstruction

The obstruction is:

    no source theorem classifies all source-valid possible-image regions of a
    fixed uniform rho=1 C by the two B-row families plus arch.

Specifically missing:

(O1) global multi-prime/aggregate row classification;
(O2) other-local-type (wild/e!=ell) row formulas or exclusion;
(O3) full Ind1/log/Theta iteration exhaustion;
(O4) actual complete C and target hull H_C/TC-B;
(O5) aggregate B=I global volume classes.

No uniform extra region is constructed in this note, and none is needed to
refute NPC as a *source theorem*: the point is that NPC is not available from
the frozen classification. If one assumes NPC, U follows; without it, the
b=273 upper side remains blocked.
