## 4. Exact mod-p criterion for B=O_K versus B=I

Write l in the adapted U⊕W basis as

where the first coordinate is U. Since Tr(l)!=0, the U-coordinate is nonzero
and can be normalized to 1. Let G_p=Sp_40(F_p) act by (1,w) -> (1,A w),
fixing U pointwise.

Criterion (exact linear algebra):

    v = 0      =>  G_p fixes l; orbit(l)={l}; B=O_K.
    v ≠ 0      =>  G_p acts transitively on nonzero vectors of W; choose A
                  with A v = e_1. Then (1,e_1) is in orbit(l). Using all
                  A' in G_p gives (1,e_i) for all i, hence U and all e_i;

p odd (standard symplectic transvection argument); see the finite certificate
below for an explicit transvection.

Thus the B-branch decision is exactly the question `v=0?`.  It is not a
question about arbitrary matrices: only the actual source line l and the
actual U/W splitting enter.
