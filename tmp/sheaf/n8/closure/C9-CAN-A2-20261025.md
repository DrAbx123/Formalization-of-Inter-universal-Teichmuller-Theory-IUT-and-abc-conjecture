## 1. Canonical question

The canonical A2 statement would be an identity of canonical real numbers:

    deg_can(L_H) / M = mu_log_can(H) = -|log(Theta)|_can,       (1.1)
    deg_can(L_q) = -|log(q)|_can,                               (1.2)
    -|log(q)|_can <= -|log(Theta)|_can.                          (1.3)

with no choice of packet/procession normalization, no normalized surrogate,
and no arbitrary integer M.

The source does not provide this canonical absolute form. It provides a
normalized form:

    deg_nu(L_H) / M = mu_log_nu(H) = -|log(Theta)|_nu,           (1.4)
    deg_nu(L_q) = -|log(q)|_nu,                                 (1.5)

for a normalization nu described in Proposition 3.9(i). The subscript nu is a
real choice: packet normalization (O(-) volume zero; multiplication by p_v
adds -log(p_v); multiplication by e adds 1) and procession normalization
(average over capsules).

The exact result of this task is:

- the ratio identity (1.4) is canonical up to a common positive rescaling;
- the absolute identity (1.1) is a source gap;
- the P6 inequality (1.3) is invariant under common positive rescaling, so a
  normalized A2 suffices for the inequality, but not for canonical values.

## 3. Exact normalized identity

The normalized identity of task-392 is:

    L_H = det^otimes M(E_H) tensor det^otimes M(O(-))^{-1},       (3.1)
    deg_nu(L_H)/M = deg_nu(det E_H) = mu_log_nu(H)
                  = -|log(Theta)|_nu.                             (3.2)
    deg_nu(L_q) = -|log(q)|_nu.                                  (3.3)

Proof. Ob3-3/Prop3.9(iii) give deg_nu(det E_H)=mu_log_nu(H). Ob3-2 gives the
M-th power, so deg_nu(det^otimes M(E_H))=M mu_log_nu(H). Prop3.9(i) makes
deg_nu(det O(-))=0, so the O(-) inverse determinant has degree zero. Divide by
M. QED.

This is exact **for the chosen nu**, but it is not the canonical absolute
identity (1.1).

## 4. Normalization covariance

Let nu' be another normalization obtained from nu by a common positive scalar
c on log-volumes and degrees:

    mu_log_nu' = c mu_log_nu,
    deg_nu' = c deg_nu,  c > 0.                                 (4.1)

Such a change is induced by rescaling the Haar measures / log-volume units
uniformly on both sides. Then

    deg_nu'(L_H)/M = c deg_nu(L_H)/M = c mu_log_nu(H)
                   = mu_log_nu'(H),                             (4.2)
    -|log(q)|_nu' <= -|log(Theta)|_nu'
      iff -|log(q)|_nu <= -|log(Theta)|_nu.                     (4.3)

Thus:

(C1) The **ratio identity**

         deg_nu(L_H) / (M mu_log_nu(H)) = 1                       (4.4)

     is canonical: it is independent of nu, provided deg and mu_log use the
     same nu.

(C2) The **absolute value** -|log(Theta)| is not canonical: it changes by c.
     The source does not fix c canonically.

(C3) The **P6 inequality** is invariant under common positive rescaling, so a
     normalized A2 is sufficient for the inequality (1.3), even though it is
     not a canonical absolute identity.

## 6. Exact canonical result

Theorem 6.1 (canonical ratio, conditional). Assume the normalized A2 identity
(3.2) for a normalization nu, and assume deg_nu and mu_log_nu are related by a
common positive scalar under change of normalization as in (4.1). Then the
canonical ratio identity

    deg_nu(L_H) / (M mu_log_nu(H)) = 1

holds independently of nu, and the P6 inequality (1.3) is independent of the
common normalization.

Proof. (3.2) gives the ratio 1 for nu. Under (4.1), numerator and denominator
both scale by c, so the ratio is unchanged. The inequality is homogeneous of
degree 1 under c>0. QED.

This is the strongest canonical statement available. It is a **ratio**
identity, not an absolute identity of canonical real numbers.

Exact gap: there is no canonical absolute value -|log(Theta)| in the source;
the source fixes only a normalized log-volume nu, and the degree-log-volume
equality is stated "relative to a suitable normalization." Therefore the exact
canonical A2 identity (1.1) is not available.

## 7. Consequences for P6_can

- If P6_can means the inequality -|log(q)| <= -|log(Theta)|, then the
  normalized A2 identity suffices, because the inequality is invariant under
  the common positive rescaling nu -> c nu.
- If P6_can means equality of canonical absolute real numbers, then the
  canonical A2 identity is a source gap: the absolute normalization c is not
  fixed.
- In neither case does the source provide the explicit determinant/O(-)/M
  construction; G1-G7 remain.
