## 0. Verdict

(Adm) is REFUTED as stated. The obstruction is a container/type mismatch, not a numerical error:

- S_q = {q_v O_v} is a value-group/fractional-ideal diagonal, i.e. a pilot class in the value-group container. It is not a measurable subset of the log-shell volume container VC(I_v) in which eta^anab_S is defined by LANA. LANA's own sentence (line 2517) says that the **pilot of the target Rss of eta_q** is the class of {q_v O_v} embedded diagonally into VC(I_v); that makes it a pilot class in Rss, not an admissible integral structure S.
- The diagonal {q_v O_v} is measurable in the value-group/small container (q_v O_v is compact open in K_v), but measurability in that container does not give measurability as a subset of the tensor/log-shell container VC(I_v). No source embedding/containment is constructed.
- N-stability is not established (and is not a property of the q-pilot diagonal in the LANA construction). The N-action on VC(I_v) is nontrivial; LANA uses M=1·S as the pilot, not an N-fixed S. The q-pilot diagonal is the pilot for eta_q, not the fixed integral structure S required by eta^anab.
- Therefore eta^anab_{S_q} is not defined by the LANA construction; Lemmas A and B of the eta-reduction cannot be applied; C1 is not obtained from this route. C1 itself is not disproved; only this admissibility reduction fails.

No extra assumptions are introduced. The exact obstruction is the identification of a pilot class with an admissible integral structure in the log-shell volume container, plus the missing N-stability/domain theorem.

## 1. LANA objects

From LANA section "The main goal":
- VC(I_v) is the log-shell version of the large volume container; it is a product/direct sum of tensor powers of log-shells I_v (lines 1540-1580).
- Rss = { T subset VC(I_v) | T adelic and measurable } / ~, where T ~ T' iff their volumes coincide (lines 2508-2510).
- Once fix S subset VC(I_v), LANA says this provides an isomorphism
      eta^anab_S : R^val -> Rss,
  with M=1·S (the action of 1 in N) representing LGP·S, and the class [M] as the target pilot (lines 2506-2513).
- For the q-pilot, eta_q is the isomorphism whose target pilot is the class of {q_v O_v} embedded "diagonally" into VC(I_v) (lines 2515-2517).
- The main goal is: exists S such that eta_q = eta^anab_S (lines 2519-2523).

Important distinction: the S in eta^anab_S is an **integral structure** fixed in VC(I_v); the {q_v O_v} diagonal is the **pilot of eta_q's target**, a class in Rss. The notation "{q_v O_v} embedded diagonally into VC(I_v)" does not by itself say that this diagonal is an admissible S; it says the pilot class is represented that way.

## 2. Measurability of S_q

q_v is a nonzero element of K_v; q_v O_v is a compact open O_v-submodule of K_v (a fractional ideal), hence Haar measurable with finite positive measure in K_v. Therefore the diagonal {q_v O_v} is measurable in a product/small value-group container built from copies of K_v.

But eta^anab_S lives in the **log-shell version** VC(I_v), not the value-group container VC(K) or the small container. VC(I_v) replaces K_v by the log-shell I_v and tensor products over Z_{v_Q}. The inclusion q_v O_v subset I_v may hold in a single nonarchimedean component for q_v integral (q_v O_v subset O_v, and O_v subset I_v for the usual log-shell), but:
- the diagonal embedding into the **large** container uses tensor powers of I_v and products over places; it is not the same set as q_v O_v;
- for archimedean components and for the full adelic product, the containment/measurability of the diagonal in VC(I_v) is not stated by LANA;
- no source construction embeds the value-group diagonal q_v O_v as a measurable subset of VC(I_v) with the required tensor/adelic structure.

Thus measurability in the value-group container is ACCEPTED, but measurability/inclusion in VC(I_v) is NOT PROVED. This is already a failure of the "S subset VC(I_v)" requirement if read literally.

## 3. N-stability

The N-action of the eta algorithm is the action of the discrete N-part of the Gaussian monoid on VC(I_v) (LANA lines 2008-2020, 2495-2503). LANA defines M=1·S, i.e. only the unit element 1 acts on S to produce the pilot; it does not require or prove S to be stable under all of N.

For S_q={q_v O_v}:
- q_v O_v is a fractional ideal/lattice in the value-group direction; the N-action on VC(I_v) is a nontrivial Gaussian/log-shell action, not multiplication by an O_v-unit on q_v O_v.
- There is no source identity N·S_q=S_q. If N-stability means equality, a nontrivial N-action would move the diagonal; if it means N·S_q subset S_q, one would need S_q to be a VC(O)-submodule/integral structure stable under the Gaussian monoid, which is not proved.
- LANA's construction uses S as an integral structure and M=1·S; the q-pilot diagonal is the target pilot of eta_q, not a fixed S. Confusing the two gives the circularity already recorded in C9-C1-LITERATURE (S=q-pilot diagonal is circular unless admissibility is proved).

Thus N-stability of S_q is REFUTED as a proved property; the exact failure is that S_q is a pilot/value-group class, not an N-stable integral structure. If one interprets N-stability downward, the property is at best unproved; if equality, it is false for a nontrivial action.

## 4. Admissibility for eta^anab

LANA says "once we fix S subset VC(I_v), this provides an isomorphism eta^anab_S" (lines 2506-2513). This is a source assertion about S; it is not an assertion that every subset of VC(I_v), and in particular the q-pilot diagonal value-group class, is admissible.

The eta^anab construction uses:
- the action of N on VC(I_v);
- S as the integral structure/reference;
- the volume quotient Rss and the class M=1·S as target pilot.
For S_q={q_v O_v}, the construction would need:
(i) S_q subset VC(I_v) measurable (section 2: not proved);
(ii) S_q compatible with the N-action/integral structure (section 3: not proved/refuted);
(iii) the target pilot class [1·S_q] to be the q-pilot class; this is the intended pilot matching, but only after (i)-(ii).
Without (i)-(ii), eta^anab_{S_q} is not defined; the pilot-matching Lemma B of C9-C1-LANA-ETA-REDUCTION is conditional on this definition.

Thus admissibility is NOT PROVED; the construction cannot be applied at the stated level.

## 5. Consequence for the eta-reduction and C1

The eta-reduction argument was:
- Lemma A: two pointed linear isomorphisms agreeing on the pilot are equal (elementary, true);
- Lemma B: eta_q and eta^anab_{S_q} have the same pilot [S_q] (conditional on S_q admissible/defined);
- Therefore eta_q=eta^anab_{S_q}, hence C1.
The failure is Lemma B/Adm: eta^anab_{S_q} is not defined because S_q is not an admissible S in VC(I_v). Lemmas A and B cannot be applied. C1 is therefore not obtained from S_q.

This does not prove C1 false; it proves this particular S_q admissibility route fails. The exact obstruction is:
    value-group pilot class {q_v O_v}
    is not a log-shell integral structure S subset VC(I_v)
    with a proved N-action compatibility.
The source LANA states the q-pilot class as the target pilot; it does not identify it with the admissible S required by eta^anab.

## 6. What would be needed for a proof

A proof of (Adm) would need:
1. An explicit source embedding of the diagonal {q_v O_v} into VC(I_v) as a measurable adelic subset, with containment in the log-shell tensor factors and correct Haar normalization.
2. A proof that this subset is stable/compatible with the N-action (or a precise definition of the "integral structure" condition showing stability is automatic).
3. A proof that eta^anab_S is defined for this S and that its target pilot is exactly the q-pilot class [S_q].
No such source statements are in LANA lines 2502-2523; LANA says the main goal is open and does not construct S. C9-C1-LITERATURE records this as the open comparison.
