- Do NOT use closed loop/cQ3/cQ4 to directly produce the q-pilot numerical

## 1. Strategy A (recommended): exact local comparison + sum

Goal: prove a local version of xi-f exactly, then sum.

A1. For each v in V_bad, define the local q-pilot log-volume
      Q_v = -(1/2l) log q_v  (2l=82 normalization),
    and the local multiradial output packet U_v associated to the theta values
    q_v^{j^2}, j in F_l^*.

A2. Prove the local exact equality
      logVol(U_v) = Q_v.
    Reason: U_v is built from the Gaussian monoid generated by q_v^{j^2};
    the theta ratios theta(U_j)/theta(U_0)=q_v^{-j^2/2} have log-volume
    exactly -j^2/2 log q_v; the j-averaged/procession-normalized sum gives
    Q_v. This is local arithmetic, no global approximation.

A3. Prove U_v is a possible output packet: it is obtained by applying the
    local portion of the multiradial algorithm to the Theta-pilot object.
    This is the local part of Theorem3.11; no Ind quotient is needed for the
    VALUE at v.

A4. Sum over v with the global weights/procession normalization:
      Q_can = sum_v Q_v (+ arch/good zero).
    The union/product of the local packets U_v is a possible global output
    packet U with logVol(U)=sum Q_v=Q_can.

A5. Therefore Q_can is the log-volume of an actual possible output U;
    Q_can in R. Since R is bounded by h_can, Q_can <= h_can.

Key advantage: bypasses the global closed loop and the 'approximation'
quotient by working at the local value level where the computation is exact.
Key obligation: exact local theta/log-shell computation A2 and compatibility
of local packets with the global multiradial output A3/A4.

## 2. Strategy B: closure/limit + compactness

Goal: use the source's approximation as a limit, not as exact equality.

B1. From xi-e/f, for every formal indeterminacy neighborhood there is a
    possible output value x with x arbitrarily close to Q_can (up to Ind).
B2. Prove the set R_poss of possible output log-volumes is closed:
    possible output data lie in compact log-shell packets; log-volume is
    continuous on compact hulls; the hull operation is continuous.
B3. Then Q_can, as a limit of elements of R_poss, lies in R_poss.
B4. R_poss subset R_{<=h_can}; hence Q_can <= h_can.

Key advantage: matches source's approximation language literally.
Key obligation: construct the approximating outputs and prove closedness/
compactness (including the VQ index/finiteness problems flagged in review).

## 3. Strategy C: determinant line bundle exact degree

Goal: prove Q_can is the degree/log-volume of an output line bundle.

C1. Construct the q-pilot line bundle L_q and the hull determinant line
    bundle L_H = det^tensor M(E_H) tensor det^tensor M(O(-))^{-1}.
C2. Prove L_H is isomorphic to L_q in the global Frobenioid, in a fixed
    packet+procession normalization.
C3. Then deg(L_H)=deg(L_q), and by Ob3-3/Prop3.9 this common degree is both
    h_can and Q_can; hence Q_can is an output log-volume.
C4. Conclude Q_can in R_{<=h_can}.

Key advantage: uses the source's actual comparison objects (xi-d).
Key obligation: rank/O(-)/M/normalization details, previously rejected as
'suitable normalization' handwaving; must be displayed exactly.

## 4. Strategy D (fallback): APT fixed-point

The APT algorithm constructs the input q-pilot log-volume. If the algorithm
is a map F on log-volumes and constructs its input, then Q_can is a fixed
point of F. The output set R contains the image of F; if the fixed point is
in the image, Q_can in R.

Key obligation: define F and prove the fixed-point/image statement from APT;
currently only informal ('constitutes a construction'), so likely rejected.
